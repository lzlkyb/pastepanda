P1.1 选区拖拽即画新框

对标微信截图：默认吸附窗口已就绪，本步只修正"在吸附窗口内按下=平移选区"这一处偏差，使任意起点拖拽都画新矩形。

交互对比

改前（现状偏差）
  • 按下点在当前选区内 → 进入「平移选区」，拖拽=移动整个窗口选区
  • 只有按下点在选区外 → 才画新矩形
  • 后果：吸附窗口铺满大半屏时，想框一小块却变成移动窗口
改后（微信同款）
  • select 态按下一律画新矩形（任意起点，含吸附窗口内）
  • 位移 < 4px（单击）→ 提交当前吸附窗口进标注
  • 位移 ≥ 4px（拖拽）→ 提交新矩形进标注
  • 平移改为：选区确认后用八向手柄拖移

期望交互流

进入·全暗→ hover 吸附窗口（蓝框）→ 按住拖拽（任意起点画新框）→ 松开·提交进标注

落在吸附窗口内直接拖 = 画新框（不再平移）；单击窗口 = 采纳该窗口；Esc = 回吸附；双击空白 = 全屏。

验收

  • 在吸附窗口内部按下并拖拽 → 画出新矩形（非平移窗口）
  • 在窗口内单击 → 直接进标注（采纳该窗口）
  • 从空白处拖拽 → 画新矩形（原行为不变）
  • Esc 回 select → 重新 hover 吸附
  • 多选/标注后 Shift 多选、八向手柄拖移仍正常
