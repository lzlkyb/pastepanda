0 · 现状语法账（解析器已支持，本稿零语法改动）

任务文字尾部 @日期 时间：日期 = 今天 / 明天 / 后天 / 9/26 / 09-26 / 2026-09-26， 时间可选 = 16:00（全角冒号 16：00 也认）；@ 必须由空白引出且延伸到行尾（1–2 个词）—— 邮箱@example.com 不算尾巴。带时间 = 到点提醒；只写日期 = 全天（当天 23:59:59，不提醒，只排序）。 ❗ 预览的措辞必须如实区分这两者（「到点提醒」vs「全天 · 不提醒」），不许把全天说成会响。

3 · 节拍与状态机

触发行为退出
输入出现 @（空白后独立段）补全面板弹出 + 预览条出现（实时解析）点 chip / Esc / 删掉 @ / 失焦
点日期 chip（今天/明天/后天）替换尾部为 @今天 （光标落在尾端等时间词）面板保持（还可能继续点时间 chip）
点时间 chip（9:00/14:00/18:00）尾部无日期 → 先补 @今天 再接时间：@今天 14:00完成即收面板
每击键（含 @）invoke todo_island_parse_due（本地解析，微秒级，无需节流）→ 预览三态—
Esc面板开着 → 先关面板；再按 → 既有两级取消（compose→list→pill）—
❗ Esc 变三级（面板 → 列表 → 胶囊）：面板是输入框内的临时层，先关它符合「最近优先」直觉，且面板 Esc 不产生任何副作用（没改输入）。落地时 TodoIslandList 的 onKeyDown 在 Enter 分支前插 Esc 分支即可。

新增 todo_island_parse_due(text) → { ok, label, has_time } | null：内部直接调用 due_tail → parse_due_date / parse_due_time → resolve_due → due_label 现有函数链（规则 #11.1： 展示文字的唯一定义就是那条链，预览绝不允许第二份解析——不然预览说 ✓ 实际存进去是正文，比没有预览更糟）。 本地纯解析，不联网不花钱，不涉 AI 开关（规则 16）。todo_island_parse_due 注册进 lib.rs 命令表。

5 · 无障碍与边界

项处理
预览条读屏role="status"（aria-live polite）：解析结果变化自动播报，不抢焦点
面板 chips 键盘chips 是真 button，Tab 可达；面板开时 Esc 归面板（§3）；不塞箭键导航（6 项点选为主，避免 roving 复杂度）
失败态不给假信心⚠ 态明确「没看懂」+ 支持范围一句话 + 一键纠错；绝不静默把尾巴当正文存（这正是本稿要消灭的事）
回车记下时预览为 ⚠拦一道：⚠ 态回车 → 预览条 shake 一次 + 输入框聚焦（不阻塞、不强改），用户明确再按才放行？否——推荐不拦：用户有权故意留正文里的 @；预览职责到「如实告知」为止（拍板项③）
多屏 / 主题预览条与面板材质走既有 --island-* 令牌，浅色主题 data-island-mode 自动跟随

7 · 请拍板（三项）

① 预览条出现时机：仅输入含 @ 时（推荐）——零打扰；备选常驻一行提示（发现性更好但永久吃 24px）。
