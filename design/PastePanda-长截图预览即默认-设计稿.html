长截图「预览即默认」— 微信思维落地

P1 预览即默认 · P2 单击采纳 / 拖拽自定义 · P4 Esc 回预览。改前 vs 改后。

改前 现状

点「长截图」→ 立即隐藏截图窗 + 自动向下滚动拼接。
用户看不到「会截多长」，只能等跑完；想只截一段得进状态窗点「停止并出图」盲停。

改后 预览即默认

整页 ≈ 2400px · 约 4 屏
点「长截图」→ 截图窗不隐藏，先显示整页淡预览（虚线框 + 斜纹延展 + 尺寸标签）。
• 单击预览区 = 截整页（原有自动滚到 get_scroll_bottom）。
• 拖拽青色终点手柄 = 只截到该处为止。
• Esc / 放弃 = 回选区，零成本。
实现要点（基于真实代码）
  • 后端新增 get_scroll_range(x,y)：复用 find_vscroll_hwnd + GetWindowRect + GetScrollInfo，返回 {x,y,w,h,n_max,n_page,n_pos}；无 Win32 滚动条返回 None。
  • 前端点「长截图」先调用它：命中有滚动条且 extraBelow = n_max-n_page-n_pos 明显 >0 → 进 longPreview 态（窗口不隐藏）显淡预览；否则直接走原有 startLongShot()（零回归，浏览器/SPA 无预览仍可用）。
  • startLongShot 增加可选 captureBottomPx：循环里 totalH 达该值即裁末帧底部并 break（与 get_scroll_bottom 双保险）。
  • 预览层用现有 css()=v/dpr 坐标系渲染，与选区高亮同源；pointer 事件 stopPropagation，不触发 select 态框选。
  • 坐标：调用传绝对屏幕坐标（同 get_scroll_bottom 的 toScreenPt 写法）。
