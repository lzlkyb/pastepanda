交互说明：右键菜单「生成二维码」触发条件：内容是 URL 或短文本（≤300 字符）。 对话框 320px 宽，二维码 200×200 居中，下方显示内容类型徽标 + 原始内容（限高 60px）。 「复制图片」将 QR Canvas 转为 ClipboardItem 写入剪贴板；「保存 PNG」调用 Tauri 文件对话框另存为。
2 右键菜单 — 新增入口
URL 卡片右键（含二维码 + HTML 剥离）
「粘贴并变换」子菜单（含 HTML 剥离）
HTML 转纯文本：「剥离 HTML 标签」出现在「粘贴并变换」子菜单中（所有文本类型通用）， 同时 EditDialog 工具栏新增「去标签」按钮。检测逻辑：内容包含 <tag> 闭合标签对即判定为 HTML。

二维码：「生成二维码」仅对 URL 或 ≤300 字符短文本显示，位于「粘贴并变换」之后。
