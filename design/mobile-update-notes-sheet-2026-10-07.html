  • 容器：新增 MobileUpdateSheet 包 MobileSheet（drag-to-dismiss + 返回键 + 常驻 footer 全部现成），footer 放「稍后 / 主操作」。
  • 显示：条目渲染沿用桌面 GroupItem/stripBold 口径（剥 **、**标题**： 只显标题），分类 chip 色（CATEGORY_COLORS 字面色）落 CSS module 类，不用内联 style（lint:ui V 规则）。
  • 接线：MobileUpdateSection 与 MobileUpdateBanner 的「更新 / 查看」统一 open() 半屏，取代当前 firstLine() 露出的裸 markdown 星号；各事件态（available/downloading/ready/needPermission/error）驱动同一张半屏切换视图。Provider/hook 不动，符合桌面 UpdateContext 零改动契约。
  • 装机硬边界：ready/permission 视图如实说明系统确认不可跳过，不做「假装一键装成」的误导。
