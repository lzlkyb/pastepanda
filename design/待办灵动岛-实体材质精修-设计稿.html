待办灵动岛 · 实体材质精修（路线一）

2026-09-26 · 前提：Windows 上「胶囊形状」与「真系统毛玻璃」互斥已定论（红色探针 + 官方文档 + 三大生态对标一致）。本稿不再谈玻璃，只谈把不透的材质做到业界常数值。

对标结论（本稿依据）
  • 可查证的开源岛应用 2/2 纯黑实体、零桌面模糊：boring.notch 岛体 .foregroundColor(.black)（NSVisualEffectView 只出现在设置面板）；NotchDrop 全仓零 NSVisualEffectView，.foregroundStyle(.black) + .mask(notchShape)。
  • Electron 岛类一律 frame:false + transparent:true + hasShadow:false + CSS 画胶囊，全部放弃 vibrancy。
  • 它们共同的常数是：恒深外观（boring.notch 强制 .darkAqua）、岛体 α≈1、无系统阴影、顶边贴屏幕缘、圆角只在下部。

§1 五项精修 · 现值 → 建议值（现值全部抄自源码）

#项现值（源码）建议出处 / 代价
A岛体实体化基座 --island-tint: rgba(20,20,24,.78)（档 3a「厚磨砂」定档）默认推到 rgba(17,17,20,.97)；.92 作次档保留两家岛 app 是 α=1。唯一比它们多的考量：我们的岛是软件元素、不是硬件缺口，纯黑会在浅桌面上读成「死块」，所以停在 .97 而非 #000 —— 稿内甲/乙/丙三版并排给你判。
B恒深、不跟浅色主题[data-island-mode="light"] 整套白材质：rgba(255,255,255,.78) + fg #18181b岛体恒深（浅色模式下也是黑岛），删掉浅色材质整套覆写boring.notch 强制 darkAqua。翻案项：推翻 待办灵动岛-主题亮暗适配-设计稿.html 的方案 A「跟随应用主题」。收益是白壁纸上不再靠描边勉强保形，代价是「岛跟应用不同调」。不拍板就不动。
C边缘抗锯齿region 走「逐行像素中心」：像素中心落在 CSS 圆内才进 region（todo_island_stage.rs::build_stadium_region）region 外扩约 1px，把 CSS 弧的半透明过渡带留在 region 内现在的规则会把 AA 过渡带整像素裁掉 ⇒ 帽边是阶梯。外扩后过渡带与桌面正常混合，帽边变滑。代价极小：命中区只多出一圈 1px 环（不是四角各 110px² 的死区）。这一项跟材质无关，属独立技术账。
D受光层随实体化重算--island-gloss:.07 / --island-rim:.09 / --island-line:.12 / 两层外投影 .22 / .24实体档 gloss→.02（与现有 dark 档同值）、rim→.14、外描边 .12→.16不透之后，形状只能靠描边与亮线读出来，所以高光是负资产（我们自己的实测：深色可读性的杀手是镜面高光，不是染色），而描边要加重。投影两层保持不变（shadow(false) 靠自绘已是业界同款）。
E形状语言（顶部比方）展开态四角统一 border-radius:12px（候选 6 的顶 8/底 12 已按设计稿收回）改回顶 8/底 12iOS 与各家 macOS 实现都让形状「顶部更方」，因为它从屏幕边缘长出来（实施文档 §④ 已记过一次）。二次翻案，且 region 要同步拼非对称形状（历史上顶角月牙就是这么来的）⇒ 默认不做。

§3 C 项：帽边为什么是阶梯，外扩 1px 后长什么样

C 项必须先实测再改判据

本仓库对 GDI region 已经交过四次学费（§10.5 探针把 rgn 摘成矩形、§10.6 扫描线「左含右排」、底行整行被裁、条高理论被实测推翻）。所以「外扩 1px」的落地顺序必须是：① 探针实拍判据先定（深色背景 + 放大裁切，不用 PtInRegion 读数，那个有 ±10px 误差）→ ② 改 fill_row_polygon 的取整 → ③ 更新 test_stadium_region_hugs_css_cap 的 ±1px 判据为 ±1.5px。任何一步跳过都会把月牙问题换个形态再犯一次。

§4 三套配方

配方含项优点代价 / 风险
甲 · 保守A(.92) + D + C不动任何已拍板的东西（浅色主题、四档、形状全保留）；.92 就是现有 dark 档的值，等于只把默认档从 frost 换成 dark + 修边缘变化最克制，可能「看不出做了事」
乙 · 推荐A(.97) + D + C，浅色主题下仍给深岛（B）与两家业界常数对齐；对比度只会变好（.97 压白壁纸背景亮度≈ rgb(27)，比现在实算的最坏 rgb(72) 更深，现有 --island-due 全套取值全部富余）；浅壁纸上不再靠描边勉强保形翻案「跟随应用主题」，设置页要删一个开关或改成「岛恒深」；[data-island-mode="light"] 整套覆写作废
丙 · 全套乙 + E(顶 8 底 12) + 岛体纯黑 #000最接近 boring.notch/NotchDrop 的观感，「像硬件一部分」的错觉最强二次翻案候选 6；region 要重拼非对称形状（历史月牙高发区）；纯黑在我们的浮窗语境下有可能读成黑块

四档设置（data-glass：clear .30 / frost .78 / steady .90 / dark .92）在三套配方里都全部保留——想透的人仍可自选 clear；改的只是默认档与受光层随档位的重算。

§5 拍板点

?问题选项
