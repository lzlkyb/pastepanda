落地要点（Rust 端 src-tauri/src/pinned_window.rs）
1. WindowState 增加 rotation: f32、flip_h: bool、flip_v: bool 三个字段（当前只有 scale/offset/alpha）。
2. fill_buffer() 绘制时应用变换：旋转用「先以中心为原点旋转采样坐标」或 GDI world transform；翻转即镜像采样（sx = flip_h ? img_w-1-sx : sx，sy 同理）。注意旋转后需按外接矩形扩大缓冲区，否则四角被裁。
3. WM_KEYDOWN 新增分支：VK_R → rotation = (rotation+90)%360；VK_F → flip_h=!flip_h；VK_V → flip_v=!flip_v；'1' → scale=1.0。
4. WM_RBUTTONUP 菜单 items 增加「旋转 90°/水平翻转/垂直翻转/实际大小」四项，cmd_id 接 5–8，复用现有 match 结构。
5. HUD：在 WM_PAINT 末尾用 GDI DrawText 在底部画一行「缩放 N% · 旋转 N°」（仅当窗口有焦点/鼠标在窗内时显示，避免遮挡）。
6. 管理面板按 path 操作：新增命令 transform_pinned(path, {rotation, flipH, flipV})，经 CURRENT_WINDOW 按 path 找到 hwnd → PostMessageW 自定义 WM_APP+1 带新变换；或后端直接改对应 WindowState（需按 hwnd 取 USERDATA 指针）。
7. 验证：npx tsc → cargo check（带 LIBCLANG_PATH）→ 手动贴两张图分别 R/F/V 验证多贴图各改各的。
