PastePanda · 反馈面板（P0）设计稿方案 A

目标：用户在「设置 › 关于」里写反馈，一键导出脱敏诊断包，作者手动收取。纯本地、零服务器、不碰隐私红线。

1

入口：关于页页脚

在「设置 › 关于」底部操作栏加一个「反馈与建议」按钮（沿用 aboutFooterLink 样式，accent 色以示可交互）。

2

反馈对话框（FeedbackDialog）

点击入口弹出的独立对话框：分类 → 写反馈 → 隐私声明 → 导出诊断包 / 复制文本。复用全局 dialog 壳（遮罩 + 圆角面板）。

反馈与建议
✓

导出的诊断包已脱敏：只含版本、系统、使用统计与近期日志摘要，不含任何剪贴板内容。保存前可预览。

已导出 pastepanda-diagnose-2026-08-22.json（可拖到 GitHub Issue / 微信发给作者）
交互流： 点「反馈与建议」→ 写反馈 / 选分类→ 点「导出诊断包」→ 系统保存对话框选位置→ toast 提示成功 （「仅复制文本」生成 Markdown 模板贴到 Issue）
3

诊断包内容（JSON）

保存前弹一个预览确认（红线：让用户知道包里有什么、确认不含敏感内容再落盘）。

// pastepanda-diagnose-2026-08-22.json — 全部为脱敏信息，无剪贴板内容
{
  "app": { "name": "PastePanda", "version": "6.18.2", "os": "Windows 11 23H2", "arch": "x64" },
  "feedback": { "category": "建议", "text": "希望截图取文字支持竖排", "time": "2026-08-22 18:00" },
  "settings": { "ai_enabled": false, "theme": "ocean", "screenshot_hotkey": "Ctrl+Alt+A", "secrets": "excluded" },
  "usage_30d": { "total": 1420, "top_actions": [["ocr",386],["mosaic",204]], "ai_edit_rate": 12 },
  "recent_logs": ["[INFO] 截图窗打开", "[WARN] 取文字失败重试", "[ERROR] OCR 模型加载超时"],
  "screenshot_stats": { "ocr_runs": 386, "pin_count": 42 }
}
隐私红线：诊断包字段全部白名单化 —— 只导版本 / OS / 开关状态 / 统计数字 / 日志摘要。API key、剪贴板内容、历史记录文本一律不导出；日志取前端内存环形缓冲（最近 200 条、单条截断 160 字符），不读任何业务数据文件。
