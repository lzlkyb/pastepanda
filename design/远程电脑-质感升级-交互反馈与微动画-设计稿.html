4 · 动效规格与红线

令牌值用途
--motion-fast120ms / 按压 100ms:active 按压、开关拨动
--motion-base140–160ms所有 hover/选中/展开过渡，缓动统一 cubic-bezier(.2,0,0,1)
--motion-slow240ms入场类（横幅、列表 stagger、详情滑入）
--shadow-sm/md现有令牌复用三级浮起直接用已有 shadow 令牌，不新增阴影值
落码位置内容量级
RemoteComputerA2.module.css反馈三件套（:active / focus-visible / 统一 transition 挂到全部可点类）、三级浮起、选中态重做、绿点呼吸、shimmer、菜单弹出、横幅滑入主要工作量
RcA2DeviceList.tsxstagger 用 CSS :nth-child 延迟即可，无需 JS；shimmer 替换「正在加载设备…」纯文本态小
theme.css新增 --motion-fast/base/slow 三个令牌（亮暗同值）3 行
性能红线（AGENTS.md 规则 8）：① 只动 transform / opacity，禁止动 width/top/color 做动画；② 常驻动画仅绿点呼吸一个（每设备 1 个 9px 小元素的 opacity，合成层零重排）；③ 不引入 backdrop-filter；④ stagger 只在列表首屏出现时播一次，翻页/刷新不重播；⑤ 全部动效挂进现有 prefers-reduced-motion: reduce 兜底（A2 文件 997 行已有该块，动效统一在其中关闭）；⑥ 工作台窗口隐藏时 CSS 动画自动降频，无需 JS。
