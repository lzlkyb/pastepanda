远程电脑 · 质感重做设计稿 v1 · 全部基于真实组件与 token

参照稿：design/远程电脑最新设计稿.html（外部参考，非本产品 UI）——取它的材质与分层语言， 不取它的色值与信息架构。落地对象：「远程电脑」独立工作台窗口（1200×780 起）＋ 主窗口内三条 rc 常驻条。

〇 · 取法：那张稿的「质感」拆成 6 条，我们全都有对应 token

那张稿看起来「有质感」，不是因为它用了什么高级色，而是因为它把六件事做齐了：柔光渐变底 / 玻璃层 / 白描边 + 顶部高光 / 大圆角 / 带色柔影 / 克制的一组色。 对照我们的 theme.css：这六条里五条已经是现成 token（ocean 主题早就打开了 --shell-blur）， 问题只是 RemoteComputer.module.css 一条都没消费 —— 全库 grep --shell-bg / --app-bg / --glass-card-*，rc 域命中数为 0。 所以这次不是「引入外来风格」，而是把自家视觉层的账补齐：底子照旧，材质补上，圆角扩一档。

一句话：底色用 --app-bg、侧栏用 --shell-bg + --shell-blur、卡片用 --glass-card-* + --card-top-light、 主按钮用 --accent-solid / --ic-capture 渐变 —— 全部 color-mix 自现有 token 推导， 六套主题零改动自动继承（深色两套靠 --card-bg 变深自动变成「深色玻璃」，不需要各写一份）。 作用域挂在 RcWorkbench 已有的 data-rc-root 上 —— 这个挂点现成，不必新增。

新增：rc 域玻璃 token（本稿定义的唯一新东西）

[data-rc-root]{
  --rc-glass:      color-mix(in srgb, var(--card-bg) 70%, transparent);  /* 侧栏 / 轨 */
  --rc-glass-soft: color-mix(in srgb, var(--card-bg) 54%, transparent);  /* 主区舞台 */
  --rc-glass-hard: color-mix(in srgb, var(--card-bg) 88%, transparent);  /* 行 / 卡 / 底栏 */
  --rc-blur:       blur(18px) saturate(1.25);
  --rc-edge:       color-mix(in srgb, var(--accent) 13%, transparent);   /* 结构描边 */
  --rc-shadow:     0 1px 2px rgba(15,23,42,.04), 0 8px 24px color-mix(in srgb, var(--accent) 12%, transparent);
  --rc-r-ctl:9px; --rc-r-row:12px; --rc-r-card:14px; --rc-r-stage:18px;  /* 圆角阶梯扩档 */

  /* 主按钮渐变：起点 #0378B4（白字 4.88:1）、终点 #026AA0（白字 5.96:1），两端口都过 AA */
  --rc-cta: linear-gradient(135deg, #0378B4 0%, #026AA0 100%);
  --rc-cta-shadow: 0 1px 2px rgba(2,106,160,.35), inset 0 1px 0 rgba(255,255,255,.24);
}

为什么主按钮不加亮：参照稿的 #006cff 压白字只有 3.1:1。渐变起点每上一档都要重算 —— #0386C9 是 4.01:1（不合格）、#0B8FD4 是 3.56:1（不合格）， 起点最亮只能到 #0378B4。质感靠「微渐变 + 顶部内高光」拿，不靠提亮。

#改哪里怎么改风险
1RemoteComputer.module.css 顶部（新增 [data-rc-root] 块） 写入本稿的 8 个 --rc-* token。零组件改动，先落地这一层不影响任何现有视觉。低
2.wbSide / .sideRail background: var(--card-bg) → 玻璃 + 顶光层；border-right 灰 → --rc-edge；补 backdrop-filter。低
3.devItem 系列 圆角 8 → 12、灰底 → --rc-glass-hard、:hover 加 accent 渐变描边与柔影；.devItemRecent 加左缘 2px 色条。低
4.miniBtnPri / .icoPri / .dangerBtn 换 --rc-cta 渐变 + --rc-cta-shadow；圆角 6 → 9。低
5徽章 .tagRecent / .tagRc / .tagTrusted / .tagDenied 实色底 → 渐变底 + 语义描边。文字色沿用现有 --green / --danger 等（对比度已验过）。低
6RcEmptyGuide.tsx emoji 🖥️ → 渐变徽标 + SVG 图标（新增 1 个内联 svg，不引 lucide 图标表）；三步块换成 .step 卡；文案一个字不改。中（组件结构变动）
7新增 .stage 容器（RcWorkbench 主区包裹层） 空闲 / 等待 / 被控三态套一层玻璃舞台；会话态不套（画面自己就是舞台）。判据沿用 workbenchMainMode，不新增状态。中

验证口径：改完按现有节奏走 tsc / vitest / lint:css；视觉侧用真实 dev 窗口截图核对，重点看三处容易踩的 —— 玻璃层叠后的文字对比度（模糊会吃掉一点对比）、圆角嵌套是否打架、以及 backdrop-filter 在深色主题下是否发灰。 深色两套主题必须各看一眼：本稿的 color-mix 写法理论上自动跟随，但深色下 70% 卡片色 + 模糊仍可能偏亮。
