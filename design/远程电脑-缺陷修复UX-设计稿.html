远程电脑 · RC 前端缺陷修复

对照现有 RC 设计语言（深色会话壳 / 浅色设置面板 / miniBtn·fb 体系）， 逐条列出 U3.5 / L2 / P2 / P3 债的交互、文案与状态。本稿是修 bug 说明，不引入新视觉体系。

U3.51 · 能力加载失败 ≠ 能力不存在

位置设置 ·「允许被远程」→ 画质档 / 画面范围（RcAllowPanel）
原状catch 把 monitors / caps 落成空，档位看起来像「本机没有高帧率能力」
状态 正在读取本机能力… 未能读取本机能力 · 重试 正常档位
文案 错误条：未能读取本机能力 / 未能读取本机显示器列表 +「重试」
降级提示：能力未知时写明 未能读取本机能力，已隐藏高帧率+/4K60；屏列表未知时 未能读取本机显示器列表，已隐藏逐屏选项

U3.52 · 剪贴板「空」与「失败」分开说

位置会话底栏 ·「拉取对方剪贴板」（RcClipboardBar）
原状对方剪贴板为空或拉取失败 一句糊两种相反事实
状态 对方剪贴板是空的 拉取失败 · 重试 已写入本机 · N 字符
文案 真空白（空串）→ 对方剪贴板是空的（info，不需要重试）
超时/失败（null）→ 拉取对方剪贴板失败 +「重试」
异常 → 原因原文 +「重试」

P23 · 码率本地保存失败要出声

位置会话底栏 · 码率下拉（RcSessionBar.pickBitrate）
原状远端已生效，本地偏好 catch(() => {}) 静默吞掉
文案本次生效，下次会话可能恢复原码率（info，走同一 onStatus 可见域）

P24 · 工具条隐藏时不可 Tab · 不再挂全局 mousemove

位置画面右上浮现工具条（RcViewTools）
原状隐藏仍可 Tab 聚焦；window.mousemove 常开（规则 8）
修法 隐藏态 visibility:hidden + 按钮 tabIndex={-1}（移出 Tab 环）
监听改挂在画面容器（stage）上，不再吃全窗口 mousemove；转场 200ms（U2）

U45 · 成功浮条 6s 自动清

位置RcSessionBar / RcFileBar / RcClipboardBar 的 fb 浮条
规则成功/信息 6s 自动清（对齐撤销条 UNDO_WINDOW_MS）；错误保留并给重试
状态 画质已同步到对方 · 6s 后消失 改档失败：… · 常驻

15.26 · 切页不丢改名草稿

位置设备详情面（RcA2DeviceDetail）的改名 / 管理展开
原状详情面随切页卸载，editingName/draftName/manageOpen 一并丢失
修法草稿态上提到不会卸载的工作台层（历史已用同一模式）；换设备才重置

157 · 重连要确认 · 有中间态 · 失败可中止

位置会话顶栏「⋯ → 重连」（RcStage / RcSessionTop）
流程 短确认（将断开与「X」的当前连接并重新发起 ·「重连」）
→ 过程 正在重连
→ end 失败则中止：结束当前会话失败，已中止重连

L28 · 文件行操作带常驻文字

位置文件传输行（RcFilePanel）FolderOpen / X / RotateCcw
原状常驻图标只有 title/aria，无可见文字（L2 违规）
修法图标 + 常驻文字，叫法与 aria/别处一致：打开所在文件夹 / 取消 / 重试
备注任务中的 RcDeviceMenu.tsx 在现网不存在；A2 设备行已是「连接/检测」文字钮，会话顶栏「更多」已有常驻文字

体量9 · RcOverlay 超限待拆

现状RcOverlay.tsx 338 行 > 300。本批未改它的行为，按纪律只在文件头注明超限待拆，不顺手重构

P310 · 光标 overlay 跟随 resize

位置rcCanvasStyle.cursorOverlayStyle + RcScreenCanvas
原状只在渲染期算定位，窗口 resize 后到下次鼠标移动才自校正
修法ResizeObserver 观察 canvas，尺寸变化即重算 overlay 坐标

视觉沿用现有 token：圆角 4/8/12 · 间距 4/8/12/16/24 · 字号 11/12/13/15/20（U5）； 语义色 --danger/--warning/--success/--accent（U6）；新样式进 CSS Module（U8）。
