待办灵动岛 · 吸附双态与精准命中 设计稿（方案 A+B 合并）

2026-09-26 · 决策：方案 A（精准命中 + 意图延时 + 贴顶）与方案 B（停靠/意图/预览双态视觉）合并实施 · 基于真实组件 TodoIsland.tsx / TodoIsland.module.css / todo_island_hover.rs / todo_island_stage.rs · 业界对标：iOS 灵动岛、NotchNook、Boring Notch、Notchy
解决两个用户抱怨：① 岛附近无法点击下层窗口（干扰操作）② 岛与顶部之间悬空 10px、没有「吸附」感，且吸附态与悬停态看起来一样。

0 · 问题归因（三句话，全部有码可查）

① 拦截范围比看得见的岛大一圈：hover 判定按「窗口矩形外扩 8px 进 / 12px 出」 （todo_island_hover.rs:38-42,111），且按矩形算——胶囊圆角外的死角、peek/list 展开态的窗口空白区都算命中。 光标离岛还有 8px 时窗口就开始拦截点击。
② 路过即触发：光标扫过顶部、本意去点下层窗口，路径穿过岛附近就立即收事件并展开 peek（300×40），恰好盖住标签栏区域。
③ 悬空 10px：TOP_MARGIN=10（todo_island.rs:75）是写死的常量；展开时顶边钉死、只向下生长（这部分保留）。

1 · 业界三共识（调研提炼）

① 命中区域 = 可见形状，不是外扩矩形——macOS 刘海系应用（NotchNook 等）用 ignoresMouseEvents 动态穿透， 命中只留在刘海可见形内（notchbay.com 的 NSWindow 技术要点）。
② hover 必须带意图——顶部悬停激活与「鼠标去顶部必经之路」天然冲突，是这类应用投诉最集中的点（koffret.com）； NotchNook 的解法是 hover 激活延时 + 可切点击激活 + 可缩小 hover 区；社区最常见的自救是干脆关 hover。 我们不砍 hover，而是把它拆成「拦截（必要，最小化）」和「展开（需停留 150ms）」两件事。
③ 吸附感 = 零间隙贴边 + 实体材质——iOS 岛永远贴死安全区边缘、无悬浮缝；不是靠阴影「浮」着。

2 · 机制设计（方案 A）：命中几何

核心一句话：拦截范围收缩到「看得见的岛」本身——判定从「窗口矩形 ± 8/12px」改为「可见形状 ± 2/6px」， 展开触发加 150ms 停留判定。拦截与展开拆开：拦截立即可保证点击可达，展开必须停留才发生。

旧：窗口矩形 + 8/12px 外扩（红色 = 会吃点击的区域）

新：可见形状 + 2px 进 / 6px 出（蓝线 = 拦截边界）

形状判定是纯几何（不读像素、不加线程）：胶囊 = 左右半圆 + 中段矩形；list/compose = 12px 圆角矩形。 在现有 60ms 轮询 step_hover 里替换判定式即可。展开（peek）触发新增停留计数： 形内连续命中 ≥3 拍（150ms）才切舞台——光标掠过岛面也只是被拦 1–2 拍（60–120ms，这是「岛本身的面积」，本来就该拦），不会展开挡住下层。

为什么不动尺寸和透明度：窗口尺寸由 Rust 逐帧驱动、CSS 不持有（module.css 文件头「分工」），停靠态再开一个小舞台等于新增一份 Rust/CSS/rgn 三处同步的账，收益低；透明度降低会让 tint 95 的对比度结论作废。所以「更实」的表达落在投影与亮线这两个纯装饰层—— 停靠态投影贴边收敛后，视觉重心自然「挂」在屏幕顶边上，与预览态的满投影浮起形成明确对比。

6 · 请拍板（三个小项）

① TOP_MARGIN：0（推荐）——岛顶与屏幕顶零间隙，吸附感最完整；胶囊上圆角与屏幕边之间的两个小三角空隙由壁纸透出， 是「贴上去」的自然观感（同 iOS 岛圆角与屏幕边的处理）。备选 4px：给 Windows 任务栏自动隐藏/贴边布局留一线余量，但吸附感打折。
② 拦截时机：形状内立即拦截（推荐）——保证「停在岛上点一下」零失败；备选「拦截也等 150ms」更激进， 但快速直扑岛点击会把第一击穿到下层窗口（丢点击是比误展开更贵的失败），不推荐。
③ 停靠态是否做「顶平方角」半胶囊形变（顶部两角 r=0、像从屏幕里长出来）：默认不做（推荐）—— 需要改 SetWindowRgn 拼新形状 + Rust 舞台加新分支，为纯装饰收益背三处同步的账不划算；想要可以二期单独出一稿。

7 · 落地清单（拍板后执行）

① todo_island_hover.rs：新增纯函数形状命中判定（胶囊/圆角矩形，无环境依赖，可单测——规则 11.1 的守卫单测钉住「死角不命中」不变量）； step_hover 换判定式 + 新滞回（2/6px）+ 停留计数（150ms / 3 拍）+ 第 3 拍 emit todo-island-intent。
② todo_island.rs：TOP_MARGIN 按拍板值改；calc_top_center_for 相应归零（公式不变）。
③ TodoIsland.module.css：停靠态投影收敛 + 顶缘亮线消隐（data-st="pill" 且非 intent/peek 时生效）； ::after glow 由 data-hover 扩为 data-hover, data-intent 双触发。
④ TodoIsland.tsx：listen todo-island-intent 写 data-intent；peek 展开 Handoff 不变（仍由 hover 事件驱动，Rust 端已延时）。
