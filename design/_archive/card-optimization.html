💡 悬停卡片查看 hover 动效差异：左侧上浮 2px + 1.008x 缩放；右侧上浮 3px + 1.01x 缩放 + 边框色变深。
🔧 具体变更清单
逐一对比每一项调整
  • 卡片高度 72px 74px — 内容呼吸感更好
  • 内边距 12px 16px 10px 16px — 上下稍紧，视觉居中更佳
  • 圆角 16px 14px — 小卡片 14px 更精致协调
  • 卡片间距 10px 8px — 紧凑但不拥挤
  • 默认阴影 0 1px 3px rgba(0,0,0,0.06) 双层：1px+2px / 1px+3px — 更自然的"浮纸"感
  • Hover 阴影 0 6px 20px rgba(0,0,0,0.1) 双层：4px+12px / 2px+4px — 更明显的抬升层次
  • Hover 位移 translateY(-2px) scale(1.008) translateY(-3px) scale(1.01) — 反馈更明显
  • Hover 边框 不变 border-color 微深 — 视觉聚焦
  • 过渡时长 0.2s 0.25s — 稍慢更优雅
  • 图标圆角 12px 10px — 与卡片 14px 形成层次
  • 图标阴影 无 0 2px 6px rgba(0,0,0,0.06) — 增加图标层次感
  • 选中态 蓝色背景 + 边框 + 外发光 + 左侧 inset 3px 蓝条 — 替代已删除的色条
  • 标题行高 1.4 1.45 — 多行文本更舒适
  • 时间颜色 --text-muted 稍亮 (#8B99B0) — 弱化次要信息
