方案 B 实现说明

  • 触发流程：右键「粘贴并变换 → 正则替换 → 选择规则」→ 弹出预览对话框 → 确认粘贴 / 复制结果
  • 预览对话框：左右分栏（原文高亮匹配 / 替换结果高亮变更），顶部可编辑正则+替换串+标志（临时调试），底部显示匹配数
  • 规则管理：独立弹窗，预设规则只能开关和编辑替换串（不可删除），自定义规则可增删改
  • 存储：localStorage key = pp_regex_rules，JSON 数组，无需后端改动
  • ReDoS 防护：正则执行包裹在 try/catch + 100ms 超时（Web Worker 或 setTimeout 中断）
  • 预设 8 条：去空行、去首尾空格、合并连续空格、移除行号、URL 解码、手机号脱敏、身份证脱敏、去 HTML 标签
  • 组件拆分：regexRules.ts（数据层）+ RegexPreviewDialog.tsx（预览）+ RegexRulesDialog.tsx（管理）
  • 懒加载：两个 Dialog 均 React.lazy 独立 chunk
