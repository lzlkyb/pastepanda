# PastePanda 项目文档 ## 简介 PastePanda 是一款**智能剪贴板管理器**，支持 Windows 10/11。 它提供了*丰富的编辑功能*和便捷的快捷键操作。 ## 功能特性 - 剪贴板历史记录与搜索 - **Markdown 实时预览**与编辑 - 图片格式转换与压缩 - CSV 表格编辑与导出 - 密钥/Token `自动脱敏` ## 代码示例 ```rust fn main() { let greeting = "Hello!"; println!("{}", greeting); } ``` ## 任务清单 - [x] 完成编辑器架构重构 - [x] 添加图片裁剪功能 - [ ] 支持多标签页编辑

交互流程：双击卡片 → 弹出小编辑器（w480，纯 textarea，无预览）→ 点右上角「放大」或底部「全屏编辑」按钮 → 进入全屏分屏编辑器（CodeMirror + 实时预览）
关闭流程：全屏 Esc → 如果小窗口有未保存修改则弹确认 → 关闭全屏回到小窗口 → 小窗口 Esc 关闭
