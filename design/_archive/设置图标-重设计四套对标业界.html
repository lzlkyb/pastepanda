设置图标 · 重设计（对标业界 + 贴 PastePanda）

先看别人怎么做，再收敛到适合我们的 4 套。共性只有一条： 图标必须「同一家族」——同一尺寸、同一圆角、同一笔画粗细、同一色相饱和度档。 之前的问题是：emoji 彩色位图 + 白圆盘 + 高饱和砖，三套语言叠在一起。

业界对照（我按产品记忆整理，非截图临摹）

  • macOS 系统设置 / iOS 设置：29–40pt 圆角方砖（圆角约 22%），实色或微渐变，白色 SF Symbol。每类一个色相，扫读极快。是「分类积木」范式的标准答案。
  • Windows 11 设置：几乎不上彩色砖，Fluent 单色线稿 + 列表行。安静、系统感，但扫读弱。
  • Linear / Notion：无砖，单色/语义色线稿，密度高，偏「专业工具」。
  • Raycast：偏好里可用浅色 tinted 底 + 单色图标，介于 macOS 与 Linear 之间。
  • Material You（Google）：同色相「浅底 + 深字」双调，六主题好迁，对比度可算。
对 PastePanda 的判断： 产品是剪贴板/效率工具，设置行很多、要扫得快；同时有 blossom/dawn 等活泼主题，不能做成 Win11 那种纯灰。 所以：需要「有色瓷砖」提高扫读，但字形必须是同一家族的矢量线稿（与主窗 lucide 一致）， 不要再用彩色 emoji 位图。emoji 和瓷砖抢颜色，是上一轮看不清的根因。

怎么选

D 果冻砖（推荐）— 要「设置页一眼扫得动」且有点产品个性。与主窗 lucide 同语言，emoji 问题彻底消失。

B 双调 — 要更安静、更「专业软件」，接受扫读弱一点。

A — 就要最标准的 macOS 设置感（和 D 几乎同族，D 只是圆角/渐变更 PastePanda）。

C — 极简密度流，一般不建议用在设置这种「找开关」场景。

四套共用同一套 8 语义色相与 lucide 图标表；落地时只换 --ic-* 与 .sRowIcon 皮肤，调用点 hue 不用再动。
