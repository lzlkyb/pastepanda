PastePanda 项目文档

简介

PastePanda 是一款智能剪贴板管理器，支持 Windows 10/11。它提供了丰富的编辑功能和便捷的快捷键操作。

功能特性

  • 剪贴板历史记录与搜索
  • Markdown 实时预览与编辑
  • 图片格式转换与压缩
  • CSV 表格编辑与导出
  • 密钥/Token 自动脱敏

代码示例

fn main() {
    let greeting = "Hello, PastePanda!";
    println!("{}", greeting);
}

快捷键

按 Ctrl+Shift+K 进入栈模式，Ctrl+Shift+P 逐条粘贴。
