玻璃档位：四张 chip → 一根滑杆（方案 A）

2026-09-26。目标：岛体遮盖度可自定义连续调节，只设下限不设档位。本页的滑杆是真能拖的，公式与将要写进代码的完全一致 —— 拖到底看高光收没收、描边还在不在，就是在验 CSS。

§3 「深色」档不再需要特例：高光与描边由数值派生

现款 dark 档相对 steady 多改了两样（TodoIsland.module.css:124-128）：gloss .07→.02、rim .09→.07。把它做成线性派生，滑到 92 就自动等于原 dark 档，不需要开关：

/* 唯一由设置驱动的数（挂在 html，探针可从外部覆写 --island-tint，机制不变）*/
--island-glass: 78;

/* 深色材质：tint 直接吃数值 */
--island-tint:  rgb(20 20 24 / calc(var(--island-glass) * 1%));
/* gloss/rim 过 78→.07/.09、92→.02/.07 两点定线，两端 clamp 在现款取值域内 */
--island-gloss: rgb(255 255 255 / clamp(0.02, calc(0.348 - var(--island-glass) * 0.00357), 0.07));
--island-rim:   rgb(255 255 255 / clamp(0.05, calc(0.2015 - var(--island-glass) * 0.00143), 0.09));

/* 浅色主题只覆写 tint 的基色，gloss/rim 维持现款定值（.55/.85，浅玻璃上另有一套论证） */
html[data-island-mode="light"] { --island-tint: rgb(255 255 255 / calc(var(--island-glass) * 1%)); }
vtint αgloss αrim α对应现款

20–78 段 gloss/rim 被 clamp 顶住 = 恒为现款厚磨砂的取值，只有 tint 在变；78 以上才开始收高光。这与「越实越哑光」的直觉一致，也不会让最透档的高光过曝。

§4 数据流：拖动不落盘

拖动中（每帧）
  设置页 range.onChange
    ├─ 本地 state → 预览胶囊 + 读数（同窗口，即时）
    └─ emit("todo-island-glass-preview", v)   ← 新事件，只带数值
         岛前端 listen → html.style.setProperty("--island-glass", v)
         Rust 不听这个事件 ⇒ 不触发 show()/hide() 门控、不读盘

松手（onChange 走 onPointerUp / onKeyUp）
  updateAndSave({ todo_island_glass: v })  → save_config（一次）
  emit("todo-island-config-changed")       → Rust 门控 + 岛前端重读配置（现有通路，不动）
为什么不能边拖边存：save_config 每次调用都会 backup_config() 把全量配置明文写一份到 config_backups/ 并轮转保留 10 份（src-tauri/src/data_store/config.rs:446）。一次拖动几十帧 = 几十次全量明文落盘。
已知代价：拖动中途切走窗口或崩溃，岛上的预览值不落盘，下次启动回到旧值。这是「不写盘」的必然结果。

两处与 §4 设计稿的有意偏差：

  • 预览胶囊的文字色不随数值翻面（设计稿 paint() 在 v<45 换深色字）。真实岛面只有主题决定的 --island-fg 一档，预览若跟着翻，等于演示一个岛上并不存在的行为——低遮盖度 + 亮桌面下文字偏虚，与原 clear 档 2.81:1 是同一个已记录的已知代价。
  • 端点标签字号从设计稿的 10.5px 归到 11px（U5font 五档），预览条内边距 10px → 8px、胶囊 5px → 4px（U5space）。

能力回退（需用户确认是否补）：原 dark 档「恒深色、不跟主题极性」随四档一起删掉了——浅色主题下现在拿不到深色岛，只能把滑杆推到 92 附近近似。要保留得另加一个「强制深色岛」开关，不在这次范围。
