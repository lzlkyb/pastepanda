§6 交互规则（实施约束，全部可判定）

规则约定
常驻可见（规则 15）胶囊条任何折叠态下都在；文件请求 / 变更提示到达 → 橙点 + 自动展开抽屉一次；用户手动收起后至少保留橙点徽标
展开 / 收起点胶囊整条切换；Esc / 点外部收起；结束键 stopPropagation 不随整条触发
危险动作「立即结束」保持现有 confirmDialog 守卫；「开启免确认」保持 U9 行内二段确认
窄窗（320px）胶囊内 .who 独占压缩（overflow-wrap），pill/时长/图标 flex-shrink:0——沿用 09-22 崩坏修复的压缩模型
无障碍胶囊 role=button aria-expanded；live region 只包状态变化不包计时器（C5 现状保留）
删除物RcInboundView 中央卡片删除（事实并入抽屉）；RcControlBanner 三段式结构废弃；工作台被控分支改为一行指引「会话详情见顶部胶囊」
顺手修右上角竖排「关闭」tooltip 常驻：tooltip 容器加 min-width + white-space:nowrap（独立小修）
