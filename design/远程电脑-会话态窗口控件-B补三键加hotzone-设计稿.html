B 的风险与打点（相对 A 多出的）

① 指针锁边界：锁定指针模式下鼠标被 Pointer Lock 捕获，移不到顶边热区 → hotbar 唤不出。 对策（实施时定）：锁定态在 Esc 解锁提示旁加「解锁后可呼出控制条」提示；或锁定态改由 viewTools 保留退出全屏入口（A 的做法兜底）。
② 热区误触：远程画面顶部 8px 属于「吃掉远程点击」的区域——viewTools 当年浮现式改造（2026-09-19 误触排查）正是为这个。 对策：热区仅在「非锁定指针」时激活；8px 极窄，误入成本天然低。
③ 与全屏 API 的层级：hotbar 必须在 fakeScreen 子树内（Fullscreen API 只显示该子树）——实施时挂进 RcSessionStage 的 fakeScreen 容器，不是 body 级浮层。
④ 工作量：A ≈ 40 行 2 文件；B ≈ 160 行 3 文件（+1 组件 + 测试）。B 含 A。
