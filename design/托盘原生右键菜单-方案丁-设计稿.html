托盘原生右键菜单 — 方案丁设计稿

目标：根治「右键托盘，弹窗整体显示不出」。放弃自绘 WebView 弹窗（tray-popup），改用 Tauri/muda 原生菜单， 由系统 TrackPopupMenu 渲染 —— OS 菜单永远显示得出、零常驻内存、自动跟随系统亮暗与 DPI。 左键行为不变（显隐主窗口，U54 双击去抖照旧）。

2. 与现自绘弹窗的能力对照

现弹窗能力原生菜单去向说明
最近复制 3 条 · 点击即贴✅ 平铺菜单项标题 = 「粘贴：」+ 截断文本（≤40 字符，超出省略号）；文本取当前值，悬停（Enter/Move 事件）时经 run_on_main_thread 就地 set_title 刷新，点击时永远新鲜
图片记录的缩略图⚠️ 降级为 16px 图标muda MenuItem::set_icon；Windows 菜单图标固定走 SM_CXSMICON（100% 缩放下 16px，随 DPI 缩放），做不了大图预览。图片项显示「[图片] W×H」文字 + 缩略图图标（内存里现成的缩略图缩到 16px）
暂停/恢复监听✅ 双态菜单项沿用现文案切换（比勾选框直观）；set_title 动态改
显示主窗口 / 设置 / 退出 / 贴图管理 / 调整浮标 / 连接设备✅ 一一对应逻辑不变，只是触发方从前端按钮改为 on_menu_event 路由到同一批命令。条件块（rc 可连、浮标开）语义照搬：不满足就整项不出现，禁用占位则 set_enabled(false) + 原因写进标题
存储统计 + 内存条❌ 移除原生菜单塞信息条很怪（Ditto/微信都不这么做）。数据都在设置页看；这是本方案唯一的真删项
自绘视觉（玻璃、彩色图标、红色「退出」）❌ 换系统观感收益：自动跟随 Win11 Mica/亮暗/字号/DPI，任何机器都渲染得出。「退出」无红色 → 建议加一次性确认（范式 §17 两级取消），待定
键盘 ↑↓ / Esc✅ 系统自带删掉自装的 TrayPopup.tsx 方向键导航与全局 mousedown 收起

3. 反馈可见性域（规则 15 的落点）

菜单点击后 OS 立刻关闭菜单 —— 弹窗时代「在弹窗里 showToast」的反馈没有承载体了。方案： 粘贴成功/失败改用托盘图标角标闪烁：复用 set_tray_stack_mode（tray_manager.rs:636）已验证的 「合成橙点覆盖图 → set_icon」机制，成功=绿点 600ms 后还原、失败=红点 1.5s 后还原（防连点互相覆盖：还原前比对当前应显态）。 这条路径常驻可见、不依赖任何窗口，正好满足 15.1「触发与反馈同可见性域」。 连接设备/退出等有独立窗口的动作，反馈跟着那些窗口走，不受影响。

4. 实施要点（确认后落地）

增：setup_tray 里 MenuBuilder 静态建骨架（含条件占位），.menu(&menu) 挂到 TrayIconBuilder；on_menu_event 按 id 路由到现有命令（show_main_window / toggle_monitor / open_pinned_panel / stack_hud_adjust / emit_tray_open_settings / exit_app / do_paste(托盘路径, 位置 -1) / rc_connect）。 动态化：Enter/Move 回调里 run_on_main_thread 调 set_title/set_enabled/setVisible 刷新最近 3 条与双态文案 （纯判断部分抽函数单测，按规则 11.1 收口「该显示什么」为单一数据源，新增守卫单测钉住 rc/hud/monitoring 三条件）。
删：show_tray_popup 全函数 + POPUP_REBUILDING + 失焦监听线程 + set_dwm_round_corners 的弹窗用途； src/popup-main.tsx、TrayPopup.tsx、popup.html；capabilities 中 tray-popup 窗口授权； 命令 get_tray_popup_data/hide_tray_popup 若无他用以编译器引用为准删除。
保留不动：左键显隐主窗口（U54 去抖）、托盘 tooltip、栈模式橙点、monitoring 图标状态机。
验证：单测=菜单可见性纯函数守卫；实机=右键必出菜单、连点 5 次无卡死、4K150% DPI、Win10/Win11、亮暗系统主题、 无最近记录静默态、隐藏图标溢出面板里右键。
Android：无托盘，#[cfg(desktop)] 边界照旧，不触碰 mobile 占位实现。

6. 拍板与实施补记（2026-10-03，已落地）

总决策（推翻 §4 的「删」）：自绘弹窗不删——默认切原生菜单，设置页「系统与编辑 → 托盘右键菜单」可切回自绘弹窗。 config 键 tray_menu_style，口径同栈浮标：只有显式 "popup" 才走自绘，缺键/脏值一律原生（tray_menu::native_or_default）。
§5 三点按推荐口径落地：① 平铺（变体 A）；② 退出不加确认（与现状一致）；③ 采纳角标闪烁（绿 600ms / 红 1.5s，FLASH_EPOCH 计数防连点覆盖）。
与稿子的偏差（有意为之）：
· 图片缩略图 16px 图标（§2）改为标题前缀 emoji（🖼/📁）——省掉图标转码管线，观感在原生菜单里够用；
· 敏感内容且主窗口隐藏时，粘贴桥先 show_main_window 唤出主窗再进脱敏确认条（否则会挂起在看不见的模态上）；
· 「暂停/恢复监听」的反馈走 tooltip 后缀（「— 监听已暂停」），不占角标；角标只服务粘贴/浮标调整失败；
· 存储统计条与内存条仅在原生模式不存在，弹窗模式原样保留。
弹窗路径小加固：show_tray_popup 的固定 sleep(80ms) 改为轮询销毁（≤300ms）， build() 失败时兜底复用仍在的旧窗口（刷新定位 + 重推数据 + show）。
分工收口（规则 11.1）：菜单摆不摆由 Rust 纯函数 plan_items(snapshot) 决定（6 条守卫单测钉住）； 粘贴与远程连接经 tray-menu-paste/tray-menu-rc-connect 事件交回前端唯一分派 pasteHistoryItem，Rust 不抄第二份。
