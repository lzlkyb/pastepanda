实现要点（基于真实代码）
  • 入口：screenshot-main.tsx 与 longshot-main.tsx 删除 applyTheme("midnight")，改照 popup-main.tsx 模式：applyTheme(DEFAULT_THEME) → invoke("get_config") 读主题 → listen("theme-changed") 实时跟随（截图窗与托盘弹窗共用 default capability，权限已具备，纯前端改动）。
  • 令牌：6 套主题各补一组 --shot-* 变量（放 theme.css 各主题块内，单一数据源，规则 11）；screenshot.css 删除硬编码色、全部改为 var(--shot-*) / 现有主题令牌。
  • 对比度红线：所有「白字实色底」走 --accent-solid（6 套主题全部 4.5:1 校验过）；浅色玻璃上的次要文字走 --text-muted 的浅色档；出口语义色（粉/薄荷/蓝）在浅色主题换深色档保证 4.5:1。
  • AI 渐变 hack：.annot-toolbar { --brand-ai-from/to: … } 重绑删除（原注释里「浅色主题下压深底看不见」的前提不再成立）。
  • 遮罩 / 选区框 / 文字输入框底板保持功能语义：遮罩深色压暗、选区框 var(--accent)、输入框半透明底 + 对比描边 —— 这些是与「底图内容」交互的层，不跟主题（微信/QQ 同理）。
  • 测试：新增 theme-changed 跟随与令牌映射的守卫测试；现有截图几何/布局测试不受影响（只动颜色不动坐标）。
设计稿仅示意颜色与结构；实际尺寸 / 间距 / 圆角以 screenshot.css 为准。改后观感以 dev 实测为准。
