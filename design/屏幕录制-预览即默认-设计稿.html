4

录制中:红框脉动 + 可拖动控制条,画面零遮挡

进入录制后:选区描边从主题色换成红色(--danger 语义色)呼吸脉动——与截图蓝色框明确区分「这回是真在录」; 录制区内没有任何常驻遮罩,被录画面 1:1 可见。控制条默认吸附在选区上缘外,可整体拖动(抓手手柄), 条外区域 pointer-events 全穿透,不挡任何操作(§18 P3 / §17.7 状态单一)。 控制条只保留三个元素:REC 脉动点 + 计时(等宽数字)+ 停止;档位以只读徽标展示(录制中不可改)。 停止后写文件收尾(约 1~2 秒)期间控制条变「正在写入…」转圈,完成后 toast。

与远程会话并行的说明
· 录屏走独立的捕获与编码器实例,与远控推流互不复用状态,可同时开。
· 启动时探测硬编会话余量;GPU 编码器不可用时,开始前就报「没有可用的硬件编码器」, 不许出现「录完了才发现文件是空的」。
· 录制中收主窗 / 锁屏 / 休眠:安全路径——立即落盘停止 + toast 说明, 不静默丢帧。
· CPU / GPU 开销数值待实测后再写进文案,不预设「开销极小」。

首版范围与非目标

首版做 全屏 + 框选区域 · MP4 封装(H.264 兼容档 / HEVC 高效档自动降级)· 四档画质(原画/高清/标准/流畅)· 系统声音 + 麦克风双音轨(独立开关)· 热键 + 工具箱 + 托盘入口 · 3 秒倒计时 · 完成 toast 直达文件
首版不做 单窗口捕获(WGC 路线,后续加)· 暂停/续录 · 录制中改档 · 摄像头画中画 · 剪辑 · 帧15/24 档 · WebM/AV1
复用 远控的 DXGI Desktop Duplication 抓帧(GPU 零拷贝)、WASAPI 环回 + MF AAC 音频轨、 硬编探测降级链(MF → nvenc/qsv/amf);新增 MF SinkWriter 写 MP4 + 一条不经网络的本地采集循环
已知取舍 编码参数录制开始时定死(录中改档不做);倒计时 3 秒不可配; 硬编不可用时报错而非软编兜底(软编 4K60 CPU 扛不住,不做假可用)
