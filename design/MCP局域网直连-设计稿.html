MCP 局域网直连 · 设置页设计稿

位置：设置 → MCP → 高级折叠内，HTTPS 之后、写权限之前。默认关。

一句话：打开后，同一端口额外接受局域网连接；远程机填 http://<本机局域网IP>:17650/mcp + 同一枚 Bearer 令牌。 本机客户端仍走 127.0.0.1，互不影响。

1. 安全模型（改后的门禁）

门本机请求局域网请求
IP 白名单回环直接过必须命中白名单（IP 或 CIDR），否则 403
Origin只放行本机 origin有 Origin 仍只认本机（防同事机网页）
Hostlocalhost / 127.0.0.1 / ::1额外放行本机真实网卡 IP
Bearer 令牌必填必填（不变）
写权限与本机共用现有 8 档开关（默认全开，可逐项关）

配置键：mcp_lan_enabled · mcp_lan_allowlist（字符串数组）

2. 关态（默认）

监听中 · 端口 17650
高级：端口 · 令牌 · HTTPS · 写权限 · 调用记录
局域网访问
允许局域网 关闭 · 仅本机 127.0.0.1 可连接

3. 开启确认框（每次开都弹，同 MCP 总开关策略）

允许局域网访问知识库 MCP？

打开后，白名单内的局域网机器可以用与本机相同的权限读写你的笔记。

  • 仍需访问令牌；令牌在局域网内以明文 HTTP 传输
  • 白名单至少填一条 IP 或网段（如 10.203.5.99 / 10.203.5.0/24）
  • 写权限走下方 8 档开关，与本机同一套
  • 删除仍只进回收站；写入计入调用记录

⚠ 能连上的机器可读你全部笔记。请只放行你信任的设备。

4. 开态（配置齐全）

监听中 · 端口 17650 · 局域网已开
高级：端口 · 令牌 · HTTPS · 写权限 · 调用记录
局域网访问
允许局域网 已开启 · 白名单 2 条
本机地址 http://10.203.5.48:17650/mcp 自动探测首个非回环 IPv4；多网卡时下列出全部
IP 白名单
每行一条：精确 IP 或 CIDR。保存后立即生效，无需重启。

5. 异常态（必须就地可见，规则 #15.3）

白名单为空却开着
允许局域网
⚠ 白名单为空，当前没有任何局域网机器能连上。请添加 IP 或网段，或关闭开关。
bind 失败（端口/权限）
允许局域网 配置已开，但未能监听局域网
✕ 无法绑定 0.0.0.0:17650：权限不足或被占用。本机 127.0.0.1 服务不受影响。

6. 远程客户端配置示例（复制卡片）

{
  "mcpServers": {
    "pastepanda": {
      "type": "http",
      "url": "http://10.203.5.48:17650/mcp",
      "headers": {
        "Authorization": "Bearer <你的访问令牌>"
      }
    }
  }
}

令牌不在 status 轮询里返回；复制卡片时由「需要令牌」路径按需取一次。

7. 实现落点

  • mcp/mod.rs：配置键常量
  • mcp/server.rs：按开关选择 bind 127.0.0.1 / 0.0.0.0；McpStatus 增加 lan 字段
  • mcp/auth.rs：CIDR 白名单匹配；Host 放行本机网卡 IP；ConnectInfo 取对端 IP
  • commands/mcp.rs：开关 / 白名单保存 / 状态
  • 前端 McpLanPanel.tsx（新，<300 行）挂进 McpServerPanel
  • 测试：CIDR 匹配纯函数 + 过线 HTTP（假对端难做时至少测 auth 单元）
