结论：拖选模型完全一致，唯一实质差距是「字级精度来源」

  • 一致：拖拽选字、实时高亮、单击整行、Esc 取消、非模态——交互心智与微信相同。
  • 差距：微信字级来自后端字符级 box（腾讯优图）；我们后端 images.rs:451 仅行级，字级靠前端等距切分近似。
  • 中英混排 / 比例字体下，等距切分的"边缘字"会误纳或漏纳——属体验级近似，与 QQ 同级、用户可接受。
  • 要对齐微信真·字级：后端 OCR 须输出字符级坐标（改 PP-OCRv6 离线封装或加 char detector，风险较高）。否则接受近似即可。
  • 观感补强：鼠标落在文字上方变 I 形光标（微信同款），纳入 P1。

二、目标交互（微信式拖选）

拖选橡皮筋（rubber-band）

  • 标注态 OCR 就绪后，鼠标落在文字区域按下拖拽 → 起手画半透明青框（橡皮筋）。
  • 实时高亮命中文字（indigo 填充），松手 → 选中文本 + 浮「复制 ✓」条（不挡底图）。
  • 单击某行（<4px 位移）→ 复制整行（保留现状 copyRow）。
  • 双击 → 选中整行（同单击但视觉强提示）。
  • Esc → 取消当前选择（两级取消，回到文字层）。

精确到字（前端切分）

  • 对命中 word 的 box，按 text.chars().count() 等距切分宽度 → 生成"伪字级"命中单元。
  • 第 k 字 box ≈ (x + k·w/N, y, w/N, h)；橡皮筋与字框重叠即纳入。
  • 输出：按纳入字符 index 升序取 word.text 子串（用 char_indices 防 emoji/组合字符截断）。
  • 中英混排字宽不均 → 仅作"拖选体验"近似，与微信/QQ 同级，不追求像素级。
示意图：word box 内按字符数等距切分，橡皮筋拖选命中中间 4 个字符 → 复制「0000」（sub-word 精度）

三、Before / After（标注态）

Before（当前）

  • 标注态 ocr-line 为 inert，图上文字点了没反应。
  • 要选字 → 进结果态面板 或 Ctrl+R 抽屉（滑入挡图）。
  • 只能整行复制，无法选其中几个字。
  • 拖拽 = 画标注/移动选区，文字"选不中"。

After（目标）

  • 标注态文字层已激活：落字上拖拽 = 橡皮筋选字。
  • 选中即高亮 + 浮「复制 ✓」条，不挡底图（P3）。
  • 可精确到字：拖选命中 sub-word 子串。
  • 单击=复制整行；Esc=取消选择（P4 两级）。

四、实现要点（纯前端，无 Rust 改动）

  • 1. 前置依赖（⑤ 基础）：先去掉 ScreenshotOverlay.tsx:3176 的 inert 三元，让标注态 ocr-line 可交互（已在 ⑤ 稿规划，未改码）。
  • 2. 新增状态：textSel（选中的 {li,wi,charStart,charEnd}[] 或拼接文本）、textDragRef（橡皮筋进行中）。
  • 3. 触发策略（不抢其它交互）：仅在 phase==="annotate" && ocr 就绪 时，指针落在某 ocr-line 命中区内 onMouseDown 起手 → stopPropagation，不走标注绘制/选区拖移；空白区拖拽 = 现有行为不变。
  • 4. 命中算法：复用 rectsOverlap 选相交 word；再对每个命中 word 做字级切分，纳入橡皮筋 rect 内的字符（见第二节）。阅读顺序：按行升序 → 同行 word 升序 → word 内 char 升序 拼文本，行间补 \n。
  • 5. 复制浮条：松手若有选中 → copyText(sel)（复用 copyRow 的复制通道）+ 浮「已复制 N 字 ✓」条（2 秒淡出）；空选 → 视为单击（复制整行，保留现状）。
  • 6. 坐标：所有框用 css()=v/dpr 换算渲染（与现有标注/选区同坐标系）；OCR word box 已是屏幕物理像素，直接复用 css(w.x) 等（同 ocr-line 现有渲染）。

六、风险与守门（claude.md 第 18 条）

守门红线：① 文字层是轻覆盖，复制浮条不得挡底图（P3）；② 一键可推翻——Esc/点击空白即取消（P4）；③ 选字不污染截图产出（只复制文本，不画标注）。
已知风险：中英混排字宽不均导致"边缘字"误纳/漏纳（近似可接受，必要时按字符视觉宽度加权切分）；性能上 OCR 行数多时需节流橡皮筋重算（requestAnimationFrame 限帧）；与自动打码预览（橙色框）同屏时需视觉区分（选中=indigo，打码=amber）。

七、与既有功能关系

  • 本文是 ⑤「选区即文字层」的深化：⑤ 去掉 inert 是基础，本稿在 ⑤ 之上加拖选 + 字级。
  • 自动打码预览（③）遮住的行：isRowMasked 已不渲染其 ocr-line，故选字层天然跳过隐私行，不泄漏。
