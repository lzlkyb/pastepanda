现状：全屏选区几乎无反馈

悬停桌面 → 选区=全屏 → 4 块蒙版尺寸全部为 0（零暗化）；选区框贴屏幕边缘（1px 白边几乎看不见）；底部提示条老用户已退休。屏幕上没有任何"截图模式"痕迹。

方案：四边暗带 + 强边框，一眼看出在截图

全屏选区时屏幕四周出现一圈 5px 暗带（与选区外蒙版同色系），选区框加粗 + 蓝色外发光，尺寸标签带"全屏"字样。与普通桌面形成明确边界。

改动明细（全部为纯前端 CSS/JSX，零后端）

打开瞬间暗层rgba(10,14,24,0.4) → 0.5 + animation: shadeIn .15s ease-out（ScreenshotOverlay.tsx:3885 无选区分支）
全屏判定w ≥ sw×0.98 && h ≥ sh×0.98（物理像素，含 1-2px DWM 阴影扩展的容差）
四边暗带全屏时渲染 4 个 .edge-band（各 5px，rgba(10,14,24,0.5)），替代 0 尺寸的 4 块蒙版
