# 远程电脑工作台 · 视觉设计规范 v1

> 基准稿：`design/远程电脑-质感重做-设计稿.html`（已选定方向）。
> 本文档把该稿固化为可实现的设计 token 与组件规则，供 `src/components/rc/` 落地与后续回归对照。
> 所有颜色对比度均按 WCAG 2.1 相对亮度公式实测，非估算。

---

## 1. 设计定位与原则

产品气质：**冷静的远控工具台**——像一台擦得干净的仪表台，玻璃与冷色金属感，不炫技、不霓虹。

四条原则：

1. **一块深色画布定调**：整个工作台唯一的大面积深色区域就是远程画面区，其他一切保持浅色玻璃。深浅对比本身就是信息——「亮处是控制台，暗处是对端屏幕」。
2. **状态永远双色冗余**：任何状态（在线/最近/离线、可控/只看、开/关）必须同时用「颜色 + 文字或形状」表达，禁止只靠色相区分。
3. **动效只回答动作**：hover 底色差分、菜单弹出 120ms、失败回滚抖动，只此三类。无页面级入场动画。
4. **玻璃分两级，不叠加**：hard（卡片级）与 soft（条带级）两级毛玻璃，同屏最多各一层，禁止玻璃套玻璃。

## 2. 布局系统

窗口 1200×780（`rc.rs` 工作台默认尺寸），最小高 640。

```
┌──────────────────────────────────────────────────────┐
│ 顶栏 44px：标题「远程电脑」+ 通道状态 pill + 关闭        │
├──────────────┬───────────────────────────────────────┤
│ 侧栏 272px   │  主区（随状态切换）                     │
│ 本机卡片     │  · 空态引导（图标+三步+主按钮）          │
│ 一次性协助   │  · 设备空列（侧栏已有摘要）              │
│ 设备列表     │  · 会话视图（画面区 + 会话条）           │
│ 配对按钮     │    画面区 flex:1，深色画布              │
├──────────────┴───────────────────────────────────────┤
│ 底部：本机画质条（仅非会话态）                          │
└──────────────────────────────────────────────────────┘
```

- **间距阶**：4 / 6 / 8 / 10 / 12 / 16 / 24。设备行内 gap 10，列表行间 gap 6，区块间 gap 12–16。
- **圆角阶**：6（按钮/输入框）、8（设备行/菜单）、10（卡片/空态框）、12（会话条/横幅）、999（pill/徽章）。同一层级的元素共用同一档，禁止混用。
- **边框**：常态 1px 透明占位（保高度），hover/focus 换 `--rc-line-strong`。彩色边框只用于语义告警（`noteWarn` 左侧 3px）。

## 3. 配色方案

### 3.1 基础面（浅色，接全局主题变量）

| Token | 值 | 用途 |
|---|---|---|
| `--rc-bg` | `var(--app-bg)` ≈ #F4F8FC | 窗口底 |
| `--rc-surface` | `var(--card-bg)` ≈ #FFFFFF | 常规卡片 |
| `--rc-glass-hard` | rgba(255,255,255,.88) + backdrop-blur 14px | 侧栏卡片、顶栏 |
| `--rc-glass-soft` | rgba(255,255,255,.66) + backdrop-blur 10px | 会话条、工具浮条 |
| `--rc-line` | #E2E9F2 | 分隔线/描边 |
| `--rc-line-strong` | rgba(2,132,199,.35) | hover/focus 描边 |

### 3.2 文字层级（浅色，对比度已实测）

| Token | 值 | 对比度(白底) | 用途 | 最小字号 |
|---|---|---|---|---|
| `--rc-ink` | `var(--text, #0F172A)` | 16.9:1 | 标题、设备名 | 12.5px |
| `--rc-ink-2` | `var(--text-secondary, #495565)` | 8.6:1 | 正文、说明 | 11px |
| `--rc-ink-3` | `var(--text-muted, #627083)` | 4.56:1 | meta、时间戳 | 11px |
| `--rc-ink-4` | #627083 @ 11px only | 4.56:1 | 兜底，不得再淡 | 11px |

🔴 **禁用色**：`#7C8CA0`（3.43:1）、`#6E8095`（4.05:1）出现在质感稿的部分次级文字里，落地时一律替换为 `--rc-ink-3`。新代码不得引入低于 4.5:1 的前景色。

### 3.3 强调与语义

| Token | 值 | 对比度 | 用途 |
|---|---|---|---|
| `--rc-accent` | `var(--accent, #0284C7)` | 4.7:1(白底) | 主按钮、焦点环、链接 |
| `--rc-cyan` | #06B6D4 | 仅装饰渐变，不作文字色 | accent 渐变终点 |
| `--rc-ok` | #15803D | 4.9:1 | 成功态文字 |
| `--rc-warn` | #B45309 | 5.0:1 | 「最近」点、告警文字（图标点用 #D97706，3.19:1 达图形 3:1） |
| `--rc-danger` | `var(--danger, #D64545)` | 文字用 #B42323（5.4:1），底色可用 #D64545 | 结束/禁止 |
| `--rc-pill-on-fg` | #0369A1 on #DCF2FE | 5.1:1 | 选中 pill 文字 |

### 3.4 深色画布区（远程画面）

| Token | 值 | 对比度 | 用途 |
|---|---|---|---|
| 画布底 | 渐变 #1A2332 → #0F141C | — | 画面区背景 |
| `--rc-hud-fg` | #C7D6E8 on rgba(9,17,28,.62) | 12.7:1 | HUD 芯片文字 |
| `--rc-hud-fg-dim` | #7E93A8 同底 | 5.9:1 | HUD 次级文字 |
| 工具图标 | #A8BACD（未激活）/ #FFFFFF（激活） | 9.4:1 | 浮动工具条 |
| 键盘捕获描边 | inset 0 0 0 2px `--accent` | — | fakeScreenKb |

## 4. 字体排印

单一字族，系统栈：`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`；数据（IP、指纹、时长、fps）用 `ui-monospace, "Cascadia Code", Consolas, monospace`。

| 级别 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| 标题 | 15px/1.4 | 600 | 窗口标题、区块标题 |
| 设备名 | 12.5px/1.4 | 600 | 列表主文字 |
| 正文 | 12.5px/1.6 | 400 | 说明、空态文案 |
| 次级 | 12px/1.5 | 400 | 菜单项、输入框 |
| meta | 11px/1.5 | 400 | 时间戳、提示、按钮文字 |
| HUD | 10.5px/1.4 | 500 | 画面浮层芯片（唯一允许 <11px 的场景） |

- 字重只用三档：600 / 500 / 400。不用全大写标签，不用字距拉开做层级。
- 按钮文字与正文同字号（11px），**不缩**——按钮小字是可读性问题高发区。
- 🔴 字号纪律：10.5px 仅限深色 HUD 芯片；浅色区任何文字 ≥11px。当前 CSS 中 6 处 10/10.5px 需在落地时清理。

## 5. 组件视觉风格

### 5.1 按钮

| 类 | 高度 | 样式 |
|---|---|---|
| `miniBtnPri` | 24px | `--rc-accent` 底、白字、radius 6 |
| `miniBtn` | 24px | 白/玻璃底、1px `--rc-line`、文字 `--rc-ink-2` |
| `dangerBtn` | 24px | #D64545 10% 底 + #B42323 文字 + 1px 35% 描边 |
| `icoBtn` | 26×26 | 透明底，hover 出底色差分；**必须 aria-label + title 成对** |

按下反馈统一 `transform: translateY(0.5px)`，80ms。禁用态：opacity .45 + cursor not-allowed，**不改文字色**（保对比度）。

### 5.2 设备行（devItem）

常态无边框浅卡；hover 换 `--rc-glass-hard` + `--rc-line-strong` 描边；「上次」行以 4% accent 底色差分表达（不叠彩框）。头像 26px，纯函数取色、深色文字（≥7:1）。徽章（上次/同步/远程/已禁止/免确认）全部 10.5→11px pill，语义色底 ≤10% 透明度。

### 5.3 pill 选择组（画质/画面）

高 24px，选中 `#DCF2FE` 底 + `#0369A1` 字，未选透明底 + `--rc-ink-2` 字；选中态**必须** `aria-pressed`。两组之间用 8px 间距 + `画面`/`画质` 小标签分隔。

### 5.4 开关

44×26 轨道，`role="switch"` + `aria-checked`，轨道内嵌「开/关」文字（SC 1.4.1 不依赖颜色），thumb 220ms ease-out。

### 5.5 横幅（RcOverlay / 被控条）

高 40px 通栏，被控中：#D64545 10% 底 + 左缘 3px 实色；live region 只包状态短语，计时器移出。出站会话横幅同构、accent 色。

### 5.6 会话底栏

`--rc-glass-soft`，高 40px，含两个 RcDropdown（画质/画面）、键盘捕获徽章、剪贴板开关、连接状态文字（10.5→11px）。下拉向上弹，弹层 radius 8 + 阴影 `0 8px 24px rgba(15,23,42,.14)`。

### 5.7 空态

虚线框 `--rc-line` + `--rc-surface` 底，中心图标（lucide，24px，`--rc-ink-3`）+ 一句标题（600）+ 一句说明（400）+ 一个主按钮。三步引导用数字列表（内容真是序列，允许编号）。

### 5.8 焦点态

全局零特异性规则已兜底：`:focus-visible` → `outline: 2px solid var(--accent); outline-offset: 2px`。rc 模块内**禁止**任何 `outline: none` 不带替代；`.fakeScreen` 的键盘捕获描边（inset 2px accent）即其焦点指示，属例外并已验证。

## 6. 动效

| 场景 | 时长/曲线 |
|---|---|
| hover 底色差分 | 100ms ease-out |
| 菜单/下拉弹出 | 120ms ease-out + 2px 上移入场 |
| 开关 thumb | 220ms ease-out |
| 失败回滚 | 原地 1 次 2px 抖动，160ms |
| 加载 | Loader2 旋转 1s linear |

`prefers-reduced-motion: reduce` 时仅保留透明度过渡，去掉位移与抖动。
