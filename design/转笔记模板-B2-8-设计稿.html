2 · 变量表

占位符值备注
{{content}}按类型抽出的正文就是不套模板时的那个正文（CSV 已转成 Markdown 表格）
{{title}}按首行抽出的标题只能读，模板改不了标题本身（见 §3）
{{origin}}来自 Chrome · 2026-09-01 14:32没来源时只写时间，不留「来自 」尾巴
{{source}}来源应用名可能为空
{{time}} / {{date}}完整时间 / 仅日期采集时间，不是转笔记的时间
{{content_type}}中文标签（「代码」而不是 code）它是写给人看的，内部值在正文里没意义
{{tags}}标签名，逗号分隔无标签为空串
{{ocr}}图片的 OCR 文本非图片为空串。图片卡片的 {{content}} 本来就是 OCR，这个是给「既要原文又要引用 OCR」用的

3 · 交互细则（都已写进实现并钉了用例）

  • 留空 = 不套，而不是套出一篇空笔记。这是默认值，也是向后兼容的保证—— 加了这个功能不能改变没配过模板的人的转笔记结果。示例模板只能靠「填入示例」按钮进去，不能当默认值。
  • 未知占位符原样保留。正文里真出现 {{foo}}（从别的模板系统拷来的一段）不会被吃掉， 也因此不需要转义语法。代价：拼错变量名（{{sorce}}）不报错、会原文出现在笔记里—— 这比静默删掉一段文字好，而且实时预览里一眼就能看到。
  • 占位符容忍空白与大小写：{{ source }}、{{SOURCE}} 都行。
  • 只套正文，不套标题。标题行就那么宽，往里塞 来自 Chrome · 2026-09-01 只会把真正的标题挤成省略号。想把来源写进标题的需求可以后补，但不是默认。
  • 类型覆盖清空 = 没配，不是「配了个空模板」。用户把输入框清空的意图是 「不特殊对待这个类型」，而不是「把正文清空」。
  • 配置存脏也不阻断转笔记：覆盖表存的是 JSON 字符串，解析失败就退回默认模板， 而不是「因为模板配置坏了所以转不了笔记」。
  • 预览样本跳过密钥类卡片（走已有的 isSecret）。预览会把全文摄到设置页上， 而密钥卡片在卡片列表里本来是遮罩显示的——不能在这里绕过那个遮罩。 扫前 30 条找第一条能转笔记的，一条都没就用内置示例。
  • 保存时机：弹窗里敲的是草稿，不点保存就不落库。 弹窗本身就是一个明确的「我要改这个」手势，它理当有取消； 也因此不再需要上一版的失焦即存 + 卸载补写那套机制。 每次打开重新从配置取草稿：上次取消掉的内容不能留到下一次。
  • 有未保存改动时，ESC / 遮罩 / ✕ / 取消 四条关闭路径都先问一句。 四条走同一份弹窗壳（规则 #11）——写两份必定漏一条。 嵌套确认框是支持的：ConfirmDialog 用 .z-confirm（z=600），就是为「从弹窗里再弹」准备的。
  • 样本卡片的类型刚好配了覆盖时，预览上方会明说：预览框属于默认模板（否则改默认模板看不到变化）， 但那条卡片实际转笔记走的是类型覆盖——不说就是一个预览与真实结果不符的坑。

4 · 模板在哪一步生效

右键「转为笔记」/ 卡片角标 ┐
待沉淀区「转为笔记」   ┴─→ openNoteForCard ─→ extractNoteDraft ─→ [套模板] ─→ 弹窗

今日速记（热键 / 右键追加） ─→ note_append_daily ─→ 固定格式（不过模板）

只在 openNoteForCard 一处套。两个转笔记入口都走它； extractNoteDraft 在别处（卡片菜单、待沉淀区按钮）只用来判「能不能转」，不套。

今日速记不走模板。 D11 写死了「不做模板引擎」，而且它的 ## HH:MM · 来自 X 是固定格式，套模板会打乱那个流水账结构。

5 · 边界（明确不做）

  • 不做模板引擎——无条件、无循环、无函数。规划写死的边界，那是 Templater 的路。
  • 不做按来源应用匹配（Clipper 是按 URL 匹配的）——content_type 是更稳的信号： 同一个浏览器里拷出来的可能是代码也可能是文章。
  • 不做多模板选择器（方案 C）——转笔记是高频动作，每次多一步点击就是给「低摩擦捕捉」让路。 而且现在连水位数据都没有，不知道用户一天转几条、有没有多种笔记类型。
  • 不做模板导入/导出/分享——就几百字节，需要时直接拷文本。

6 · 验收

  • 不配模板（默认态）转笔记 → 结果与以前一字不差
  • 填入示例模板 → 转一条 → 正文首行是 > 来自 XXX · 时间
  • 模板里写 {{sorce}}（拼错）→ 预览里原样显示 {{sorce}}，不是空白
  • 给「代码」配一个覆盖 → 转一条代码卡片走覆盖、转一条普通文本走默认
  • 把「代码」的覆盖清空 → 转代码卡片回到默认模板，而不是得到空正文
  • 改完模板不重启直接转笔记 → 新模板已生效（配置现读不缓存）
  • 今日速记追加 → 仍是 ## HH:MM · 来自 X，模板没介入
  • 两行与上下其它设置行同高、同内缩、图标同尺寸；设置页搜「模板」能命中这一节（包括小节标题）
  • 弹窗里改完点取消 → 行上摘要不变，转笔记也不变（草稿没落库）
  • 弹窗里改完直接敲 ESC → 先问「放弃未保存的模板改动？」，选「继续编辑」回到弹窗且内容还在
  • 没改任何东西时，保存按钮是置灰的，ESC / 遮罩直接关、不多问一句
