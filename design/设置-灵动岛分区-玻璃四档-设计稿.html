一 · 一句话背景

窗口技术没有错：现实现就是交互稿 A 档写的「窗口级 Acrylic 负责模糊 + CSS 管高光描边」。 观感差异来自 染色浓度：稿子默认展示 A 观感玻璃（tint .30，最好看），上线时按 3a 实测换成厚磨砂（tint .78， 四背景文字对比全过 AA）——「透」和「清楚」在不可控的桌面背景前物理互斥，所以给用户自己选。 四档只动一组数（岛面 CSS 的 tint α 与高光强度），形状、动画、布局全都不变。实现路线已按红色探针定稿修正：窗口级 Acrylic 被推翻（DWM 材质层不服从 SetWindowRgn，胶囊四角方块玻璃是那条路线的固有产物），玻璃改由 CSS 半透明面承载（PILLAR 同构），四角方块根除。
