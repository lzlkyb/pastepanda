问题

① 马赛克 / 模糊 / 自动打码 是三个独立按钮，遮档类功能被拆散，主栏拥挤；
② 马赛克和模糊本质是同一交互（涂抹 / 拖框 + 强度），用户得记两个位置；
③ 自动打码的「预览确认条」锚在主栏按钮上，与它的触发点同域，但按钮本身孤立。
② 方案 A · 主栏 合并后
「模糊」「自动打码」两个按钮从主栏消失（马赛克 6 保留；7 仍可切模糊）。虚线框 = 原按钮位置让出的空间，主栏变短。

态 3 · 自动打码执行后 确认条新锚点

确认条从「主栏按钮上方」挪到「自动打码分段下方」（同属性栏锚定，跟随翻转）。点完分段视线零移动。工具高亮仍停在马赛克 / 模糊（动作不切换工具）。
④ 行为细节（方案 A）
• 模式状态复用现有 tool（mosaic / blur / automask），不新增状态：点「模糊」= setTool("blur")，属性栏形状 / 强度 / 滚轮 / 撤销重做全部原样生效；
• 点「自动打码」= 现有动作（OCR 检测 → 橙框预览 → 确认条），不切换工具，打码产物仍是 mosaic 标注、整批一次撤销；
• 快捷键：6 马赛克、7 模糊 保留（TOOL_BY_KEY 仍含 blur），肌肉记忆不失效；
• 已画在画布上的 blur 标注不受影响（类型照旧，draw.ts 不用改）；
• 首用引导（discover 脉冲）：挪到「自动打码」分段上，用过即停（持久化逻辑不变）。
