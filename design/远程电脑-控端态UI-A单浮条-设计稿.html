远程电脑 · 控端态 UI — 方案 A「单浮条收编」设计稿

目标：画面四周只保留两个控制点——瘦身的窗口壳顶栏 + 一条会隐藏的浮条。画质 / 画面 / 视图 / 详情 / 结束全部收进浮条， 底栏（RcSessionBar 常驻玻璃条）删除，viewTools 与 HUD 按钮删除。全屏态复用 RcFullscreenHotbar 同构。
业界对标：Chrome Remote Desktop 边缘 dock · RustDesk 顶部单条（collapse-toolbar）· Parsec 顶部胶囊。

§7 交互规则与实施落点

  1. 浮现：连接后首显 2.5s（可发现性）；此后顶边 56px 热区或悬停浮条唤出，离开 2.5s 淡出（复用 RcViewTools 现行机制与常量）。
  2. 锁显：链路异常 / 操作无画面 / 文件传输进行中 → 浮条不淡出，警示胶囊就地呈现。
  3. 穿透：浮条外画布区域 pointer-events:none 不变，远程点击零遮挡；淡出态 visibility:hidden + tabIndex=-1（P2-12 口径）。
  4. 失败回滚：画质/画面/码率改档的乐观更新 + 失败回滚链路原样保留（RcSessionBar 的 remoteSend 逻辑搬入浮条组件）。
  5. 确认红线：结束会话 / 申请控制权 / 重连一律 confirmDialog（U1 口径不变）。
  6. 实施落点：新建 RcSessionCapsule.tsx（浮条 + ⋯ 面板，预估 ~260 行）；RcViewTools 删除；RcHud 的按钮并入、面板逻辑保留；RcSessionBar 删除（remoteSend 搬走）；RcSessionTop 删结束/更多；RcFullscreenHotbar 改挂同一胶囊；RcSessionView 删 recentRow。CSS 新增 .capsule* 组、删 .sessionBar/.viewTools 组。
