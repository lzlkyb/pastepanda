远程电脑 · 设计稿

PastePanda · 2026-09-14 · 对应规划 docs/PastePanda-规划与排期.md §3.7 · 一期 R0 门禁 + R1 只看 + R2 可控壳 · 默认关闭

先读这句：这是「远程协助」不是 ToDesk。只服务已配对的自有设备； 被控端默认拒绝一切远程；每次会话都要对端点头；无会话时协议层直接丢 Input 帧。 远程 shell / 文件管理 / 无人值守 明确不做（规划 §4）。

二、R0 · 设置「允许被远程」

挂在设置页 · 与「知识库同步」同级新块。默认关；关时无任何 RC 网络入口。

演示 · 被控开关
允许被远程协助
打开后，已配对的设备可以申请查看或控制这台电脑。默认关闭。 会话开始时本机会出现常驻横幅，随时可结束。
能力上限
「可控」包含只看。对方申请的能力不能超过这里选的档。 选「只看」时，即使对方申请控制也会被拒。
设备级限制
某台配对设备永不许远程这台电脑时，单独关掉。与同步暂停是两个开关：暂停停同步，这里停远程。

九、不在本期

  • 远程 shell / 任意命令
  • 浏览或下载对端磁盘文件
  • 无人值守常开被控
  • 手机控制端
  • 剪贴板文件夹、会话录像（屏幕录制已拍板不做）
实现顺序建议：先 R0 协议与双端开关 + 单测（未 Grant 拒 Input）→ 再 R1 低帧只看 → 再 R2 键鼠。 设计稿确认后动代码；UI 落地前仍按规则 4/12 对照真实 Settings.module.css / ToolboxView。
