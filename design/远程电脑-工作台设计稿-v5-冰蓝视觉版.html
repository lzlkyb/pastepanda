实施备注 · 与现行代码的差异对照

左列为稿中区块，右列为现行实现与差异性质。「照搬」= 文案/结构与代码一致可直接落地；「新提案」= 图里有、代码里没有，需拍板；「改口径」= 与代码单一数据源冲突，二选一。

  • 标题栏（RcA2TitleBar.tsx）：品牌「PastePanda / 远程电脑」、中间「远程通道已开启」照搬。新提案：品牌下标语「连接更近 · 工作更自由」、右侧延迟 chip / 通知铃 / 账号入口——延迟可取 lastMeasuredRtt()，铃铛与账号目前没有数据源与交互定义，不做就删（L6：长得像能点就必须能点）。
  • 侧栏设备列表（RcA2DeviceList.tsx）：「我的设备 / 添加设备 / 重新检查 / N 台设备 · 正在确认 N 台 / 允许别人连接本机 / 已开启，可接收远程请求 / 已允许 / 让别人帮我 / 帮助别人 / 输入接入码 / 文件·记录·设置」全部照搬。改口径：搜索框 placeholder 代码为「搜索设备」，稿随图作「搜索设备名称或备注…」；设备行由「图标+两行+右置分体按钮」改为「缩略图+三行+通栏分体按钮」，行内新增重命名铅笔（现仅详情头有）；行按钮文案代码为「连接 · 可控」，稿随详情头统一为「连接并控制」。
  • 设备状态文案（rcDeviceStatus()，lib/utils.ts）：「正在确认是否可连接…」照搬（checking 档）。「正在等待对方确认连接」代码没有——发起申请的等待态现在只出现在会话面 RcPendingWait。若要在行/详情头常驻，须给 rcDeviceStatus 加 awaiting 分支并收口全部调用点（规则 11.1），不能逐处补 if。
  • 详情英雄卡（RcA2DeviceDetail.tsx）：「连接并控制 / 只看 / 传文件」三键、在线 pill 照搬。改口径：图把「局域网直连」（pathKindLabel）与「12ms」（lastMeasuredRtt）从「连接与权限」注解行上移为头排 chip——两处只能留一处真源展示，建议 chip 展示、注解行去掉重复半句。手写标语「让距离，不再是距离」为纯装饰新提案。
  • 连接与权限（RcA2ConnectionFacts.tsx）：四项 dt/dd/注解文案逐字照搬（上次连接·局域网直连·来自最近一次会话实测 / 连接确认·每次由对方确认·默认更安全 / 文件接收·每次询问·接受后才写入电脑 / 设备身份·指纹·已完成配对校验）。改布局：竖排 dl 改横排四卡。新提案：卡尾「›」与头部「端到端加密保护 / 安全校验已完成」两枚绿 chip——chevron 需定义点击后做什么（否则违反 L6），两枚 chip 需真实状态支撑（配对校验失败时不能仍写「已完成」，U3）。
  • 最近会话（RcRecentSessions.tsx）：时间「今天 10:00 / 9/21 10:41」（formatWhen）、时长「00:13」（formatDuration）、结果着色（resultTone：取消=灰、超时=橙红、结束=绿）照搬。改口径：能力标签代码为「可控 / 只看」（historyCapabilityLabel），图写作「远程控制」——与记录页共用单一真源，改则两视图一起改。新提案：行首结果语义图标块、行尾「⋯」菜单（菜单项未定义，先不落地）。
  • 视觉层：冰蓝云感画布 + 浮动白卡是浅色主题视觉提案，质感为毛玻璃（2026-09-23 按用户反馈补）：blur 只加在 5 块静态大面板 + 工具导航 + 通道 pill（背景是静态云纹，采样一次性）；chip / 设备卡 / 会话行 / 事实卡等重复元素只用半透明白、不加 blur（规则 8.3：N 个元素 N 个合成层）。现行 A2 禁写死颜色（rcA2ThemeTokens.test.ts 守卫），落地时全部映射为 theme.css 令牌，并为其余 5 套主题（含暗色）出对应取值；暗色主题下毛玻璃取值需单独调（半透明白要换半透明黑）。
  • 窄窗口防塌（2026-09-23 实机截图回归）：英雄区改可换行 flex——动作组在窄窗口整体换行右对齐，chip / pill / 状态行全部钉 white-space:nowrap（中文可按字断行，不钉会被压成一字一行竖条）；会话与设备列表换 6px 细滚动条。
  • 尺寸档位：稿中圆角 9/10/12/14 超出 U5 的 4/8/12 档，落地时就近收档（9→8、10/14→12）；字号 11/11.5/12/12.5/13/14/24 需收到 11/12/13/15/20 档（24→20）。
