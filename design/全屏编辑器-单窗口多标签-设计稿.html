全屏编辑器 · 单窗口多标签（多页签）

路线：单窗口多标签 + 保活（方案 A）。类型范围：markdown / json / html / csv / code / diff / 流程图 / 图文混排共用同一条标签条。上限 12。并排多窗格不在本期。

一、定下来的六条决策

#决策理由（含被否决的做法）
1标签条只在 ≥2 个标签时渲染，高度 34px，位置在工具栏之下、格式栏之上单文档时视觉与今天完全一致，回归面最小；放在工具栏之上会与「48px 常驻拖拽头」打架（拖拽区被切成两段）
2每个标签的视图保留挂载，非活动的 display:none与现有「仅预览模式不卸载编辑区」同一手法（.editorPane 已验证）；卸载则 undo 历史、光标、滚动位置全丢
3脏点静态不 pulse；自动保存失败另用红点工具栏那颗脏点是唯一一颗，pulse 没问题；标签条是常驻区、最多 12 颗，N 个常驻动画违反规则 8.1。失败态换红点是为了让「切走之后存不进去」仍然可见（规则 15）
4命中已打开的文档 → 切过去，不重载；即使该标签脏也不覆盖重载会冲掉该标签未保存的编辑。这是现存缺陷（system.rs 已存在的窗口直接 emit 覆盖，无守卫）的顺手修复
5关闭分两级：关标签（单文档守卫）/ 关窗口（聚合所有脏标签后逐个处置）N 个脏标签逐个弹窗会变成弹窗地狱；聚合清单让用户一次看清「到底有几个没存」
6非活动标签停掉 fileWatch 轮询 / scrollspy / 滚动同步规则 8.2：隐藏不等于停。编辑器窗口本身是 4 窗口之一，不能在里面再叠 N 份常驻开销

部件规格依据
标签高 / 宽34px / min 132px、max 200px与标签条等高（撑满）。下限 132px 是渲染实测后从 96px 提上来的：96px 下文档名只剩约 30px，只能显示 2 个汉字（"需.."），失去「这是哪个文档」的辨识意义。132px 实测约显示 4 个汉字（"需求清单.md" 在此宽度下截成"需求清…"），再长的中文名必然省略号 —— 完整文件名由工具栏与 hover 的 title 兜底。上限 200px 约 11 个汉字
内边距 / 间距padding 0 8px 0 12px；gap 6px左内边距比右大 4px：左侧是图标起点、右侧是 ✕ 热区，视觉重心左移更稳
类型图标11px 文字符号，活动时用 --accent-strong沿用 spec.icon（"M↓" / "{ }" / "</>"），不新造图标集
文件名12.5px；活动 500 字重，非活动 400比工具栏文件名（13px/600）轻一档，避免与标题抢权重
脏点6px 圆点 / --orange，不 pulse；失败态 --danger复用工具栏 .unsavedDot 的尺寸与色，但去掉动画（见决策 3）
关闭钮16×16 / 圆角 4px / 12px 图标活动标签常驻显示，非活动标签仅悬停显现（12 个 ✕ 同屏会喧宾夺主）
活动标识上缘 2px --accent 指示条 + --paper-bg 实底与编辑区同面（"这个标签就是这块内容"）；不单靠底色编码，色觉障碍友好
分隔线每标签右沿 1px --border-color细分割线是本项目既有语言；比卡片式圆角标签省横向空间
为什么脏点和 ✕ 不做同位互换（浏览器常见做法是 hover 时用 ✕ 顶掉脏点）：那样非活动标签一旦鼠标扫过，「这个文档改没改」的答案就消失了，而状态栏徽章只反映活动标签。脏点常驻在文件名之后（与工具栏同语义位置），✕ 独立在最右，两者不争位。

八、明确不做

  • 并排多窗格（同一窗口左侧一个文档、右侧另一个）：现有 markdown 视图本身就是「大纲 + 编辑 + 预览」三栏，再分就是六栏，两套滚动同步与两套大纲 spy，改造量翻倍。留给 v2。
  • 多独立窗口：需要改 label 生成、capabilities 窗口白名单、PendingEditor 多槽、set_editor_target 单目标语义，且四个窗口变五个后多窗口乘法要重新审一遍。
  • 标签拖拽排序 / 拖出成新窗口 / 右键菜单：排序与菜单是纯增量体验，不影响"同时打开多个"这个主目标。
  • 跨重启恢复上次打开的标签：涉及持久化文档列表与路径失效处理，单独评估。

九、验收要点（交付前自测）

  • 单标签时标签条不渲染，DOM 里也没有占位（对比改动前截图，除标签条外像素级一致）。
  • 打开第 2 个文档后，在标签 A 改动文字 → 切到 B → 切回 A：Ctrl+Z 能回退、光标与滚动位置保留（这条是保活方案的唯一硬判据）。
  • 已在编辑器打开的文件再次从卡片点「全屏」：切到该标签，且其未保存内容不被覆盖。
  • 标签 3 处于自动保存失败态时切走，红点仍在（规则 15：反馈不能随活动标签消失）。
  • 非活动标签不再触发 file_mtime_ms 轮询（可断点或看日志计数）。
