§2 为什么是这个位置、这个尺寸

决定选了理由
放哪 形态切换器右侧、关闭按钮左侧 关闭必须是最右那个 —— 全应用（弹窗、面板、问答栏）的✕ 都在最右， 把它挤到中间会让「关闭」变成需要找的按钮。
多大 26×26（不是 --kb-hit 的 28） 旁边 .closeBtn 就是 26。两个紧挨的图标按钮差 2px 看得出来； 命中区靠 ::before{inset:-1px} 撑到 28，不占布局。 （这就是批 1 里 .caret / .addBtn 用的同一个手法。）
图标多大 MoreHorizontal size={14} 行悬停条上的 ⋯ 就是 14（NoteList.tsx:527）—— 同一个动作同一个尺寸。 旁边 X 是 13，不改。
Tab 能不能停 能停（不给 tabIndex={-1}） 这里与行悬停条相反。行上那三个必须 -1，是因为列表里有上百行， Tab 会停上百次；第三栏头部只有一份，Tab 停一次是应该的。 所以它不需要再配一个 P/M 快捷键。
菜单从哪弹 按钮左下角（r.left, r.bottom + 2） 与行悬停条上 ⋯ 的锚点公式逐字相同（NoteList.tsx:524）。

§3 菜单里装什么 —— 不新建，直接用 buildMenu

这是行右键与行悬停条已经在用的那一份（NoteList.tsx:255），一字不改：

未置顶的笔记 · 建过文件夹
📌 置顶
📂 移动到文件夹›
🗑 删除笔记
风险梯度从上到下递增（源码注释里就这么写的）
已置顶 · 一个文件夹都没建
📍 取消置顶
🗑 删除笔记
没地方可移时那一项不出（children.length > 0），不弹空子菜单
这是甲方案最大的好处：零新增产品行为。 置顶 / 移动 / 删除的文案、图标、排序、分隔线、危险色、“未分类”该不该出、 删除确认框——全部跟行上完全一致，因为就是同一份代码。 不存在「两处迟早分歧」的风险。

§4 这一批真正的工作量：不是那个按钮，是把菜单搬出来

buildMenu / folderMenu 现在住在 NoteList.tsx 里（它们是 useCallback，依赖 folders / onSetFolder / onDelete / onTogglePin）。 NoteDetailPane 拿不到——它的 props 只有 note / onClose / onSaved / notInList / onRegister / onOpenNote。

4.1 两种搬法

做法代价
抬到 KnowledgeView
（推荐）		 把两个菜单抽成 useNoteMenu()，在 KnowledgeView 调一次， 把 buildMenu / folderMenu 当 props 传给 NoteList 与 NoteDetailPane。 NoteDetailPane 多 1 个 prop；NoteList 可以退掉 onSetFolder（它只为建菜单而存在）。净增 0 个调用链。
各自调 hook NoteDetailPane 自己调 useNoteMenu()。 得给它新增 4 个 props（folders / onSetFolder / onDelete / onTogglePin）， 而它本来是个只管「一条笔记」的组件。它也成了菜单第二个调用点。

4.2 抬到 KnowledgeView 后的数据流

KnowledgeView
  ├─ q.folders · act.handleSetFolder · act.handleDelete · act.handleTogglePin
  │     ↓
  ├─ useNoteMenu({ folders, onSetFolder, onDelete, onTogglePin })
  │     → { folderMenu, buildMenu }        ← 唯一一份
  │     ↓                    ↓
  ├─ <NoteList  buildMenu folderMenu …>      行右键 / 悬停条 ⋯ / M 键
  └─ <KbThirdPane main={
         <NoteDetailPane buildMenu …>         ← 新：头部那个 ⋯
       }>
folderMenu 为什么不传给 NoteDetailPane： 它只服务于行悬停条上那个「移动」按钮与 M 快捷键。第三栏没有单独的移动按钮 （甲方案就是把它收进菜单），所以只需 buildMenu。不传用不到的东西。
❗ 规则 #11.1：抽出来后必须把同类调用点找全。 buildMenu 现在有 3 个调用点（行右键 NoteList.tsx:417、 悬停条 ⋯ :524、卡片右键 NoteCard.tsx）， folderMenu 有 2 个（悬停条移动 :507、M 键 :215）。 加上新的第三栏，共 4 + 2。抽完要逐个核对，一个不能漏。
