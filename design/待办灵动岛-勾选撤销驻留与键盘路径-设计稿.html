S1 · 勾选的时间线：现状 vs 拟改

时刻现状拟改
0ms勾圈翻绿（≤150ms 有反馈）不变
200ms行淡出消失（反悔 = 切「已完成」tab → 翻找 → 重勾）行留在原位：完成态样式 + 行尾「撤销」chip + 2px 绿色倒计时条开始收缩
200ms–6s—悬停该行 = 暂停倒计时（条停住提亮），移开恢复；点 chip 或重勾 = 行回原位未完成态
6s—倒计时走完 → 行按现有 .rowLeave 动画退场归档（写回早已发生，此步纯视觉）
写回时机不变：点勾那一刻就调 toggleTask（乐观翻面照旧）。「撤销」= 再发一次 toggle（回未完成），失败路径沿用现有 notice「这条待办刚被其它途径改过，已还原」。闲置自收（6s）若在驻留期间触发，直接收起不等待——写回已落库，只是视觉提前结束。

2026-09-27 追加（用户定稿 B 方案）：整行可点 = 勾/取消勾——命中面从 24×24 勾圈扩到全行（36px 高），滚列表蹭到的误触由上面的 6s 驻留 + 撤销 chip 兜底（两个改动互为前提）；来源笔记名 .src 拦冒泡不参与勾选，预留给「打开笔记」。已落地并带守卫单测（点行一次 toggle / 勾圈不双触发 / 来源名不触发）。

驻留行的三个状态（自左向右）

状态触发视觉
驻留中勾选后即刻完成态样式不变 + 「撤销」chip 弹入（150ms）+ 绿色倒计时条从满条 6s 收缩
已暂停鼠标悬停该行倒计时条停住并提亮（opacity .55→.9）；chip 提亮。移开恢复收缩
撤销点 chip / 再点勾圈行回未完成态（back 150ms），chip 与倒计时条移除，重新发 toggle
边界处理
写回失败现有路径：乐观翻面作废、notice「已还原」，驻留态一并取消（行回原位）
驻留期间岛收起直接收起，不等 6s（写回已落库，纯视觉提前结束）
驻留期间该行被外部改掉现有「服务器现状收敛」逻辑照走：行从列表消失，chip 随之不存在
chip 挤占行宽chip 挂在行尾（原退场前空出的位置）；.tx 已有 ellipsis，不新增布局规则

S3 · 键盘路径：键位表

键位作用实现落点
Alt + T全局热键：任何应用下唤岛并直进输入态（焦点落输入框）；岛已展开时等效「回到输入态」。再按 = 收回胶囊（开关键）Rust hotkey_manager.rs 注册（插件已在）；热键 → todo_island_show + 广播新事件 todo-island-hotkey，岛前端收到达成 compose
Enter / Space岛体（胶囊态）被 Tab 聚焦后展开列表root 补 tabIndex={0} + keydown 分支（现 role="button" 名实相符）
Esc不变现有两级取消（compose→list→pill）
← / →在「进行中 / 已完成」两个真按钮 tab 间切换.seg 的 span 换 <button role="tab">，roving tabindex
Tab列表内焦点序：收起 → tab → 各行勾圈 → 撤销 chip → 记一条行内元素本就是按钮；只补 :focus-visible 样式（见 S5）

S5 · 焦点可见性规范（全岛统一）

元素:focus-visible 样式
岛体 root（胶囊态）outline: 2px solid var(--island-accent-focus) + outline-offset: 2px；圆角跟随胶囊
tab 按钮 / 收起 / 记一条 / 勾圈 / 撤销 chip同上但 outline-offset: 1px（小元素不留大空隙）
输入框 .cinput保留现有 border 变化，再叠同款 outline（现在是 outline: none，SC 2.4.7 不达标处）
新增令牌 --island-accent-focus: #38bdf8（深色）/ #0369a1（浅色）——比现有 --island-accent 提亮一档，保证焦点环在深玻璃上也醒目；随手补 prefers-reduced-motion 不受影响（focus 环无动画）。
