G · 质感层规格 v4 相对 v3 的全部面层改动，逐项可落地

  • 页面底平色 #F4F8FC → 蓝天渐变 linear-gradient(135deg,#F6FAFF,#EDF4FF 55%,#EAF3FF)
  • 玻璃面统一 blur(20px)；卡片为纵向白渐变 rgba(255,255,255,.92→.78) + 白描边 rgba(255,255,255,.75)
  • 投影一层细影 → 双层柔影 0 10px 30px rgba(27,76,164,.08)；弹层 0 14px 36px rgba(15,23,42,.16)
  • 辉光所有渐变主元素（logo / 导航选中 / 主按钮 / 播放钮 / 开关开态 / 显示器）带同色 glow 0 8px 20px rgba(2,132,199,.32)
  • 圆角窗口 14→18 · 卡片 16→20 · 工作区 18→24 · 行 12→14 · 输入 8→10
  • 留白导航项 37→43px 高 · 卡片 padding 13→15/18 · 顶栏 56→60 · 窗口高 676→700
  • 工作区光晕单光晕 → 双光晕（右上 cyan .14 / 左下 紫 .06），尺寸 640/420
  • 显示器插画180×118 → 190×124，辉光加深至 .32，底座加宽
  • 画布深色区不改（HUD 10.5px 纪律保留），加内高光 inset 0 1px 0 rgba(255,255,255,.06)
  • 不变项文字色四级 / 状态色 / 语义化结构 / 图标纪律 / 五页布局全部沿用 v3

H · 微动画规格 三类动效：入场级联 / hover 反馈 / 状态呼吸；落地对应 CSS transition 与 keyframes

  • 入场级联侧栏 0ms → 顶栏 60ms → 左列卡片逐张 100/160/220ms → 工作区 140ms；统一 riseIn（上移 10px + 淡入）450ms ease，一次性播完，不循环
  • 弹层入场devMenu / HUD 芯片 popIn（scale .97→1）180–300ms，transform-origin: top right（菜单）/ center（芯片），HUD 芯片逐个 70ms 级联
  • hover 浮起卡片 / 设置组 translateY(-2px) + 投影加深 180ms；列表行 / 按钮 / 下拉 -1px；播放钮 -1px + scale 1.05 + brightness；导航未选中项右移 2px
  • 按下回落btn / menuBtn / tag / playBtn :active scale(.97)——按下有「压下去」的物理感
  • 状态呼吸在线点 / 通道点 ping 雷达扩散 2.2s（box-shadow 0→6px 扩散，currentColor 混色，出站蓝入站绿自动跟随）；横幅 liveB 已有 pulse 1.6s
  • 等待画面显示器 floatY 上下浮动 3.4s + glowBreath 辉光呼吸（0→16px 扩散圈）——「在等待」不用文字也能感知
  • 会话态只看水印 breathe 透明度呼吸 2.6s；对端光标 cursorDrift 5.5s ease alternate 漂移 26×-14px——暗示远端正在活动
  • 开关旋钮 left 220ms ease（原有）——唯一保留的「位移型」交互动画
  • 动画边界动画只落在装饰元素（点、水印、插画、光标）与面层（transform / box-shadow / opacity），不动文字内容与颜色——SR 朗读不受任何影响
  • 降级@media (prefers-reduced-motion: reduce) 全量关闭 animation 与 transition——前庭敏感用户零动画
  • 性能纪律只动画 transform / opacity / box-shadow（合成层属性），禁止 top/left/width 布局属性动画；浮动元素均已有 will-change 语义替代（不显式声明，避免常驻合成层）

v4 = v3 结构 × 参考稿质感层 × 微动画层。质感来自「面」的物理属性（渐变、模糊、描边、投影、辉光），动效来自三类微动画（入场级联 / hover 反馈 / 状态呼吸）——均不触碰文字 token 与可访问性纪律。落地映射同 v3：侧栏→RcSideRail、左列→RcSelfToggleRow/RcQualityBar/RcDeviceRow、工作区→RcSessionView/RcSessionBar、横幅→RcControlBanner；设备列表 / 会话记录 / 设置为 RcWorkbench 内路由页；动画层建议收敛为一个 `rc-motion.css`（keyframes + transition 工具类 + reduced-motion 兜底）统一挂载。
