Docker 端口占用排查

来源：Windows 终端 · 2 天前复制 · 一键转为笔记

现象

容器启动报 port is already allocated，但 netstat 查不到占用。

定位

docker ps -a --format "{{.Names}}\t{{.Ports}}"
netsh interface ipv4 show excludedportrange protocol=tcp

第二条是关键：Windows 的 Hyper-V 会预留一段端口，这段端口不在 netstat 里显示。

解决

换到预留段之外的端口，参见 多阶段构建瘦身 里记的端口表。

我

上次那个 Docker 端口被占用的问题，最后是怎么解决的？

是 Windows 的 Hyper-V 预留端口导致的：那段端口被系统预留，netstat 里查不到，但 Docker 分配时会判为已占用1。

定位用 netsh interface ipv4 show excludedportrange protocol=tcp 看预留段，然后把容器端口换到段外1。

你记的那篇里还留了一张可用端口表，在《多阶段构建瘦身》里2。
