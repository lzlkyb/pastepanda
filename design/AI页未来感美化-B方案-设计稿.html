性能自查（规则 8）
· 常驻动画共 3 个合成层：扫描线（heroScan）/ 光斑漂移（heroOrb）/ 呼吸光点（badgeDot），全部 transform + opacity，GPU 加速，零重绘。
· 无光晕动画（box-shadow 全静态）、无 filter blur 动画、无 backdrop-filter 新增。
· 设置弹窗是模态窗口：关闭即组件卸载，动画随组件消失，不存在「多窗口 hide 后照跑」的乘法问题（规则 8.2 不适用）。
· 新增动画只在「已就绪」徽标与 hero 卡上，未配置态 hero 卡也显示扫描线（频率 6s，几乎无感）。

兼容性
· 颜色零硬编码：全部 --brand-ai-from/to · --accent-glow · --hero-glow · --accent*，六套主题（ocean / ocean-dark / midnight / forest / blossom / dawn）token 都已定义，自动适配。
· prefers-reduced-motion 落地时会加媒体查询关动画（可选，见改动清单 #6）。

③ 改动清单（落地范围）

#位置变化
1AiTab.module.css 的 .heroCard升级为渐变描边（padding-box / border-box 双层渐变）+ --hero-glow 光斑底 + --accent-glow 外发光；新增 .heroScan（扫描线）与 .heroOrb（漂移光斑）两个子元素样式 + 2 个 keyframes。
2AiHeroCard.tsxheroCard 内加 <span className={styles.heroScan}/> 与 <span className={styles.heroOrb}/> 两个装饰节点；「已就绪」徽标的 CheckCircle2 旁加 .badgeDot 呼吸光点（图标保留）。
3.badgeReady + 新增 .badgeDot呼吸光点：opacity+scale 2.4s；静态 box-shadow 光晕（不动画）。
4.heroStatNum加 tabular-nums + 轻微 letter-spacing + 静态 text-shadow: 0 0 12px var(--accent-glow)。
5.accIcon / .accItemOpen / .accHeadOpenaccIcon 换品牌渐变底 + 微边框；展开条目描边光晕聚焦（--accent-glow）；展开头部底部 1px 渐变发光线（::after 实现，替代素色 border-bottom）。
6（可选）@media (prefers-reduced-motion: reduce) 关闭 3 个动画——无障碍兜底。

不改的部分：AiTab 的编排逻辑、AiSection 结构、手风琴互斥、测试结果条、warn 条、红线声明条——全部保持原样。
为什么与整体风格协调：品牌渐变（蓝→紫）与顶栏 AiMark、TransformHub 的 AI 角标同源（--brand-ai-*）；光晕强度压在 --accent-glow（12% alpha）这一档，和卡片 hover 光晕同级，不会比主窗卡片更跳。
