1当前主题 Token 对照

A氛围底 --app-bg

Ocean：死白 → 青/微紫静态渐变。其它主题不变。

B壳层 blur

仅 Ocean：侧栏 blur(16px)。场景主题 none。

C卡片阴影

全部主题：近影 + 中影；深色档用黑影 + 白 inset。

D选中态

2px 硬环 → 3px accent 柔环 + 淡投影。

E控件微光

搜索框玻璃化；工具钮 on 用 --control-ring。

F性能边界

卡片 filter 仍 none；壳 blur 仅 1 个容器且仅 ocean；无新增 infinite 动画。

  --glass-card-elev: 0 1px 2px rgba(15,23,42,.04), 0 6px 16px rgba(15,23,42,.07);
  --card-top-light: linear-gradient(180deg, rgba(255,255,255,.55) 0%, transparent 45%);
  --card-selected-glow: color-mix(in srgb, var(--accent) 16%, transparent);
  --shell-bg: color-mix(in srgb, var(--card-bg) 72%, transparent);
  --shell-blur: none;          /* 默认关；ocean 覆写打开 */
  --control-glass: color-mix(in srgb, var(--card-bg) 72%, transparent);
  --control-ring: inset 0 0 0 1px color-mix(in srgb, var(--accent) 20%, transparent),
                  0 1px 4px color-mix(in srgb, var(--accent) 12%, transparent);
}
