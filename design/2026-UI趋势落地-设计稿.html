PastePanda · 2026 UI 趋势落地设计稿

2026-09-09 · 对照来源：NN/g（Liquid Glass / Neobrutalism）、Figma Config 2026（Motion 一等公民 / Shader / Agent）、 Smashing（Agentic UI / Button 之死）。
本稿只做「趋势 → 本产品怎么吃」：不照搬 iOS 26 的透明叠字，不引入粗野主义描边。 主线是：壳层光学玻璃 · 内容层清晰 · 动效有语义 · AI 状态一等可视。

选型结论先说：推荐落地 A 路线「壳玻璃 + Bento 概览 + 语义动效 + AI 门控可视化」。 它是现有 ocean/midnight 玻璃语言的精修，不是换皮；性能上继续遵守「卡片不加 backdrop-filter」（规则 8.3）。

1趋势地图：吃哪条、不吃哪条

吃 · 壳层 Liquid Glass / 玻璃 2.0

顶栏、侧栏、弹窗壳用光学折射边 + 内高光；内容卡片禁止 blur。NN/g 批评点是「透明压正文」，我们反着做。

吃 · 动效 Expressive Motion

选中、运行中、落定用形变/位移表达状态（150/200/300ms 四档），不是「好看就动」。时间轴可进设计系统。

吃 · 布局 Bento 概览

主列表上方 4 格不等分卡：今日剪贴、AI 可用、知识库、快捷动作。不把整页改成官网式 Bento。

吃 · AI Agentic 状态可视化

侧栏常驻 AI 门控点（规则 16）；运行条带进度与撤销；空态/错误态分开展示（U3 / U3.5）。

不吃 透明叠正文

iOS 26 的 Messages 背景图压文字、Mail 字叠字——可读性直接崩。内容层永远实底或 ≥55% 不透明。

不吃 Neobrutalism 全盘

粗描边 + 硬阴影适合创作者营销站；效率工具里会抬高认知负荷。最多借「高对比选中」一点。

2主窗口全景（可切主题）

布局骨架不变：侧栏 + 顶栏 + 卡片列表。变化在「壳的光学感、Bento 概览条、AI 运行条、卡片状态语义」。

3关键组件：现状思路 → 2026 精修

3.1 壳 vs 内容（Liquid Glass 的正确打开方式）

常见错误 · 学 iOS 26
半透明卡压在花哨背景上
正文对比度崩了 · 选中态看不清 · 长列表全是合成层

NN/g：透明叠字 = 灾难。卡片一多 GPU 也炸（规则 8.3）。

本稿 · 壳玻璃 / 内容实底
📝
内容卡不透明 / 无 blur，文字始终可读
✨
场景光只从壳与页底透出

壳负责「有材质」，内容负责「读得清」。职责分开。

3.3 AI 门控：规则 16 的可视化答案

状态侧栏门控点卡片上的 AI 表现用户能做什么
可用 AI 可用 出现「AI 建议」「已摘要」等 .pill.ai/.ok 一键变换、试跑、预算条
运行中 同上 + 列表顶出现 AI 运行条 橙色 .pill.run + 底部进度 取消 / 看进度 / 完成后可撤销
未启用 AI 已关闭 零 AI 按钮 / 建议 / 变换入口 点门控 → 设置开启（显式例外）
红线对照：未启用时前端零可见、后端零请求。本稿侧栏门控是「唯一常驻入口」， 避免 AI 能力散落在卡片溢出菜单里却没人知道总开关在哪。

4新增/收敛的视觉 Token（建议）

TokenOcean 参考用途约束
--shell-bg rgba(255,255,255,0.72) 侧栏/顶栏/弹窗壳 唯一允许 backdrop-filter 的层
--shell-border rgba(255,255,255,0.85) 壳顶部折射边 配合 ::before 静态高光，不做动画 blur
--glass-card-* 沿用 theme.css 卡片/笔记行 filter 恒 none；不透明度可升到 0.45–0.6 压场景
--motion-150/200/300 150/200/300ms U2 四档 曲线仅两条：cubic-bezier(.2,0,0,1) / (.4,0,.2,1)
状态 pill 色 绿 / 橙 / accent / danger U3 四件套 + AI 状态 只许语义色（U6），禁止色名变量

5建议落地切片（可拆 PR）

切片做什么验收性能/规则
P1 侧栏 + 顶栏改壳玻璃 token；卡片保持现状 ocean/midnight 都不发灰；四窗口截图一致 壳 blur 只在 1–2 个节点；不可见时可 pause 场景
P2 主列表上方 Bento 四格（今日/余额/KB/快捷） 窄窗自动折成 2×2；数据来自已有 store 无网络；不引入新请求
P3 AI 门控点 + 运行条 + 卡片 pill aiAvailable=false 时全部消失 规则 16 双保险；失败走错误态不是空态（U3.5）
P4 选中/置顶/落定的 Expressive 微动效 与 surface.css keyframes 统一命名 pp-* 只用 150/200/300；reduced-motion 走全局兜底
先别做：全站 Bento 官网化、卡片加 blur、Neobrutalism 描边、每卡独立 backdrop-filter。 这些在效率工具里收益低、风险高（可读性 / GPU / 多窗口乘法）。
