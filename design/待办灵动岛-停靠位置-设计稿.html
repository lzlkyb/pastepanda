§2 三种做法

做法成本取舍
C1 本稿默认 设置页加「停靠位置」六宫格（顶/底 × 左/中/右），不做拖拽 小：只改定位与形状镜像，不碰手势与穿透状态机 够用且零误触；缺点是想微调几像素做不到
C2直接拖胶囊到想要的边，松手吸附到最近锚点，设置页同步显示 中：要加拖拽手势（start_dragging 在 Windows 走模态消息循环，或自己按光标轮询推 set_position），并处理「拖拽要收事件 ↔ 收起态要穿透」的抢占 最顺手，但拖拽起手必须收事件，等于给「吞点击」留了个后门；且手势与悬停展开会打架
C3C1 + 「距边缘」滑杆（0–48px） 中：一旦不贴边，停靠形状要从半胶囊退回满胶囊（rgn / hit / CSS 三处都要三态） 适合「顶中但往下让 20px 避开标签栏」这类需求；几何状态从 2 种变 3 种，守卫测试翻倍

建议：先 C1。六档能覆盖「让开 ✕」这个诉求的绝大多数场景；C2 的拖拽等 C1 用一段时间、确认还想微调再上（C2 落地时锚点数据格式不用变）。

§3 几何与数值账（照代码真值）

项现款本稿
定位calc_top_center_for()：x = 屏宽/2 − w/2，y = TOP_MARGIN(=0) 改 calc_anchor_pos(app, w, h, anchor)：六档各自的 x/y 公式（见下）
取哪块屏主屏 monitor.size()（物理÷scale） 不变用主屏，但改用 work_area：底部两档必须避开任务栏，否则岛压在任务栏上；左右两档各留 16px 边距，避免圆帽贴屏幕圆角
生长方向顶边钉住，只向下长（stage.rs:22 写死 y 恒为 TOP_MARGIN） 顶三档不变；底三档底边钉住、向上长 ⇒ 动画每帧 y = 底边 − h（animate_window 三处 set_position 都要按锚点分支）
停靠形状半胶囊：上缘压平（CSS border-radius:0 0 16px 16px，rgn r_top=0） 底三档镜像为下缘压平（CSS 16px 16px 0 0，rgn r_bottom=0）。build_top_rounded_region 已具备双半径能力，镜像只是把两个参数调换，零新增拼装代码
命中判定IslandShape::HalfCapsule（r_t=pad, r_b=eh/2） 加 HalfCapsuleBottom（r_t=eh/2, r_b=pad）——shape_hit 已是「上下角半径可不同」的通用实现，同样只是换参数
舞台尺寸208×32 / 300×40 / 420×240 / 420×280，本稿一律不动（只动摆位与形状朝向）

六档公式（wa = 主屏 work_area 逻辑矩形，M = 左右边距 16，w/h = 当前舞台尺寸）

锚点xy
顶 · 左wa.left + Mwa.top
顶 · 中wa.left + (wa.w − w)/2wa.top
顶 · 右wa.right − M − wwa.top
底 · 左/中/右同上三式wa.bottom − h（逐帧随 h 变，实现「向上长」）
