待办灵动岛 · 内容活性三动效 设计稿

2026-09-27 · 承接「够不够灵动」讨论的结论：形体灵动已到位（弹簧/形变/分拍），内容灵动未开始—— 胶囊 95% 的时间纹丝不动。本稿做三件事：① peek 实时递减（内容在走）② 事件入场脉冲（世界敲门有回音） ③ glow 跟随光标（受光面液态化）· 基于真实组件 TodoIsland.tsx（tab/热键版）/ TodoIsland.module.css / useIslandSignals.ts
🔴 总红线（规则 8）：三者全部事件驱动、放完即停——没有常驻动画、没有循环 rAF、不加 backdrop-filter。 灵动 ≠ 动得多，岛的第一美德仍是不抢注意力（吸附双态稿 §0 的初始抱怨）。

1 · 动效一：peek 实时递减——最便宜的一针「活」

演示：倒计时每秒走字；跨过 0 线翻红（演示用 5s 压缩时长）
3整理周报素材 14:32

真实口径：dueMs − now < 1h 才走字（mm:ss）；>1h 保持既有静态文案「今天 16:00」；跨过 0 → 翻红（--island-due）+ 一次脉冲。无 dueMs 不显示（既有口径：宁可少说，不编时间）。

实现点：nextDueLabel（TodoIsland.tsx:178）从静态 dueLabel 改为「临近时由 dueMs 现算」—— 新增 useLiveDue(dueMs, active)：active = stage==="peek" && 临近 时挂 1s interval， 返回 mm:ss；active=false 即清。跨 0 的判定在 interval 内（残值 ≤0 → 置 over + 触发一次脉冲回调）。
为什么安全：interval 只在 peek 可见 + 有临近任务时存在（不可见即停，规则 8.1）；每秒重渲染的只有 一个 span（tabular-nums 定宽数字，走字不抖版式）。list/compose 不走字——列表里的到期 chip 是「日期语义」， 秒级跳动是噪音。

2 · 动效二：事件入场脉冲——世界敲门，岛有回音

新待办到达 / 提醒到点：果冻脉冲（顶边锚点，底缘弹）
到点了 回邮件给张工

提醒态：脉冲 + 铃 shake（±13° 三摆 600ms）。新待办到达：只脉冲、不 shake。

全清：勾 stroke 描画（350ms）
今天没有待办了

描画即「刚刚完成」的余韵；1.5s 延迟隐藏照旧，描画不延迟隐藏节奏。

触发判定（防误触发是本节的账）： ① 新待办 = state.tasks.length 比 ref 里的上次值大且岛已挂载超过 1s——首次挂载 / 同步恢复批量灌入（+N 条）不算事件，只算状态（否则每次开应用全屏待办集体跳舞）； ② 提醒 = dueAlert 从 None → Some（Rust 账本点火的那一刻），横幅 30s 清账收回不打扰； ③ 全清 = 进入 clear 态那一刻（collapseToPill 口径不变）。
实现点：一次性 class（.pulse / .shake / .draw.go）+ animationend 摘除；三态互斥时取优先级最高的一个触发（提醒 > 新待办 > 全清）。
reduced-motion：三者全部跳过（usePrefersReducedMotion 现成）——信息不变，只去掉运动。

3 · 动效三：glow 跟随光标——受光面液态化

把鼠标在岛上左右移动：高光圆心跟随入射点
3整理周报素材· 14:32

CSS：radial-gradient(120px circle at var(--glow-x) -40%, …)；JS 只 setProperty 一个变量。

取光标位置不新增 Rust 通道：拦截生效后（set_ignore_cursor_events(false)）岛 webview 能收到 pointer events——前端 pointermove 直接算 --glow-x = offsetX/width×100%， 拒绝「Rust 每 60ms emit 光标坐标」的方案（跨进程事件风暴，收益为零）。
监听范围：仅 data-hover / data-intent 为真时挂（Rust 收事件才收得到 move， 天然对齐）；穿透期零监听零开销。setProperty 改 CSS 变量只触发重绘、不触发 layout， pointermove 高频下安全；intent 点亮的第一帧用进入点初始化（高光从入射处泛起，不是从中间跳出来）。
reduced-motion：不跟随，恒 45% 中位（现状观感）。

7 · 请拍板（三项）

① 递减文案口径：裸 mm:ss（推荐）——胶囊 32px 高，前缀「xx 后到期」挤占任务文字（提醒态的教训）； 蓝色数字 + 已有「今天 16:00」的语境足够。备选带前缀（信息完整但 peek 300px 装不下两句）。
② 描画时长：350ms（推荐）——勾的完整弧长配 300ms 略赶、400ms 略拖；350 不在 U2 四档内， 按既有口径在行内挂 ui-rule-ok（一次性庆祝动画，不进节奏库）。要严格守四档就取 300ms。
③ glow 是否加 100ms 过渡：不加（推荐）——直改变量已经因为 pointermove 本身的连续性而平滑， 加过渡反而出现「高光追赶光标」的拖影感；真机若觉得跳再补。
