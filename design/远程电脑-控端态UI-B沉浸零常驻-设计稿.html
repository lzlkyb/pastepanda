§2 首次连接引导 一次性 · 解决零常驻的可发现性代价

连接成功后画布中央出现一次引导卡（session.id 去重），鼠标滚轮动画 + 两行文案，5s 自动淡出或鼠标靠近顶边立即消失。 键盘捕获提示（A 的"点击画面控制"）合并进这张卡——B 模式下没有底栏灰字，这是唯一的上手告知渠道。

§5 交互规则与实施落点

  1. 浮现：仅顶边 12px 热区唤出（A 是 56px + 首显），260ms 滑入；离开 2.5s 淡出。参数与 A 共用一个组件的两套 preset。
  2. 锁显：链路异常时热区改为常显微光条（3px 高亮线），浮条唤出后警示胶囊锁显——异常永远有两个可见信号。
  3. 引导卡：每会话一次（session.id 去重）， dismissed 状态落本地偏好（与 fsHintDismissed 同机制 useRcSessionPrefs）；靠近顶边立即消失。
  4. 穿透/确认/回滚：与 A 完全一致（pointer-events:none、confirmDialog、乐观更新回滚）。
  5. 实施落点：与 A 同一套 RcSessionCapsule.tsx + preset 参数；额外 + 引导卡组件（~60 行）+ useRcSessionPrefs 加一个 dismissed 键。RcViewTools / RcSessionBar / HUD 按钮 / recentRow 的删除清单同 A 稿 §7。
