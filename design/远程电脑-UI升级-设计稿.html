远程电脑 · UI/UX 升级设计稿

PastePanda · 2026-09 · 在 design/远程电脑-设计稿.html（R0–R2 壳）之上的 美化 + 流程友好升级 · 覆盖会话 HUD / 设备卡片 / 配对向导 / 反馈时序 / 快捷键 · 对齐 U1–U8、L1–L6、V1–V6

本稿要解决的三件事（远程工具的核心焦虑）：
① 对面在不在 —— 设备卡片在线态 + presence；② 我现在能不能控 —— 会话 HUD / 横幅 / 键盘捕获态；
③ 改了有没有生效 —— 画质/范围/剪贴板即时反馈，禁止静默失败（U1 / 规则 15.1）。
装饰性动效排在反馈之后；不做远程 shell / 文件管理 / 无人值守。

一、设计原则（先钉死再画）

维度规则本功能落地
U1 反馈时序<100ms 有响应；>1s 出进度；>10s 可取消画质 pill 立即高亮；连接中 spinner；申请 120s 可取消
U2 动效只 150/200/300/400ms卡片 hover 150ms；在线呼吸 2s 循环仅在线点；prefers-reduced-motion 全停
U3 状态四件套空/加载/错误/部分成功空态三步引导；错误 toast + 按钮回滚；部分成功=「已降到流畅」
L2 图标标签常驻文字，不只 hover所有操作有文字；快捷键进 tooltip/文案
L3 空态答「会出现什么 / 怎么让它出现」首次三步：配对 → 申请 → 确认
V1 层级留白 > 背景对比 > 边框设备卡用背景差分「最近」；边框只做 hover
V3 颜色一屏一强调色主强调 accent；在线 ok；被控 danger；仅状态用色
17.1 鼠标可达快捷键只是加速器Enter/Esc 有，但按钮始终可点
17.6 / 18.4 两级取消先退回预览态再退出Esc1 释放键盘 → Esc2 结束会话
accent 操作/强调 ok 在线/成功 warn 待确认/降档 danger 被控/结束 cyan 仅同步来源

九、指针锁定（可控增强）

锁定指针可选，默认关
为什么需要
不锁定时，鼠标拖出 canvas 边缘会丢 move 事件，远程拖拽窗口/框选体验差。
锁定后指针钉在画面中心，用相对位移驱动远端（绝对坐标仍可由 0..65535 映射）。
默认关；开启后 HUD 显示「指针已锁定 · Esc 或按钮解除」。
工具条状态
指针已锁定 · Esc 解除

十二、关键流程时序

12.1 发起可控

选设备 → 选能力 → 发送 → 等待 → 会话
步骤UI超时/反馈
1 点「远程」能力 pill：只看 / 可控（默认记住上次）—
2 发送申请面板切「等待对方确认…」+ 取消对端 120s 未答 → 自动失败并提示
3 对方同意自动进会话视图，拉首帧首帧 >3s 显示「对方编码中」
4 会话中HUD + 工具条 + 控制条心跳、画质反馈、Esc 两级
5 结束确认 → 回列表；可「重连」被控横幅同时消失

12.2 被控同意

步骤UI
申请到达置顶确认条 + toast（窗口 hide 也能通过事件到）
同意常驻红色横幅（谁 + 能力 + 时长 + 结束）
对方控本机键鼠被注入；UIPI 失败 → 对端 toast
任一方结束横幅消失；End 帧已双向可达
