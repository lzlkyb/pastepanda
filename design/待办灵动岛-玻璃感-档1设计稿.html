0 · 做法（两处改动，全在 .root 上，不新增任何元素）

① 顶部高光：作为 background-image 渐变叠在 --island-tint 之上（background-color 保持变量引用， hover 换色逻辑不变）；渐变段固定 26px——五个舞台高光高度一致，不会在 240px 的展开卡上被拉成半屏光带。
② 顶缘亮线：inset 阴影再加一层 inset 0 1px 0 --island-rim（inset 跟随 border-radius，胶囊与 12px 卡片都生效）， 与既有 1px 描边形成「上亮下暗」的受光关系。
两个值都是岛变量（深浅各一档），置 0 即完全回退到今天的实色——风险锁死在两个 token 上。

每格上 pill 下 list；上排深色壁纸、下排亮色壁纸。高光峰值 .07（深）/ .55（浅，白玻璃上白高光偏隐，主要靠顶缘亮线与描边的明暗差）——第一眼不喧宾夺主就对了，档 1 的目标是「受光的面」，不是「透」。

3 · 性能与边界自查（规则 8 清单）

① 不新增合成层：高光走 background-image 叠层 + inset 阴影，没有新元素、没有 backdrop-filter（8.3/8.4 不适用）； 静态渐变不参与动画，随 .root 纹理缓存。
② 探针不破坏：探针把 --island-tint 压到 .06 测窗口材质时，gloss 层是常量白 .07——on/off 两组同受它影响，像素差仍来自系统层，判据不变（探针注释会补一句说明）。
③ 回退：两个 token 置 0 = 今天的线上效果，随时可撤。
④ 与「无高光」定稿的关系：§4.4 删的是 .34 镜面高光（18:1→6.2:1 的元凶）；档 1 的 .07 有实算背书，属于「弱高光」档——§2.2 自己的结论就是「深色档和弱高光必须成对出现」，本稿即该结论的落地。
