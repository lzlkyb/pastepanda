方案 A · 语义 token 自适应（推荐）

与工具栏激活态同一套令牌：background: var(--accent-light) + color: var(--accent-strong) + 左侧条 var(--accent) + 字重 600。 各主题自动切换，不写死色值（U6）。暗色主题里 accent-light 本身就是深蓝底、accent-strong=亮蓝，仍然清楚。

方案 B · 亮色单独加码

在 A 的基础上，亮色再压一档：底 22% accent、文字用更深的 #025E8F、左条 3px、字重 700。 更「跳」，但要写亮色分轨 CSS；若以后主题再改容易漏改。

方案 C · 大纲侧栏固定深色

不管应用主题，大纲永远深色条（像 VS Code 活动栏）。选中态沿用现在的亮蓝字，对比度稳。 代价：亮色工具栏 + 深色侧栏视觉割裂；面板整套色都要写死，不再跟主题 token。

无论选哪个，建议一并做：① 左条加粗到 3px 或改用 accent 实色（不只靠底色）； ② 选中项字重 600/700（不只靠颜色，色弱用户也能分）；③ 面板底色亮色下不要用 rgba(0,0,0,.12) 半透，改主题实色，避免选中底被冲淡。
