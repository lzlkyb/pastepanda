① 模态快比（升级 DiffDialog）— 改动范围小、风险低

  • 可编辑工具栏新增「差异预览 | 双栏编辑」分段：双栏编辑态下左右各一个 textarea（等宽等行高），改动实时喂给 useDiff 重算差异，行号/增删高亮随输入刷新。
  • 独立入口除「选中 2 条历史 → 对比差异」外，新增主窗口工具栏「🔀 对比」按钮 + 全局快捷键 Ctrl+Shift+D，打开时左栏预填当前剪贴板文本、右栏空白，无需先选历史。
  • AI 闭环工具栏「✦ AI」下拉：翻译 / 润色 / 解释差异 / 合并两侧 / 总结 —— 对选中侧（或选区）调用 getTransform(id).run(text)，结果填入另一侧并实时重算 diff，形成「改→看差→再 AI 改」循环。未启用 AI（aiOk=false）时整条不渲染，与变换面板门控一致。
  • 复用完全复用既有 DiffDialog / DiffPane / useDiff / CSS 令牌；列头「✎ 编辑」为单侧重编辑的快捷开关（与分段视图互补）。
  • 文件仅动 DiffDialog.tsx、DiffDialog.module.css、CardList.tsx（加入口）、App.tsx（注册 Ctrl+Shift+D）、新增 useDiff 调用点——集中在 3–4 个文件。
