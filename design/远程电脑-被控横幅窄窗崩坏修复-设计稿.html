被控横幅窄窗崩坏 — 修复设计稿

对象：src/components/rc/RcControlBanner.tsx + RemoteComputer.module.css 的 .ctrlBanner 一族。 复现宽度：主窗默认 550px、最小 320px（tauri.conf.json）。

0 · 根因

.ctrlBanner 是单行 flex（display:flex，没有 flex-wrap）。 这一行要装 8 个元素，实测固有宽度合计约 1160px：

元素声明 flex-shrink:0550px 窗口 · 实测宽×高320px 窗口 · 实测宽×高
live region 容器（who + pillDanger）否63 × 48（文本折 3 行）63 × 48
.who「正在被「LAPTOP-LZL」远程」否63 × 4863 × 48
.pillDanger「可控」否44 × 2344 × 23
.timer 00:13否33 × 1433 × 14
.scopeNotice 声音提示否（另有 min-width:0）57 × 18118 × 270
.meta 能力说明否22 × 13511 × 270
.audioMuteBtn / .miniBtn / .dangerBtn是保持完整保持完整

横幅内容可用宽度 = 窗口宽 − 24(margin) − 2(border) − 28(padding)： 550px 窗口 → 496px；320px 窗口 → 268px。 上表数字为 CDP 实测（getBoundingClientRect，Edge headless，deviceScaleFactor=1），非盒模型估算。
判据：宽 < 高 即已退化为竖排 —— .scopeNotice 320px 下 18 × 270、.meta 11 × 270，都是「一个字宽、270px 高」的竖条。

中文没有词间空格，min-content 就是一个字，所以「压不动就换行」在这里表现为「压成竖排」—— 这不是溢出，是 flex 的正常压缩行为，所以没有滚动条、没有报错，只有视觉崩坏。

7 · 结论

  • 方案 A（推荐）：改 RcControlBanner.tsx 结构 + 新增 5 个 CSS 类。 两档宽度下均无竖排、无横向溢出，危险按钮始终在右下角。 代价：550px 下比方案 B 高 23px（多一行能力说明），换来的是元素归位、换行可控。
  • 方案 B：4 条 CSS 完事，改动最小，550px 下实测反而是四档里最矮的（112px），单行读数也正常。 代价：320px 下「立即结束」掉到左下角孤行（实测 204px 高）—— 危险按钮跑到了最不显眼的位置，与项目「误触代价不对称」的既有约束冲突；另有 .sp 换行后留下的空行。
  • 方案 C：不建议单独使用（藏安全告知，违反规则 15）。
  • 共同必做（已做）：给 .meta / .timer / .pillDanger / .pillOn / .trustOn / 三个按钮补 flex-shrink:0， 并让 .ctrlBanner 允许折行 + 收尾按钮折行后靠右—— RcOverlay 里另外 3 条旧结构横幅因此不再竖排（实测见 §5）。 但它们的**结构没改**（原因见 §5），所以 ②③ 两条在默认宽度下会从单行变两行。

8 · 落地记录（2026-09-22）

改动落在两处，本稿的 CSS 已在 §2 / §5 与实现对齐：

  • src/components/rc/RcControlBanner.tsx：JSX 改成三段式；删掉占位的 .sp； 身份段包一层 .whoLive（live region 只包 who + pill，计时器在它外面）。
  • src/components/rc/RemoteComputer.module.css：.ctrlBanner 拆 column-gap / row-gap + 加 flex-wrap:wrap； 新增 .ctrlStack / .ctrlTop / .ctrlWho（含 .whoLive）/ .ctrlActs / .ctrlNotes / .ctrlFoot；旧结构横幅的兜底一组规则。

落地与定稿的两处偏差（都是复测才发现的，不是设计改了）：

  • 间距归到 4/8 节拍：ctrlTop 的 10px → 8px、ctrlActs 的 row-gap / 危险按钮间距 6px → 8px、ctrlNotes 的 6px → 8px。 320px 高度因此从 211px 变成 213px。唯一保留的非节拍值是共享壳的 column-gap:10px ——它同时作用于另外四条横幅，本次不动它们的观感，已在代码里写 ui-rule-ok 说明。
  • 计时器位置：定稿的 demo 把计时器放在 .ctrlWho 里（靠内层折行）。 落地时一度把它移到 .ctrlWho 外面（为让它脱离 live region），复测发现 320px 下它会独占一行、横幅变成 226px；改成 .whoLive 包 who + pill 后复原成 213px。 这条偏差正是「设计稿必须真渲染一遍」的价值。

测量口径：Edge headless + CDP getBoundingClientRect；「竖排」判据为 height > width × 1.5 且 height > 24px；固有宽度 = 各直接子元素宽度之和 + column-gap × (n−1)，排除 .sp 的弹性宽度。
