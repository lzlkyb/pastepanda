托盘右键菜单 · UI 升级设计稿

右键托盘打开的是自绘 TrayPopup（非系统原生菜单）。现状把「统计仪表盘 + 库体积」和「高频操作」叠在同一屏， 低频项（贴图管理 / 调整浮标）常驻，退出与设置挤在一起。本稿按「右键要快」压扁信息密度，收拢低频入口。

现状结构（TrayPopup.tsx）：头部（logo+版本+状态点）→ 三张统计卡 → 最近复制（建议+3条）→ 六项操作平铺 → 数据库体积条。宽度约 300px，玻璃根 border-radius:14。

5 · 规格表（落地对照）

项现状升级版规则依据
统计三张渐变图标卡（约 72px）一行摘要 +「监听中/已暂停/栈模式」文字右键要快；U7 颜色不作唯一通道
头部版本VersionBadge 常驻第二行副文案改「剪贴板」；版本进设置/关于V1 层级：主视觉给状态不给版本号
主操作6 项平铺主区 3：显示主窗口 / 暂停监听 / 设置规则 17.2 高频一步
低频贴图管理、调整浮标常驻收进「更多工具」；浮标项栈关闭时禁用+说明不拿错误态当常规路径
退出与设置同列表独立段 + 完整文案「退出 PastePanda」防误点；L1 说用户的话
图标四色渐变 + emoji 混用主操作 accent 单色浅底；仅 danger 用红；全 SVGV3 一屏一强调色；符号统一
recents预览 +「粘贴」+ 第二行 meta（来源 · 相对时间）；首条默认高亮可辨识；右键完 Enter 即贴
库体积常驻进度条默认隐藏；≥80% 警示条 + 清理建议正常不打断，异常才出现
快捷键提示设置写 Ctrl+S（易误解）只保留真实热键（如显示主窗口）；无热键不写L5 不靠猜、不给假线索
高度随内容 setSize 易抖动默认高度钉住（含 3 条 recents）；仅空态/错误变高打开稳定、不跳
动效与主窗弹窗同级入场 150–200ms 淡入 + 轻微上移U2 快/标准档
明确不做：托盘菜单里做完整仪表盘 / 可拖拽排序 / 嵌套三级菜单 / 可点击的统计跳转深链。 右键路径的唯一目标是「快进快出」；要细看数据去主窗口。
