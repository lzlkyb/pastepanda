§3 几何实测（悬链线现算，卡片宽由公式现算，不是定值）

下垂量 sag = clamp(跨距 × 档系数, 6, 60)（档系数 浅 1.0% / 中 2.0% / 深 3.2%）； 由 sag = a·(cosh(S/2a) − 1) 二分反解 a（80 次）； 屏幕坐标（y 向下为正）里绳的下垂量是 d(x) = sag − a·(cosh((x−mid)/a) − 1)： 端点处 d = 0（最高、贴留边 16px），中段 d = sag（最低）。 夹子倾角跟切线走：θ = −atan(sinh((x−mid)/a))（左半段为正/顺时针，右半段为负）； 卡纸受重力保持竖直（rotate 恒 0），只有夹子跟切线倾——这是挂画的真物理，上一版把整卡歪着排是错的。 卡片宽 imgW = min(240, floor((可用跨距 − (N−1)×12) / N) − 16)，高 min(180, imgW/宽高比)； 卡纸外框 = 图 + 左右 8×2 + 上 8 + 下 20（caption 区）；imgW 算出来 < 96 时不缩窄，改让多出来的卡片排队不进绳。

读数由脚本现测（–）。判据用 offset* 整数口径：offsetWidth/offsetHeight 与公式精确相等（Δ0）；offsetLeft/offsetTop 是整数、而公式 cx / y 可能带 .5 ⇒ 位置项有 ≤0.5px 的整数取整地板，这是 offset API 的固有精度、不是几何误差（.hang 带 translateX(-50%)，故「offset 左缘」= offsetLeft − offsetWidth/2）。rect ÷ 舞台scale 只印不作判据：getBoundingClientRect 会被吸附到物理像素，本机 dpr=1.25 时 1 物理px=0.8 CSS px，即便把舞台 --k 临时置 1 也仍有 ~0.4px 量化地板（实测 rectW=141.11 vs 228×0.62=141.36）——所以 0.1px 阈值在缩放上不可达，改判 offset 的 0.5px 整数地板。入场动画进行中的卡，.frame 被 keyframe 位移，量它必然假红 ⇒ 整行标「动画中·跳过」，落定后 done() 自动补一次重量。

§6 不挑截图工具：触发链与真实时延

关键事实：外部工具不需要「被支持」。自家写入要报备，外部写入没人报备，所以必然被采集。

环节源码对「微信截图 / Snipaste / Win+Shift+S」意味着什么
写入识别clipboard_monitor.rs:224-372 PasteSuppress，begin_write :247、own_write_reason :356-371；竞争闸 RACE_MAX=500ms、身份窗口 IDENTITY_WINDOW=3000ms只有自家 8 个写入点会 begin_write。第三方进程的写入不会命中 own_write_skip ⇒ 一定进采集分支
采集触发AddClipboardFormatListener + WM_CLIPBOARDUPDATE，50ms 尾部防抖 + 1000ms GetClipboardSequenceNumber 兜底事件驱动，非轮询 ⇒ 外部截图后最快 ~50ms 被读到；若那次更新被自家写入吃掉，最迟 1000ms 兜底补采
图片分支:1299-1340（get_image()=CF_DIB、MAX_IMAGE_BYTES=50MB、dedup.is_recent DEDUP_TTL=1500ms）；:1127-1133 注释直接点名「微信截图无监听线程所以没有此竞争」CF_DIB 是几乎所有截图工具的写法 ⇒ 链路本身通用。1500ms 合并窗是「湿」的真实来源，也是唯一会让挂上晚一拍的地方
入库广播process_image :1747/:1782 emit；自家截图另有一条 screenshot.rs:1640-1643 emit；前端单点 init.ts:110-160绳层只监听 clipboard-changed 一个事件即覆盖两条来源 ⇒ 不需要给截图单独造 done 事件（现无该事件，pinImageAt 只 invoke 不 emit）
分级原料capture_foreground_source :1376-1397 → HistoryItem.source / source_icon能拿到前台窗口标题/exe ⇒ 可稳定区分「微信/Snipaste/截图工具」与「浏览器复制图片」的大多数情况；不能当拒挂依据（白名单外的 ShareX/PixPin 会被漏）——这就是你选「全挂 + 分级」的理由

链路做不到的两件事，写在这里不粉饰：① 无法区分「截图产生的图」和「Ctrl+C 的一张网图」，只能靠 source 启发式分级；② 自家截图若正卡在 500ms 竞争闸/3s 身份窗口里，挂上会晚一拍（最迟 1000ms 兜底），这一拍在舞台里点「模拟微信截图」可当场看到计时。
