浮层风格统一 · 方案与设计稿

以刚上线的编辑器查找悬浮卡片为北极星，盘点全应用「短命浮层 / 控件」与它的差距。 目标不是重画整个 UI，而是让同一类东西在六套主题下长成同一张脸，并守住规则 8.3（卡片禁无意义 backdrop-filter）。

0 · 北极星：查找悬浮卡片（已上线）

1 7.1.0问题记录
2 知识库模式下3栏状态问答回车太短
3 自己写笔记的时候没办法增加空格
4 交互问题太多了这个模式下的交互逻辑和友好性全部查一下

北极星五要素：① 不透明 --card-bg　② 外圆角 12 / 控件 8　③ 双层影（细环 + 抬升）　 ④ 28px 控件 + 胶囊开关（选中 accent）　⑤ 可拖动浮层有抓手。

3.2 材质双轨（方案 B 的关键）

工具浮层 · float-card

生命周期短、要盖在正文上读字、数量可能叠多层。

  • 查找悬浮卡、右键菜单、子菜单
  • Toast、HelpTooltip / 气泡
  • 建议条、KbSync 浮层、卡片菜单
  • 底：var(--card-bg) 不透明
  • 影：--float-card-shadow
  • 禁 backdrop-filter（规则 8.3）

窗口级 · float-glass（保留）

整窗/场景沉浸，用户会停留，背后是皮肤场景或空背景。

  • 托盘弹窗根、快捷面板根
  • dialog-box 默认玻璃（工作型继续 dialog-solid）
  • 底：--glass-dialog-*
  • 场景主题 shell blur 仍默认 none

4 · 三套方案

方案 A · 最小对齐

  • 只改右键菜单 + 子菜单 + Toast + tip 圆角
  • 全部换不透明 card 壳
  • 不动建议条 / 流程图 / 按钮圆角
  • 不动 dialog / 托盘

优点：改动 3–4 个文件，见效快，立刻和查找一致。
缺点：按钮 r7、建议条 r9 等阶梯债仍在，后续还会再裂。

方案 B · 双轨材质 + 阶梯

推荐
  • A 的全部内容
  • 新增 token：--float-card-* / 阴影 / 圆角阶梯
  • 建议条、KbSync 浮层并到 float-card
  • 全局 btn-* 圆角 7→8
  • 文档化「工具浮层 vs 窗口级」判定标准
  • 流程图浮层仅并材质，不改交互

优点：一次收口，六主题自动继承；性能与可读性都守住 8.3。
缺点：约 8–12 个 CSS 文件 + 1 份 token 表，需逐界面点验。

方案 C · 全面玻璃

  • 查找卡也改回玻璃 blur
  • 所有浮层统一 glass-popover
  • 强化皮肤场景沉浸

优点：视觉「最炫」，皮肤场景透出强。
缺点：与查找刚确立的可读性/性能方向相反；规则 8.3 会大面积破戒；叠层 GPU 乘法。不推荐。

建议选 B。A 可以当作 B 的第一阶段（先上菜单/Toast/tip），第二阶段再收建议条、按钮阶梯、流程图材质。 实施顺序按「用户每天都看得见」排序：右键菜单 → Toast → Tooltip → 建议条 → KbSync 浮层 → 按钮圆角 → 流程图浮层。
