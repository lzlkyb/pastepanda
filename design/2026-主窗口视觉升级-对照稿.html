1一眼能看到的 5 处变化

1氛围底

纯 #F7F7F8 → 静态天空/海面淡渐变（青 + 微紫）。一次绘制，无动画、不采样列表。

2侧栏景深

实色 #EFF1F5 → 半透明 + 磨砂，主区像浮在侧栏之上。

3卡片厚度

单层浅阴影 → 多层（近影 + 中影 + 描边）+ 顶部微光，选中带柔光环。

4控件微光

搜索/筛选/页签从灰方块改成白玻璃感；选中页签带渐变实底 + 投影。

5选中强调

侧栏左条带光晕；选中卡片光环更柔；图标槽渐变更透气。

2落地到 token（只动 Ocean 块即可试）

位置改前改后建议
--app-bg #F7F7F8 多层 radial-gradient + linear-gradient（见稿内 .winB）
--sidebar-bg #EFF1F5 rgba(244,247,251,0.72) + 壳层 backdrop-filter（整栏一次，不是每行）
--glass-card-shadow 0 1px 3px … 三段：近影 + 0 6px 16px + 描边环
--card-selected-* 浅蓝底 + 硬环 白→浅蓝渐变底 + 3px 柔光环 + 淡投影
搜索框 / 页签 实底灰 半透白 + 内高光；激活页签渐变实底
性能边界：氛围底是静态渐变（合成器可缓存）；侧栏 blur 只挂在一个容器上。 卡片列表仍无 backdrop-filter。多窗口 × 场景动画的乘法风险不引入。

3不改

项原因
布局骨架（顶栏/侧栏 180/卡 72）信息架构已稳，改布局成本远大于观感收益
ModeSwitcher 实色滑块透明顶栏下实色是正解，只微调圆角与投影
图标色相 amber/violet已按对比度压过
内容与徽标语义这版只谈「皮」
