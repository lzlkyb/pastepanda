今日速记 B2 #3 D11

Memos（62.5k★）验证的那条工作流：捕捉要有一个低摩擦的聚合地。一天一条笔记，随手往里丢，不用先想放哪个文件夹、不用起标题。

规划原文有一处说不通，本稿按拆开后的理解设计。
D11 写的是「热键把选中卡片一键追加」。但全局热键按下时窗口可能根本没开，没有「选中卡片」这回事。 所以拆成两个入口：全局热键抓剪贴板当前内容（不开窗口就能记，这才是 Memos 那条工作流的价值）， 窗口内右键菜单对选中卡片操作（在列表里挑一条丢进今天）。两者共用同一条后端命令。

「今日速记」是内置项，与「全部笔记」「未分类」同级，画在同一段里——它不是文件夹，不能改名删除移动。

左：未选中，日历收起。右：选中后就地展开当月，蓝点=那天有速记，方框=今天，实心=当前查看的那天。

为什么日历不常驻？ 侧栏只有 180px（与记录模式 Sidebar 同宽，不能为它加宽）。 一个月历要占掉约 120px 高，常驻就把文件夹树挤到屏幕下半截。 只在选中「今日速记」时展开——那时用户的意图正是翻日期，文件夹树反而不重要。

3 · 两个入口

① 卡片右键菜单

紧挨「转为笔记」，因为它俩是同一类动作的两个力度：转为笔记=这条值得单独立一篇；追加到今日速记=先丢进今天，回头再说。

② 全局热键 Ctrl+Alt+D

抓剪贴板当前内容追加，窗口不用打开、不用抢焦点。成功后走托盘轻提示，不弹窗不抢焦点——它的全部价值就在于不打断你手上的事。

默认值选 Ctrl+Alt+D（D=Daily）：现有 7 个热键占的是 Ctrl+Alt+V/Q/K/P、Alt+V、Ctrl+Q，Ctrl+Alt+数字 被索引粘贴占用，D 不冲突。可在设置里改。

剪贴板是空的 / 内容与上一条速记完全相同时：不静默成功，给一句「剪贴板是空的」或「这条刚记过」（规则 #15.3）。 热键类操作看不见界面，静默失败会让用户以为热键坏了，然后反复按。

4 · 数据模型：身份不能靠标题

notes 加一列 daily_date TEXT（YYYY-MM-DD），建唯一索引。

ALTER TABLE notes ADD COLUMN daily_date TEXT;
CREATE UNIQUE INDEX IF NOT EXISTS idx_notes_daily ON notes(daily_date)
  WHERE daily_date IS NOT NULL;   -- 部分索引：普通笔记的 NULL 不参与唯一性
为什么不靠「标题等于今天的日期」去找？ 标题用户随时能改，也可能手动建一条同名的。 一旦标题被改，明天开始就会另建一条，今天这条变成孤儿——而用户根本不知道发生了什么。 这与 #5 导出时「文件名不可逆，所以身份靠 pastepanda_id」是同一个教训，那次已经踩过。

速记笔记就是普通笔记：能编辑、能加标签、能导出、能被搜索、能生成 AI 摘要。daily_date 只是多一个身份标记。

一个要你拍板的口径

问题方案
速记算不算「未分类」？建议排除。「未分类」的语义是「该归档还没归档」，而速记本来就不需要归档——不排除的话，一周后未分类里全是速记，那个入口就废了。「全部笔记」里保留（它确实是笔记）。

5 · 边界（明确不做）

  • 不做模板引擎——D11 写死的边界，那是 Templater 的路
  • 不做「昨天的速记自动结转」——那是待办清单的行为，速记是流水账
  • 不做一天多篇——一天一条是这个功能的定义，多篇就退化成普通笔记
  • 不做提醒/打卡/连续天数——正面清单之外，且与「永不打扰」冲突
  • 日历不做无限翻——见第 1 节

6 · 验收

  • 热键按一下 → 托盘轻提示 → 打开知识页面，今天那条里多出一段，带时间戳与来源
  • 同一天连按三次 → 还是一条笔记，里面三段
  • 把标题改成别的字 → 再按热键 → 仍然追加到这条，不新建
  • 跨零点再按 → 新建明天那条，昨天那条不动
  • 剪贴板为空时按 → 有明确提示，不是没反应
  • 日历上有速记的日期带蓝点；点空白日期进去是空态而不是报错
  • 速记不出现在「未分类」里（若第 4 节口径通过）
