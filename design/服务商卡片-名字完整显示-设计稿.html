2026-08-11 · 所有示例按真实约束渲染：弹窗 420px、body padding 20px → 内容宽 380px。截断是真实发生的，不是示意图。

根因：三列布局在 420px 弹窗里放不下 数学问题

列宽 = (380 − 6×2) ÷ 3 = 122.7px；扣掉 padding 8×2 与 border 1×2 → 卡内可用 104.7px。

最后一行是关键：一个标签都没有时，8 个汉字仍然放不下。 所以只要「名字 + 标签同一行 + 三列」，怎么调 CSS 都必然截断——上一轮的 ellipsis 只是把「高度不齐」换成了「名字不全」。
另外顺手查出两个碰撞（比初稿写的多一个）：.provCk（选中的 ✓）是 position:absolute; right:4px; top:4px—— ① 在内置卡上它压住最右侧标签（选中 Agnes 时 ✓ 盖住「已配置」）； ② .provDel（删除 ✕）也是 right:4px; top:4px，两者坐标完全重叠——选中自定义服务商时 ✕ 直接盖住 ✓。
实现时的做法比初稿更彻底：不是给卡片加 padding-right，而是把 ✓ 改成标签行里靠右的 inline 元素（margin-left:auto）。 两个碰撞一起消失，且内置卡右上角再无绝对元素，名字能用满 104.7px。 自定义卡因为还有 ✎ / ✕（占到距右 38px），单独给名字加 .provNameInset { padding-right: 40px }。
