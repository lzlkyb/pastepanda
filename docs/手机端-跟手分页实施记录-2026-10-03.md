# 手机端跟手分页实施记录

日期：2026-10-03。用户选择 B 方案，并明确要求本次直接实施、跳过 HTML 设计稿。

## 已完成

- 设备／文件／设置使用三个真实且唯一的页面实例；横向拖动显示真实相邻页，不复制业务组件。
- 普通区域近似 1:1 跟手；同一个位置同时驱动页面和底部导航选中背景，移除松手后另播进入动画的断裂。
- 起手小于 10 CSS px 时不判方向；明确竖滑交给浏览器，未定方向的斜滑继续观察。横向锁定后不反复切换方向。
- 慢拖超过页宽 22% 可翻页；短甩需至少 28 CSS px 且末段速度达到 0.45 px/ms。使用最近 100 ms 样本，停留不稀释后续甩动，松手坐标参与判定。
- 快速反拉可取消；吸附动画中再次触摸从当前位置接管。一次甩动最多跨一个相邻页，首页／末页轻阻力回弹，不循环。
- 复用项目现有位移弹簧参数；仅拖动和吸附时更新位置，没有新增常驻动画或轮询。隐藏、失焦、旋转及进入远控时取消动画。
- 三页各自持有滚动容器，切页及进入远控保留文件操作与滚动位置。非当前页使用 inert 和 aria-hidden，不接受点按或键盘焦点。
- 设备探测仅在设备页激活时执行；文件目录加载／申请倒计时沿用 active 门控；设置页弹层与历史加载增加 active 门控。
- 输入框、滑块、文字选择、标记为独立手势的控件、弹层和远控画面不接管。保留左右各 24 CSS px 的系统边缘区域，以及底部标签点按入口。
- 减少动态效果开启时保留切页功能，拖动不移动大幅页面。

实现入口：`src-mobile/App.tsx`、`src-mobile/App.module.css`、`src-mobile/ui/useMobileTabSwipe.ts`。删除被统一分页动画替代且无调用的 `useMobileTabMotion.ts`。页面生命周期门控位于 `RcDevicesView.tsx` 和 `RcSettingsView.tsx`。
