# 流程图编辑器视觉调研 · 怎么把图做"好看"

> 目的:我们(PastePanda)的流程图编辑稿被用户评价"太丑"。本文调研 2026 年视觉水平最高的流程图/白板工具,提炼"好看"的可复用手法,并映射回 PastePanda 现有的玻璃拟态 + indigo/cyan 设计语言,给出重设计方向。
> 结论先行:**我们不是缺功能,是缺"设计语言"**。现在稿子是"开发态"的裸节点(硬边框、平色块、直角连线),而好看的工具都遵循同一套视觉语法:形状表语义、柔阴影给体积、圆角降攻击性、低饱和淡彩做层次、CSS 变量做主题、动效给生命。

---

## 1. 标杆产品与它们代表的视觉流派(2026)

| 产品 | 视觉流派 | 一句话特征 | 许可证 / 可嵌入性 | 对我们的启发 |
|---|---|---|---|---|
| **tldraw** | 精致几何(类 Figma) | 干净形状、柔和阴影、圆角、克制配色;被认为"最像专业产品" | MIT SDK,可嵌入 React | **首选参考**:我们要的"产品内嵌、专业不草图"就是它 |
| **Excalidraw** | 手绘草图(rough.js) | 故意抖动的线、蜡笔感;传达"探索中/非正式" | MIT | 反例:剪贴板工具要专业可信,**不选手绘** |
| **draw.io** | 精确技术图 | 功能强但界面密集、默认样式土 | Apache | 反例:别学它的默认丑,学它的"真符号语义" |
| **Napkin AI** | 演示级精修 | 把文字变成"像设计过"的图,社交友好审美 | 闭源 SaaS | 学它的**配色克制 + 留白 + 字体层级** |
| **Whimsical** | 固执的美学系统 | 有观点的一套风格,统一好看、学习曲线低 | 闭源 | 学它的"**opinionated style system**"(我们该有自己的) |
| **Eraser.io** | 清爽架构图 | diagram-as-code,干净云架构图 | 闭源 | 学它的"淡色分层 + 正交连线" |
| **Flowova / Lucidchart** | 真流程符号 + 多主题 | 真菱形/矩形、40+ 主题、不"AI 味扁平" | 闭源 | 学它的"主题系统保证跨图风格一致" |

**关键洞察**:好看的工具分两类——"草图感"(Excalidraw)和"精致感"(tldraw/Napkin/Whimsical)。剪贴板/生产力工具应走**精致感**,且要走**我们自己的玻璃拟态 identity**,而不是套用别人的。

## 2. "好看"的可复用手法(从真实实现提炼)

### 2.1 形状表语义,颜色不表类型(最重要的一条)
- 来源:zread 架构/流程图设计指南。**"shape carries type, not color"**——开始/结束=胶囊(oval/pill)、步骤=圆角矩形、决策=菱形、合并=小圆点。
- 颜色只保留给**焦点/开心路径/最重要节点**(一图只 1–2 个强调色,绝不在每个框都上 accent,否则失去层次)。
- 我们之前的稿子:所有节点同色硬边框 → 平、乱、没重点。

### 2.2 柔阴影给"体积感"(Material/Apple 卡片感)
- React Flow 高颜值教程标配:`shadow-sm → shadow-lg` 悬停过渡,制造"抬起来"的物理感。
- draw.io 小清新配方:阴影 X/Y 偏移 2px、模糊 4px、透明度 20%,**1px 白色描边** → 立刻高级。
- 我们之前:无阴影或硬黑边 → 平贴、廉价。

### 2.3 圆角降攻击性
- 节点圆角 8–12px;正交连线 `rounded=1`(转角圆滑)。
- 我们之前:直角矩形 + 直角折线 → 生硬。

### 2.4 低饱和淡彩做层次(而非高饱和平涂)
- svg-flowchart 技能推荐淡彩色板(明度高、饱和低):淡蓝 `#E0F2FE`/描边 `#0EA5E9`、淡绿 `#DCFCE7`/`#16A34A`、淡紫 `#EDE9FE`/`#7C3AED`、淡青 `#CFFAFE`/`#0891B2`。
- 一图主色 **2–3 种**,同色系深浅区分层级;避免荧光色、避免色相过多。
- 渐变填充加分:线性 120°、主色 80% / 辅色 60% 透明度(画布分层时不同层用不同渐变方向)。

### 2.5 连接点(handle)与连线美化
- Handle:覆盖默认小方块 → 渐变背景 + 白边 + 略大圆点(`!w-3`),成为精致装饰。
- 连线:统一线宽 1.5–1.6px、`stroke-linecap/linejoin=round`、柔和有色线(淡蓝/淡绿/淡紫,与节点协调);关键路径用 `animated` 流动或 accent 色箭头引导视线。
- 我们之前:默认灰细线、直角硬折。

### 2.6 选中反馈用"环"不用"硬边"
- 选中:`ring-2 ring-[主题色]` 高亮环 + 增强阴影,**不是**把边框变黑变粗。
- hover:节点轻微上移 `translateY(-2px)` + 阴影加深。

### 2.7 渐变描边做"贵气"(可选进阶)
- 高颜值节点用 `::before` 旋转伪元素做 conic/linear 渐变边框(√2 对角尺寸确保全覆盖);用于强调/焦点节点。

### 2.8 主题用 CSS 变量(光暗一键切)
- tldraw 把全部颜色定义为 CSS 变量(`--tl-color-selection-fill` 等),切 `.tl-theme__dark` 即整体换肤。
- **这点和 PastePanda 完全一致**——我们已有 6 套主题的 `--accent`/`--glass-*` 令牌,流程图应直接消费这些变量,而不是另搞一套。

### 2.9 留白、字体层级、语义图标
- 节点内:图标(emoji 或 SVG)+ 标题(粗)+ 描述(细灰),`space-y-3` 垂直节奏。
- 图标题可用语义 emoji(🚀部署 / 🔐认证 / 📊数据流),但**节点框内不用 emoji**(破坏对齐)。
- 图例做成与内容分离的横向细线分隔条,不浮在图里。

## 3. 映射回 PastePanda:我们的视觉方向

现有身份:**玻璃拟态(glassmorphism)+ indigo/cyan**,6 套主题(ocean/ocean-dark/midnight/forest/blossom/dawn),已定义 `--glass-*` 与 `--accent` 令牌。流程图编辑器应**延续同一套语言**,而不是引入陌生风格。

### 3.1 节点视觉规范(建议)
| 要素 | 规范 |
|---|---|
| 背景 | 玻璃感:`background: var(--glass-bg); backdrop-filter: blur(12px)` 半透明 + 1px `var(--glass-border)` 描边 |
| 圆角 | 12px(开始/结束用 999px 胶囊) |
| 阴影 | `0 4px 16px rgba(0,0,0,.12)` 常态,hover `0 8px 28px` + `translateY(-2px)` |
| 描边 | 1px 半透明白/主题色;`selected` 加 `ring-2 ring-[--accent]` |
| 决策节点 | 真菱形 + 淡紫系(唯一允许的"彩色语义",因形状已表类型,这里色仅作辅助) |
| 焦点/开心路径 | 最多 1 个节点用 accent 渐变描边(conic),其余保持中性玻璃 |
| 图标 | 节点左/上角 SVG 图标(用当前主题 accent 着色),不堆 emoji |
| 字体 | 标题 `600` + 正文 `400` 次级灰,层级清晰 |

### 3.2 连线规范
- 默认:1.5px、`round` 转角、柔和 cyan/indigo 系淡色;
- 关键路径:`animated` 流动虚线 + accent 色;
- 决策分支标注 YES/NO 于小遮罩标签上。

### 3.3 画布与主题
- 画布底色跟随主题(`--bg`);网格点用极低透明度 accent;
- 全部颜色走 `--accent`/`--glass-*` 变量 → 切 6 主题自动协调(与产品其余部分一致);
- 暗色主题下降低阴影强度、提高描边亮度。

### 3.4 与 React Flow 的落地要点
- `@xyflow/react v12` 自定义 `nodeTypes`(process/decision/start/end/io)+ 自定义 `edgeTypes`(animated/static);
- 节点组件外声明 `nodeTypes`/`edgeTypes`(避免重渲染);
- Handle 用 CSS 覆盖成渐变圆点;
- 撤销重做 zundo、自动布局 dagre/elkjs 维持原 P2 决策不变。

## 4. 我们当前稿子的具体"丑点"对照

| 当前问题 | 来源 | 改法 |
|---|---|---|
| 节点硬黑/灰边框、平色块 | 开发态裸样式 | → 玻璃背景 + 1px 半透描边 + 柔阴影 |
| 直角矩形 + 直角折线 | 默认 React Flow | → 圆角 12px + `rounded` 正交连线 + round 线帽 |
| 所有节点同色、无重点 | 无视觉层级 | → 形状表语义 + 仅 1 个 accent 焦点节点 |
| 无悬停/选中反馈 | 缺交互态 | → 选中 ring + hover 上移加深阴影 |
| 连线细灰硬折 | 默认 edge | → 1.5px round 柔色 + 关键路径流动 |
| 与产品整体风格割裂 | 另起炉灶 | → 直接消费 `--glass-*`/`--accent`,6 主题联动 |
