1当前 AI 架构现状（3 分钟看懂）

1.3 反馈闭环 —— 半通半断

✅ 已通的部分
用户改 AI 产物 → 提取特征标签 → ai_feedback_add → ai_feedback_stats (算 edit_rate) → 攒够 3 次同方向 → 提议「记住」 → pref_signal_accept → 写入 action_prefs → run.rs 拼进 system prompt → 下次该动作输出真的变了 ✅
❌ 断的部分
① 画像级特征（role_scores 等）从未进入 system prompt —— 不存在 profile_prompt.rs —— 翻译不知道你常处理代码 —— 总结不知道你偏好要点 ② profile_action_boosts 从未读取 edit_feedback.edit_rate —— 一个产物被改得再狠 —— 推荐权重也不会降
Agent 循环完全没有：ai_plan_chain（规划）与 ai_run（执行）之间没有「执行→观察→再决策」的循环。动作链（chains.rs）是人工搭建的静态线性流程，不是 AI 动态生成方案后自动逐步执行。

2与行业对标的差距：为什么现在不是 Agent

行业（2026）已从「附加聊天框」进入「可托付智能体」阶段——任务理解、计划分解、工具调用、跨应用执行、持续记忆、结果校验。PastePanda 的本质差距不是功能数量，是五条结构性缺口：

①规划与执行断开，没有闭环
ai_plan_chain 生成方案就结束，剩下全靠人手动点。缺的是「感知→思考→行动→观察」这个 Agent 定义本身要求的闭环结构。
②记忆存得住，但用不上
画像特征没进 prompt（D1），edit_rate 没进权重（D2a）。且缺「事件聚合」——只能「找一条内容」，不能「想起一件事」。
③学习系统看不见半个产品
AiQuickBar 与卡片右键菜单无行为埋点，高频入口不进 action_events；56 个变换里多结果/双输入类被排除在 registry 外。
④没有可解释性
推荐给出顺序却不说「为什么排第一」。没有可解释就没有信任，「可托付」无从谈起。
⑤AI 能力藏在后台，前台无感
四层记忆/画像/意图/动作链真实存在，但多在设置页/后台，用户日常无感知。「可托付的剪贴板智能体」仍是行业空白，是差异化空间。
综合
解决 ①②③④，才能拿到「可托付剪贴板智能体」的位置。⑤ 是把这些能力让用户感知到。

3产品愿景 / 长期蓝图

3.1 北极星

终极剪贴板 = 个人记忆（记得住）+ 环境智能（主动想到）+ 可托付执行（替你办成）
云端大模型为引擎、本地优先为前提、脱敏前置为底线。让「复制-粘贴」变成用户与数字世界之间真正智能的接口。
  • 本地优先不是障碍，是「懂用户」唯一合法前提——红线②约束的是数据去向与用户控制权，纯本地内容记忆与红线完全兼容，反是相对云端竞品的结构性优势。
  • 三个词都可度量：懂用户（行为/内容/偏好三层模型）/ 自进化（接受·修改·拒绝真正回写）/ 有思想（推断「你在调 bug」、预判下一步）。
  • 闭环结构：感知 → 记忆 → 推断 → 建议/动作 → 反馈 → 回写记忆 → 下一次更准。

3.2 三支柱现状与要补的事

① 个人记忆
Personal Memory
复制物统一编码成带「意图+来源+时间戳」的记忆碎片，能回答「我上周给客户整理的那段报价在哪」。
✅ 已具备
四层记忆、用户画像、语义搜索、统一历史表（五型 + md5 智能合并）
📋 要补
跨模态统一编码、记忆快照趋势、可解释召回、跨设备 RAG
② 环境智能
Ambient Intelligence
从「等你粘贴」到「主动在场」：粘贴瞬间把最可能对的那条顶到候选区第一位——是预判，不是搜索结果。
✅ 已具备
来源 App 信号（复制时记录）、目标 App 信号（粘贴时记录）、候选区雏形
📋 要补
重排序、意图标签、适时提示（轻量规则，不强制打断）
③ 可托付执行
Trustworthy Execution
从「原样粘贴」到「智能执行」：一句自然语言指令自动拆步、调工具、跨应用执行，每步可预览可回滚。
✅ 已具备
动作/链/计划骨架、脱敏守卫、流式输出+可回滚改写
📋 要补
Agent 智能粘贴链、跨应用动作、脱敏前置（出云前）、闭环体验
「可托付执行」精确定义：可托付 ≠ AI 自己决定干什么，而是「你授权过的事，它能替你连着做完，且每一步可预览、可中断、可撤销」。这是路线图 P1 的设计前提。

3.3 红线兼容设计（贯穿三层）

红线如何遵守
① 学习只影响排序，永不自动执行内容记忆只影响推荐/改写参数；动作链/计划永远由用户手动触发确认
② 使用日志永不出本机、可见可删内容层纯本地存储；设置提供「记忆管理」：查看摘要、一键清空
③ shell 命令永不自动执行不新增任何 shell 能力；跨应用动作走应用层 API，非命令执行
敏感内容防护密钥/凭证入库前拦截；出云前脱敏前置
