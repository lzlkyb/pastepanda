# 手机端 · 真机验收清单（2026-10-05）

> 六轮手机端交互改动（10-02 触屏升级 / 四种操作方式 / 10-03 分页手势与 Scroll Snap 导航 / 统一提示 / 10-04 画面优先布局 / 10-05 交互收口）的共同欠账：**全部未经真机验收**。
> 浏览器与单测不能替代真机（触摸采样率、WebView 分辨窗口模式、系统返回键、摄像头权限、输入法行为都只在真机上真实存在）。
> 本清单合并此前各文档的遗留项 + 本轮收口的新增验证点。建议按顺序执行，每项记录「通过 / 复现步骤」。

## 1. 分页与导航（Scroll Snap 方案的生死判定）

- [ ] 快滑 / 慢拖 / 斜滑 / 反向滑，每组 ≥20 次：翻页是否跟手、是否误触、是否停在整页（每组 30 次的旧口径可放宽，但要覆盖四个方向）。
- [ ] 连续同向滑两次：第二次是否生效（旧 bug，已修，需真机复验）。
- [ ] 滑动中点按业务按钮：兼容点击是否被正确吞掉、下一击是否恢复。
- [ ] 底部导航点按：相邻页平滑、跨页即时；弹层内点导航是否等弹层关闭后执行。
- [ ] **兜底判定**：故意在页面中间停住（慢拖中途按住不动再松手），确认最终落在整页、按钮可点（本轮 moving 滞留兜底，真机可能根本到不了那条路径——到不了即通过）。
- [ ] 若手感整体不达标（吸附迟钝 / 跟手丢帧），记录证据 → 触发「重新评估承载方式」的既定口子。

## 2. 会话输入（四种操作方式）

- [ ] 触控板（默认）/ 直接点击 / 独立触控板 / 浮动鼠标 四模式切换与记忆（杀进程后保持）。
- [ ] 单击 / 双击 / 长按右键 / 长按拖拽；点按窗口口径已收口为「550ms 充能前抬起都算点按」——重点体感：稍慢一点的按住抬起是否仍像单击（不应出现「点了没反应」）。
- [ ] 先移动后点击：hover 菜单（如任务栏右键、浏览器标签悬停）是否先悬停再点击。
- [ ] 双指滚动 / 捏合缩放边界（0.5–4.0）、回正（适应屏幕）；画面手势与电脑滚动不串。
- [ ] 独立触控板 / 浮动鼠标模式下画面只移视野；点「滚动」按钮后滚动作用于电脑。
- [ ] 修饰键条：Ctrl/Alt/Shift/Win 挂起 + 组合完成自动释放；文本输入（打字/直发两档）中文候选上屏。
- [ ] **发送失败横幅（本轮新增）**：会话中把电脑断网/杀后台，操作手机端 → 应出现「操作未送达电脑」横幅；恢复后下一次操作横幅自动消失。

## 3. 横屏

- [ ] 锁横屏按钮：全屏失败与旋转锁失败现在是两条不同文案，分别触发验证（系统锁自动旋转时 vs 禁全屏的 ROM）。
- [ ] 工具把手：收起/唤出、连接角标常驻；键盘展开时工具栏隐藏。
- [ ] 鼠标辅助侧栏、 ModifierBar 横屏高度（≤40dvh）。
- [ ] 刘海 / 系统栏四侧 inset：状态头、反馈槽、画面不被切。
- [ ] 横屏工具栏首次引导（**已实施**，见 `design/手机端-横屏工具栏首次引导-设计稿-2026-10-05.html`）：首次进横屏自动展开 15s 倒计时 → 收起后把手脉冲 + 气泡 → 主动打开/点画面/切竖屏后本会话不再出现；教学期间工具栏各入口可用。

## 4. 软键盘 / 系统交互

- [ ] 中文输入法（至少讯飞 / 搜狗 / Gboard 之一）：候选上屏、draft 提交、键盘收起不丢草稿（会话内）；断开/换设备时草稿丢弃为已知取舍。
- [ ] 键盘弹出时底栏/通知不被遮挡（键盘判定 heuristic 仍是 WebView 分辨窗口模式相关，本轮未改，真机必验）。
- [ ] 系统返回键：会话中返回 = 收键盘 / 断开确认；弹层中返回 = 关弹层；主页面返回 = 退出。
- [ ] 原生旋转 + 系统旋转锁组合；后台切换（会话保活、扫码暂停）。

## 5. 设备 / 文件页

- [ ] 在线状态探测失败提示（**本轮新增**）：断网进设备页应出「在线状态检查失败」提醒 + 重新检查按钮；恢复后重试成功提示消失（不再有永远「检查中」的卡死）。
- [ ] 扫码：**切后台摄像头灯灭（本轮新增）**、回前台自动续扫、取消后回前台不续；权限拒绝 / 无摄像头三态文案。
- [ ] 连接等待：在其他页直接「取消连接」（本轮新增），回设备页确认状态一致。
- [ ] 文件发送：跨页通知可关闭（**本轮新增**，仅「纯状态」类；失败与待确认不给 X）；准备阶段取消；部分失败文案。
- [ ] 更新：**「去授权」失败出错误通知（本轮新增）**——可用断网 / 停用命令模拟。

## 6. 性能与画质

- [ ] 首帧等待阶段文案（拨号 / 等批准 / 编码器起帧）与断流重连。
- [ ] 同 Wi-Fi 与移动数据两条链路的帧龄 / RTT（对照 10-03 媒体链路修复的实测基线：Wi-Fi 帧龄中位 202ms；移动数据中位 5334ms 属已知边界，不按 bug 报）。
- [ ] 130% / 200% 系统字体下的布局（统一提示控件、设备卡、工具栏）。
- [ ] 长会话发热与内存（视频 + 遥测 + 反馈环同开）。

## 7. 已知取舍（不按 bug 报）

- 跨网中继延迟与吞吐是体验边界（不能宣称低延迟操控）。
- 「只看」模式无输入辅助；入站申请在手机端只能拒绝。
- 文件传输无「本会话内不再问」；输入权「允许锁定我的输入」仅本次会话有效。
- Ctrl-Alt-Del 一级键架构上不可行。
