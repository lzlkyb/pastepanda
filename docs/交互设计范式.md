## 17. 交互通用核心思想（2026-08 实测沉淀，跨功能适用）

设计任何交互（截图 / 弹窗 / 面板 / 快捷键）时，先对照这套思想；具体实现细节留在代码注释里。

1. **鼠标全流程可达，键盘只做加速器**：所有功能都能纯鼠标完成；快捷键（数字键 / Enter / Ctrl+Z 等）只是熟练后的加速，绝不能成为必需路径。
2. **高频路径一步到位**：默认动作 = 用户最常用的动作（如截图"完成"=直接复制，而不是先进中间面板再选出口）；低频出口收进「更多 / ⋯」次级入口，不挡主路。
3. **有反馈、不靠猜**：任何可交互元素 hover 即有即时提示（名称+快捷键），选中/激活状态一眼可见；禁止裸图标、无态无反馈的设计。
   🔴 **已于 2026-09-09 被规则 19 的 L2 修订**：本条把 hover 当成了答案，而 NN/g 的结论是图标标签应**始终可见、无需交互**（hover 抬高交互成本且触屏不生效）。正确关系：**常驻文字标签是底线，hover 提示是加速器**（补快捷键等细节）。
4. **移动即预览**：能 hover 实时生效（如选区跟随窗口）就绝不要求额外点击确认；需要区分"预览"与"确认"时，用位移阈值（如 4px）判定意图。
5. **误触低成本**：关键操作可撤销（undo）；破坏性操作有确认；选区/编辑态可随时重来。
6. **两级取消**：编辑态 Esc 先回上一步（回到选区/还原），再 Esc 才退出；不要一步退出把用户赶走。
7. **交互一致**：同类操作（选中、拖拽、缩放、取色）在不同界面用同一套手势与反馈；状态机清晰，每个状态下可做的事语义单一。

## 18. 轻预览优先交互范式（微信式，跨功能可复用）

2026-08 从微信/QQ 截图交互中提炼的通用范式。它把规则 17 的多条原则（高频一步、移动即预览、两级取消）收敛成一个**具体可复用的模式**：任何"用户要先做选择 / 截取 / 捕获"的功能，都优先用「轻预览」而非「先弹面板 / 先点按钮 / 先确认」。

### 18.1 四条原则（交互成本跟着使用频率走）

1. **预览即默认（P1）**：智能探测用户意图，先把「最可能的完整结果」以**轻预览**摆出来，不要求先按任何键。常见路径零成本。例：进截图默认吸附光标窗口、进长截图默认显示整页淡预览。
2. **单击采纳 / 拖拽自定义（P2）**：高频动作只需单击一步（采纳默认）；低频动作才需拖拽 / 额外操作（自己框）。两者手势不同、成本低的一侧对应高频。例：吸附窗口单击进标注、窗口内拖拽画新框。
3. **非模态、不挡视野（P3）**：预览是轻量覆盖（虚线框 / 半透明 / 斜纹延展），**不是弹窗、不盖住用户要看的内容**，随时能推翻。例：自动打码先用橙色虚框预览不打上、贴图先半透明浮动预览。
4. **两级取消（P4）**：Esc 先回到「预览态」而非直接退出；再 Esc 才整体退出。误触零成本。

### 18.2 适用场景（其他设计可套用，不限于截图）

截图（选区 / 长截图 / 固定区域 / 取文字）、捕获类（自动打码、贴图），以及任何「先选范围再产出」的功能（框选导出区域、选区 OCR、固定区域记忆、模板套用预览等）。凡存在「默认结果 + 自定义结果」双轨的功能，都该先想能不能用本范式少一步。

### 18.3 三条守门红线（守不住预览就变成干扰）

- **轻量不挡视野**：预览层 `pointer-events` 可控，不能遮挡底层操作；多屏 / 混合 DPI 下预览坐标随物理像素换算，不漂移。
- **一键可推翻**：必须有明确出口（单击空白 / Esc / 放弃按钮）回到默认或退出；预览态不能成为「关不掉」的卡点。
- **预览不污染产出**：预览态的一切（框 / 线 / 半透明 / 放大镜 / 参考线）都不得进入最终截图 / 导出（截屏前临时隐藏截图窗，见 `capture_region`）。

### 18.4 与其它规则的关系

- 与规则 16（AI 红线）不冲突：本范式是交互层；凡涉及 AI 能力的预览仍须受 `ai_enabled` 约束，预览本身也不联网不花钱。
- 与规则 4 / 12 联动：套用本范式做 UI 变更时，仍须先读真实源码、先出 HTML 设计稿让用户确认。
- 与规则 17 是「具体实例化」关系：本范式是对 17.2（高频一步）、17.4（移动即预览）、17.6（两级取消）的收敛落地，不新增冲突原则。

### 18.5 落地先例（证明可复用）

均按此范式设计，HTML 设计稿在 `design/`：`选区拖拽即画新框-设计稿.html`、`长截图预览即默认-设计稿.html`、`固定区域预览即默认-设计稿.html`、`自动打码预览式-设计稿.html`、`贴图预览即钉-设计稿.html`。新功能套用本范式时优先参考这些稿子，复用同一套视觉语言（深色玻璃 + indigo/cyan 渐变、虚线紫框预览、青色终点手柄）。
