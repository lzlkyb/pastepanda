# 手机内容优先优化：实施设计

## 当前状态

设计稿：`design/mobile-focus-upgrade-2026-10-10.html`，配套 CSS / JS。

本轮已完成设计原型，真实布局等待用户确认。独立的手势指南文案纠错已在 `codex/mobile-article-ui` 工作树完成；尚未提交、推送或安装手机。

## 三种布局方向与取舍

| 方向 | 用户体验 | 取舍 |
| --- | --- | --- |
| A：保留主导航，只压缩卡片 | 模块切换一直可见，改动范围较小 | 阅读和编辑仍占用导航空间 |
| B：任务页优先（本稿推荐） | 阅读、编辑退出主导航，返回恢复列表；状态与任务聚合 | 进入任务页后先返回列表才能切换模块 |
| C：滚动时自动隐藏工具 | 阅读时动态获得空间 | 滚动方向与工具显隐相互影响，容易误判用户意图 |

本稿以 B 为基线，不引入新的左右切页手势。

## 第一批真实改动范围

1. 应用壳由知识库声明任务状态；阅读、编辑、文章剪藏预览收起主导航。返回恢复搜索、筛选与列表位置；保留现有 Android 返回优先级与草稿生命周期。
2. 知识库用一个待处理入口管理新建草稿、修改草稿、分享收集与文章任务；每份内容独立恢复。重要错误仍在可见区域展示，不仅留数量角标。
3. 文件页将待接收请求与正在传输任务放在高优先级；发送/取回压缩；已结束记录折叠。取消与失败不显示成成功，清记录不删除文件。
4. 横屏远控有紧凑侧栏、展开、可选沉浸状态。默认紧凑；沉浸入口明确可找回。原型紧凑栏 56px，展开 154px，最终实现应随字体、触摸目标与可用高度调整。
5. 画质选项在面板中前置，保留电脑接受/失败/未确认等真实回执。普通屏幕两列，大字体单列。详细说明折叠。

沉浸状态的工具按钮占用右下角一小块画面，这是需确认的取舍；非沉浸状态采用预留侧栏。不能仅靠增加透明度宣称没有遮挡。实现时工具区域的触摸不能发送到电脑；展开、旋转、键盘改变布局后仍需保持指针的内容坐标。

不改变：远控协议、配对授权、知识库同步授权范围、四种指针模式和现有草稿存储。文章抓取与图片补齐沿用 PR #12。

## 阅读工具栏微调

用户选择“先微调设计”，并指出阅读工具栏中文字排版不友好。原稿在 390px 下，返回与三项工具挤压“阅读”标题，导致标题逐字竖排。

修正：移除工具栏的重复“阅读”标题；文章标题继续标识内容。手机宽度下，三项工具采用图标上、文字下的统一排版，返回入口保持明确；横屏使用单行。标签不隐藏、不省略，选中后“已常用”也必须完整显示。

验证：新增标题守卫改前失败、改后通过；320、390、568px 各自普通/大字体六种组合中，按钮完整位于工具栏内、标签不换行、没有截断。320px 大字体的“已常用”标签也已单独检查。截图：`.cache/mobile-focus-qa/reader-header-fixed.png`。
