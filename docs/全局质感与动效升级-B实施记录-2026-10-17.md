## 已实施

- **统一节奏**：CSS 与 Framer 共用 150/200/300/400ms 四档及标准/进入曲线。14 个窗口入口接入同一动效策略；应用开关、系统减少动态效果和窗口隐藏均生效。截图与录屏等轻入口只接策略，不额外引入 Framer 运行时或 appStore。
- **即时切页**：模式指示器与内容并行响应，取消等待旧页退出的 140ms 定时器。首屏静止，后续内容轻量进入；四个视图继续互斥，不同时挂载两份虚拟列表。设置懒加载有可见的等待和错误返回入口。
- **有界列表补位**：仅在真实新增、置顶、删除前测量已挂载行，最多 64 行；只动画行内容，不接管虚拟定位 transform。滚动立即取消补位，移除原先暂停 Lenis 的逻辑；滚动复用和首屏不逐卡播动画。
- **原位反馈**：记录卡常显复制入口，显示复制中/已复制；虚拟行回收后不能继承旧记录的完成态。失败可重试，原按钮已卸载时仍能通过通知获得结果。
- **设置保存连续性**：保存队列、每个配置键的请求归属与结果在页面卸载后保留。旧失败不能覆盖新选择；页脚显示保存中/已保存/失败还原及重试。
- **可操作通知**：默认错误常驻；重复的无操作错误合并，有撤销/重试的通知保留独立操作。悬停、键盘聚焦、文档隐藏和原生窗口隐藏暂停倒计时。
- **弹层与控件**：按钮轻压、菜单短距离进入、对话框 12px 进入；取消动态大面积模糊、文字回弹及每张卡片的缩放。关闭侧栏时 inert，模式切换支持左右键、Home/End。
- **录屏与编辑器**：录制时钟不再每秒重挂载缩放，红点不再循环扩散；小控制条的展开遵循统一节奏。保留自然尺寸测量、原生命中、捕获排除及原业务时钟。编辑器退场时长与关闭守卫统一为 200ms。

## 性能结论与边界

本次没有新增常驻 rAF、setInterval 或逐全库 layout 测量。移除了卡片悬停扫光、空状态自转/浮动、录屏红点和时钟装饰循环；隐藏窗口暂停 CSS 动画、跳过新 Framer/列表动画。既有主题场景和真实任务进度另有自身运行机制，不在这里宣称整应用空闲零开销。

侧栏仍是 200ms 的真实宽度变化，会引起布局；没有把它描述成免费的合成动画。仍需同机同数据比较其最坏场景。

尚无完整改前/改后 WebView 帧耗时、GPU、内存对照，因此不宣称已保证 60/120fps 或性能零退化。单独测 Rust 宿主进程 CPU 不能代表 WebView，未作为性能结论采用。六主题全量原生验证、100%/125%/150% DPI、实录成片是否包含控制条也不能由网页或单元测试替代。

### 原生主题切换取证

同机同数据的浅色→深色→原浅色交互，采集均关闭页面截图和源码内容，原始文件留在本机忽略目录：

- `theme-interaction.json.gz`：Vite/React 开发环境，INP 981ms，最长点击任务约 628ms，其中 React 开发路径约 498ms；不能把该值当作发行环境。
- `theme-production.json.gz`：生产前端资源（确认无 `/@vite/client`）运行在同一 Tauri dev 宿主，INP 440ms。点击任务约 161ms，其中点击处理 71ms、一次样式更新 66ms（1,877 个元素），后续另有约 161ms 的任务。此结果仍未达到设计中的输入目标。

据此补充的修复只针对全局配色事务：颜色变量一次提交，暂不为所有后代分别建立过渡；相同主题广播不重启事务。普通控件的动效在事务结束后恢复。没有新增长驻循环，也不通过缩短动画时长掩盖主线程任务。

修复后，同机同数据、同组浅深色切换，生产前端采样 **INP 126ms**（DevTools 标注 good），相对于上述 440ms 明显降低。原始 `theme-production-fixed.json.gz` 解包核对：两次 click 到呈现分别为 125.798ms、87.173ms，处理函数分别为 37.298ms、23.98ms。它是这一组交互的单次取证，不是整软件平均响应或改动前后全量性能基准；仍高于设计中 ≤50ms 的首次反馈目标。当前已打开的 Tauri dev 预览使用生产前端资源，便于用户评估实际手感；临时配置在忽略目录 `.cache/motion-b/tauri.dev.json`，继续 HMR 开发时将 `beforeDevCommand` 还原为 `npm run dev -- --port 1422`。
