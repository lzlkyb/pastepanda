## 一、Markdown 实时预览（第 1 个做）

### 为什么先做

- 风险最低：纯前端实现，新增依赖 `marked` 成熟稳定
- 立即可见价值：开发者高频使用（复制 README、文档、笔记）
- 为 Diff 功能铺路：共享"文本预览"基础设施

### 技术方案

#### 依赖安装

```bash
npm install marked
# 可选：npm install @types/marked（如果 marked 不内置类型）
```

#### 检测规则

内容包含 ≥2 个以下特征即判定为 Markdown：

| 特征 | 正则 |
|------|------|
| 标题 | `/^#{1,6}\s/m` |
| 粗体/斜体 | `/\*\*.*?\*\*|__.*?__|\*.*?\*|_.*?_/` |
| 代码块 | `/```/` |
| 行内代码 | `/`[^`]+`/` |
| 无序列表 | `/^[\s]*[-*+]\s/m` |
| 有序列表 | `/^\d+\.\s/m` |
| 链接 | `/\[.*?\]\(.*?\)/` |
| 表格 | `/\|.*\|.*\n\|[-| :]+\|/` |
| 引用块 | `/^>\s/m` |
| 分割线 | `/^[-*_]{3,}/m` |

#### diff 算法选型

| 方案 | 包大小 | 优点 | 缺点 |
|------|--------|------|------|
| **`diff` (jsdiff)** ✅ | ~5KB | 轻量、按行/按词/按字符都支持、Patch 功能 | 中文按词需要自定义 |
| `diff-match-patch` | ~15KB | Google 出品、同步/异步对比 | 较大、API 复杂 |
| `diff-lines` | ~3KB | 极简 | 只支持行级 |

**推荐 `diff`**：轻量、API 简单、支持多种粒度。

#### 标注数据模型

// src/lib/annotations.ts
export type AnnotationType = 'pen' | 'arrow' | 'rect' | 'text' | 'mosaic';

export interface Annotation {
  id: string;
  type: AnnotationType;
  // 坐标（相对于图片原始尺寸，非显示尺寸）
  points: { x: number; y: number }[];  // 画笔：轨迹点，箭头：[起点,终点]，矩形：[左上,右下]
  color?: string;       // 画笔/箭头/矩形颜色
  strokeWidth?: number; // 画笔/箭头/矩形线宽
  fontSize?: number;    // 文字大小
  text?: string;        // 文字内容
  blurRadius?: number;  // 马赛克模糊半径
}

export interface AnnotationState {
  annotations: Annotation[];
  history: Annotation[][];  // 撤销栈
  historyIndex: number;
  currentTool: AnnotationType | null;
  currentColor: string;
  currentStrokeWidth: number;
  currentFontSize: number;
}

#### 关键实现细节

**坐标系映射**（最重要）：

```
图片原始尺寸: 4000×3000
显示区域: 800×600（缩放 0.2x）

鼠标点击显示坐标 (400, 300)
→ 转换为原始坐标: (400/0.2, 300/0.2) = (2000, 1500)
→ 存储到 Annotation.points
→ 渲染时反向转换
```

**Canvas 叠加层对齐**：
- Canvas 与 `<img>` 使用相同的 `transform`（scale + rotate + translate）
- 标注数据始终以图片原始坐标为基准
- 缩放/旋转时自动重新映射

**马赛克实现**：
```ts
// 1. 在离屏 Canvas 上绘制原图对应区域
// 2. 缩小到 1/10 → 再放大回原尺寸（像素化效果）
// 3. drawImage 到主 Canvas
```
