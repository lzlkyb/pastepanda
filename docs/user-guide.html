这是什么

你每天要在不同软件之间复制、粘贴几十次文字、截图、文件。但 Windows 自带的剪贴板只会保留最后一次内容——前面复制的东西，一粘贴就永远丢了。

PastePanda 就是一个常驻后台的「剪贴板记忆库」：它自动记录你复制过的每一条文本、图片和文件，随时呼出、随时找回、随时粘贴。你甚至可以把它当成：

  • 📋 一个不会丢内容的「超级剪贴板」
  • 📝 一个随手收藏常用话术 / 代码的「片段库」
  • 🛠️ 一个内置 Base64、JWT、SQL、JSON、时间戳等转换的「开发者工具箱」
  • 🌐 一台可以和同局域网其他电脑「互传剪贴板」的小工具
一句话总结：复制过的东西再也不会丢，想用哪条按一下就好。

1安装与首次启动

系统要求

项目要求
操作系统Windows 10 / 11（64 位）
运行时无需额外安装，已内置 WebView2
权限普通用户权限即可；开机自启需要写入启动项

下载与安装

  1. 从发布页下载最新版本的 .exe 安装包（通常为 剪贴板管理_x.x.x_x64-setup.exe）。
  2. 双击安装包，按提示完成安装（默认静默安装，几乎无感）。
  3. 安装完成后，PastePanda 会自动在后台启动，并在系统托盘（右下角任务栏）出现一个图标。

第一次使用你该做什么

  • 确认它在运行：看右下角托盘区有没有 PastePanda 图标。右键图标可以看到菜单（显示主窗口、设置、退出等）。
  • 试一次复制：随便复制一段文字，再按 Ctrl+Alt+V 呼出主窗口——你应该能看到刚才复制的内容已经躺在列表里了。
  • 设置开机自启（推荐）：打开设置（Ctrl+S），勾选「开机自启」，以后不用每次手动开。
小贴士：如果呼出窗口没反应，请先确认软件正在运行（托盘图标存在）。热键冲突时可在「设置 → 热键」里修改。

3核心功能

3.1 剪贴板历史（自动记录）

PastePanda 在后台以约 400ms 的间隔监听剪贴板，自动把每次复制的文本、图片、文件记录下来。相同内容（按 MD5 判断）会被自动去重，不会重复堆积。

  • 📋 文本：最长约 10 万字符会被截取保存，超长内容也能找回。
  • 🖼️ 图片：截图、复制的图片都会以缩略图保存。
  • 📁 文件：从资源管理器复制的文件，会记录为文件条目，可再次粘贴或打开。

3.2 一键粘贴到前台

这是用得最多的功能。在列表里选中某条记录，按 Enter（或在右键菜单选「粘贴」），PastePanda 会把内容直接注入到你当前正在用的窗口（通过系统消息模拟粘贴），无需你手动 Ctrl+V。

用法：在 Word / 浏览器 / 聊天框里，先点一下让光标就位，再呼出 PastePanda 选中条目回车，内容就进去了。

3.3 工作区（按场景隔离）

你可以建立多个「工作区」，比如「工作」「生活」「项目A」。每个工作区的历史记录相互独立、互不干扰。

  • 在设置或主界面切换工作区，列表会整体换成该工作区的内容。
  • 适合把「正经工作复制的东西」和「摸鱼复制的梗图」分开管理。

3.4 搜索与筛选

记录多了之后，靠滚动找太慢。PastePanda 提供多种定位方式：

方式说明操作
🔍 关键词搜索支持中文拼音首字母（如输入 dh 可匹配「电话」相关内容）Ctrl+F 聚焦搜索框
🏷️ 标签分类给重要记录打标签，按标签一键过滤右键 → 标签
📂 类型筛选只看文本 / 图片 / 文件顶部类型筛选
🕒 时间过滤只看今天 / 近一周等内容顶部时间筛选

3.5 片段库（常用模板）

把经常要粘贴的固定内容（如邮箱签名、地址、常用代码块）存进「片段库」，以后一键粘贴，还能统计使用次数。

  1. 打开顶栏工具箱下拉 → 片段库。
  2. 点击「新建」，粘贴内容、起个名字，保存。
  3. 需要时在主窗口顶部工具箱进入片段库，选中即粘贴。
  4. 也可在任意记录上右键 → 添加到片段库，快速收藏。

片段还支持动态变量，例如：

变量粘贴时替换为
{{date}}当前日期
{{clipboard}}当前系统剪贴板内容
{{uuid}}一个随机 UUID

3.6 信息提取 & 敏感内容防护

ℹ️ 信息提取
自动识别一条文本里的电话号码、邮箱、URL，在工具箱「内容提取」里集中列出，点一下就能复制。
🔒 敏感内容防护
当剪贴板内容被识别为密钥 / 凭证（如 API Key、密码）时，会自动标记为敏感，默认不记录，保护你的隐私。

4高效粘贴

4.1 全局热键（无需打开窗口）

这些热键在任何软件里都能直接用，是提升效率的关键：

热键功能
Ctrl+Alt+V显示 / 隐藏主窗口
Ctrl+Alt+Q依次粘贴（循环粘贴历史里的下一条）
Ctrl+Alt+1~9直接粘贴前 9 条记录
Ctrl+Alt+K开启 / 关闭粘贴栈模式
Ctrl+Alt+P从粘贴栈栈顶粘贴
举例：你刚复制了 3 段文字要依次填到表单里，连续按 Ctrl+Alt+Q 就能一条条填进去，不用反复切窗口。

4.2 粘贴栈模式

有时你想「先攒一堆内容，再按顺序一口气粘贴」。开启粘贴栈后，复制的内容会进栈；需要时从栈顶逐条粘贴，或全部一次性粘贴。

  • 按 Ctrl+Alt+K 开关栈模式。
  • 按 Ctrl+Alt+P 粘贴栈顶那一条。

4.3 正则替换（粘贴时自动变换）

粘贴前可以套用正则规则，对内容做自动处理，例如：去掉空行、URL 解码、手机号脱敏等。规则用 SQLite 持久化保存，可自定义多条。

  • 在设置中找到「正则替换规则」，新增一条规则（匹配正则 + 替换内容）。
  • 之后粘贴对应内容时会自动套用，省去手动整理。

4.4 HTML 剥离

从网页复制的文字常带格式（颜色、超链接）。一键「转换为纯文本粘贴」即可去掉所有 HTML 格式，只保留干净的纯文字。

5开发者工具箱 进阶

这是 PastePanda 区别于普通剪贴板工具的核心亮点：它内置了一整套「文本变换」能力，复制的内容不用离开软件就能完成常见开发转换。

5.1 变换面板（在哪里、怎么用）

选中任意一条记录，右键 → 变换，或者复制内容后直接按 Ctrl+Shift+V，就会打开「变换面板」。它会按内容类型智能推荐可用的变换（比如 JSON 内容会推荐格式化，图片会推荐 OCR / 裁剪）。

5.6 AI 快捷栏 需配置

复制内容后，部分版本会在底部或侧边出现「AI 快捷栏」，根据内容特征（如一段报错、一个链接、一段长文）推荐 2~3 个动作：脱敏、链接摘要、回复草稿、自定义动作等。点击「更多…」可进入完整的变换面板。

注意：AI 相关动作需要先在「设置 → AI」中配置可用的模型密钥后才会启用；未配置时只会显示本地变换能力。

7系统与同步

7.1 局域网同步

同一局域网下的多台设备（比如你的台式机和笔记本），可以互相同步剪贴板内容（文本 / 图片 / 文件）。传输采用 AES-256-GCM 加密，并带重放防护，安全性有保障。

  • 在「设置 → 局域网同步」中开启，并确认设备在同一网络。
  • 配对成功后，一端复制的内容会出现在另一端的历史里。

7.2 主题

内置 4 套主题：浅色 / 深色 / 蔚蓝 / 蔚蓝深色。在设置中随时切换，护眼又好看。

7.3 系统集成

  • 🌐 系统托盘：常驻右下角，右键可显示窗口、打开设置、退出。
  • 🚀 开机自启：设置中勾选，电脑开机自动运行。
  • 💾 数据导入 / 导出：在设置中把全部数据导出为 JSON 备份，或导入恢复（换电脑迁移数据很方便）。

7.4 自动更新

PastePanda 支持自动更新：

  • 何时检查：每次启动时自动检查，之后每 24 小时再查一次。
  • 如何提示：发现新版本时，主窗口顶栏版本号旁会出现更新徽章（蓝色脉动），「关于」对话框里也会显示横幅。
  • 如何升级：点击徽章 / 横幅的下载按钮，下载完成后点「重启」即完成静默安装。
更新失败排查：若长时间检测不到更新，多为网络访问 GitHub 受限所致——可检查代理；签名验证失败则可能需要手动下载最新安装包覆盖安装。

9新手 5 分钟上手

  1. 安装并启动：装好后确认右下角托盘有图标。
  2. 开启开机自启：Ctrl+S → 勾选开机自启。
  3. 随便复制点东西：复制一段文字、一张截图。
  4. 呼出窗口：按 Ctrl+Alt+V，看到刚复制的内容已在列表中。
  5. 试试粘贴：在别处把光标放好，回来看列表选中条目按 Enter，内容直接进去了。
  6. 收藏常用内容：右键一条记录 → 添加到片段库，下次从工具箱「片段库」一键调用。
  7. 用一次变换：复制一段 JSON，按 Ctrl+Shift+V，体验格式化 / 编解码。

完成这 7 步，你就已经掌握了 80% 的日常用法。

11常见问题 FAQ

Q：呼出窗口没反应 / 热键冲突？

先确认软件在运行（托盘图标存在）。如仍无效，可能是与其他软件热键冲突——打开「设置 → 热键」修改全局热键即可。

Q：为什么有些复制内容没被记录？

两类情况：① 内容被识别为密钥 / 凭证，出于安全默认不记录；② 复制的是某些特殊格式。可在设置中调整敏感内容防护策略。

Q：数据存在哪里？会泄露吗？

数据保存在本机 SQLite 数据库中，默认不上传任何服务器。局域网同步走 AES-256-GCM 加密。AI 功能仅在你主动配置密钥后才会联网调用。

Q：怎么备份 / 迁移到新电脑？

「设置 → 数据导入导出」导出 JSON 备份，到新电脑导入即可。局域网同步和导出 Excel/CSV 也便于整理。

Q：误删了一条记录能找回吗？

删除后按 Ctrl+Z 可撤销删除（在窗口内操作有效）。

Q：更新一直检测不到 / 下载失败？

多为网络访问 GitHub 受限。可检查代理；若签名校验失败，建议手动从发布页下载最新安装包覆盖安装。

Q：支持 macOS / Linux 吗？

当前发布版本仅支持 Windows 10 / 11（64 位）。

关于与许可

PastePanda 是一款基于 Tauri 2 + React 19 + Rust 构建的 Windows 桌面剪贴板管理工具。

  • 技术栈：前端 React 19 / TypeScript / Vite / Tailwind；后端 Tauri 2 / Rust / SQLite。
  • 许可证：MIT。
  • 版本号与更新信息请查看软件内「关于」对话框。
