# 手机知识库：Android 系统收集与分享

## 行为边界

系统分享（文字、链接、单张/多张图片）只进入持久待处理队列。用户预览并确认后，由现有手机草稿流程保存；原生桥接不创建笔记、不覆盖草稿、不扫描剪贴板、不依赖远控。冷启动通过插件 `load`，运行中通过 `onNewIntent` 接收。图片选取走系统 `ACTION_OPEN_DOCUMENT`，取消返回 `cancelled`。

原生图片先复制到应用私有 `filesDir/knowledge-inbox`；Rust 校验实际格式、文件大小、尺寸、目录边界后，复制到实际 `app_data_dir/images`，返回 `pp-asset:<MD5>.<extension>`。因此来源 URI 授权失效后，已复制的图片仍可收集；确认消费队列仅删除暂存图片，不删除笔记图片。

每次最多8张图片，每张10MB；尺寸与阅读器共用8192边长/1600万像素限制。队列最多20项，图片暂存最多80MB。未消费相同载荷不重复添加；队列满、URI授权失效、格式不支持、部分图片失败均有可读状态，不默默创建不完整笔记。队列索引使用 AtomicFile，复制串行；清理排在复制之后，避免删除尚未登记的图片。

向外分享走系统 Sharesheet 和 FileProvider 临时只读授权。`opened` 只表示系统分享面板打开，不宣称接收应用已经保存；系统取消也不删除原笔记。旧分享图片有缓存上限，当前这次的图片保留供接收应用读取。

## 集成

- 原生唯一源码：`src-tauri/android/KnowledgeSharePlugin.kt`、`KnowledgeShareStore.kt`。
- `scripts/prepare-android.mjs` 恢复分享 intent-filter、FileProvider、路径资源和 Kotlin 源码；不手工依赖生成目录。
- Rust：`commands/mobile_knowledge_share.rs`；插件名 `knowledge-share`。
- 前端：`src/lib/api/mobileKnowledgeShare.ts`，提供 list/ack/pick/send/listen；`incoming` 事件只提醒刷新。
- JS 每次进入前台仍拉取 list，补上冷启动时监听尚未注册的事件；`processing` 为真时等待后续完成事件。
- `ack` 仅在明确丢弃或内容已持久写入草稿后调用。新建草稿已存在时展示处理选择，禁止覆盖。
- picker 的 `collected` 表示选择流程结束；最终结果须读取队列 item 的 status/message 和 inbox.notice。

## 已执行验证与真机待验

已通过6项 Android prepare 测试：XML合法/幂等、插件反射标记、唯一源码恢复、FileProvider路径与收集 filters。4项 Rust 图片/分享测试覆盖独立持久和去重、外部路径/假图片、大小/像素限制、向外分享路径守卫。新增两个 Kotlin 文件已使用缓存 Kotlin 2.0.21 编译器和实际 Tauri/Android 依赖成功静态编译。

尚需统一 APK 构建和真机验收：其他应用的系统分享列表、冷/热启动、相册临时授权/多图片、取消选择、旧草稿保护、系统面板取消、进程重启后队列，以及分享图片的接收方实际读取。静态编译不代替这些平台行为验收。

实现参考 Android 官方规范：[接收简单数据](https://developer.android.com/develop/ui/compose/sharing/receive)、[安全分享文件](https://developer.android.com/training/secure-file-sharing)。
