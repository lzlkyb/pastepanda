## 本机命令

安装 Node/npm 与 Rust、完成 Xcode 首次设置后：

```sh
npm ci
npm run macos:check
npm run macos:dev
```

macos:check 只检查工具链和依赖，不代表功能移植完成。OCR 编译需要 libclang.dylib；脚本优先读取 LIBCLANG_PATH，否则尝试选中的 Xcode 工具链。项目内 Rust 安装位于 .cache/macos-toolchain 时会自动使用。

Windows 运行入口保持不变。版本号由维护者管理。调试包不启用更新产物；正式发布覆盖配置已启用更新归档，需维护者签名、公证凭据并完成实际发布。
