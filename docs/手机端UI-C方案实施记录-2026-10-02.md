# 手机端 C 方案实施记录

日期：2026-10-02。依据用户已确认的 C 方案，保留桌面主题令牌与共享业务层，调整移动端布局和反馈。

- 设备：大标题、实底分组列表、扫码/配对码弹层、设备操作、无人值守入口、解除配对确认。
- 文件：选择传输对象、双向文件入口、请求/任务反馈、接收位置弹层；文件页首次访问后保留，切页或进入会话不卸载上传状态。
- 设置：通道开关、会话历史与清空确认、外观（跟随系统/浅色/深色）、手势指南和触摸演示。
- 远控：键盘/画面/剪贴板/更多四入口；直接选择画质，保留横竖屏与键盘桥；只看模式禁用控制入口；断开前明确确认，失败留在确认弹层。
- 交互：按压反馈、页面/弹层入场、下拖收起、焦点管理、系统历史返回逐层收起；剪贴板反馈独立于隐藏胶囊，文件失败在应用页可见。
- 适配与性能：安全区、可视视口高度、键盘上方弹层、减少动态效果；玻璃集中于导航/会话工具条，列表实底，隐藏文件页暂停请求倒计时，无新增常驻动画。
