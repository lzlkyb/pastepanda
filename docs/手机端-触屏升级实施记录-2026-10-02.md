# 手机端触屏升级实施记录

按已确认的 B「稳定触控」方案实施，沿用 C 外观与 R2 控制布局。

- 双指采用累计位移，等待两指起手信息；一指静止时 48ms 后判定。阈值 10px，分类后本轮不切换；等待中抬指和取消都会清除识别任务。
- 接入长按充能环与文字预告；松手右键、移动拖拽、双击有对应视觉反馈。取消、失焦、权限变化清理反馈与按键；正常抬指后的捕获释放不重复取消。
- 鼠标辅助默认展开，右键、拖拽、滚动直接可达，仍可从模式面板收起。拖拽和滚动保持明确状态及结束入口。
- 底部弹层把手扩到 44px，跟随拖动；超过 80px 关闭，短距离回位；正文滚动不接管拖动。退出从手指释放处继续向下，系统取消及失焦回位。
- 共用次要按钮增加按压底色反馈，会话按钮补齐 transform 过渡；继续使用现有 150/200/300ms 与语义色令牌，系统减少动态效果保持生效。
- 缩放和平移限制在可达视野，缩小时居中；键盘或旋转改变容器后重新约束。ResizeObserver 随组件销毁断开，没有新增常驻动画或帧循环。
- 输入提交的同步失败保留草稿，错误展示在输入区；本地提交提示说明等待电脑显示，不宣称远端已执行成功。

## 验证与限制

相关手势、弹层、视野、键盘和工具栏测试通过；类型、定向代码检查、CSS 引用及 UI 规则检查通过。UI 规则检查中的 FocusTrap 内联样式提醒属于其他既有改动。

实际会话组件在 390×844 浏览器视口核对了默认鼠标辅助与拖拽状态，截图位于 `design/mobile-touch-2026-10-02/implemented-portrait.jpg`。预览复用 TouchSandbox，不连接真实设备。Android / iPhone 跨设备操作、触觉反馈与软键盘实际遮挡尚未真机验证；本轮没有打包或提交。
