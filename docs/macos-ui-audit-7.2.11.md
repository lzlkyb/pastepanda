# macOS 7.2.11 界面与功能续审（2026-10-10）

基线：master e87bf2e；修复分支：fix/macos-ui-audit。版本保持 7.2.11，不发 Release。
本轮不把源代码覆盖、合成输入的原生测试和实机 GUI 混为一个“通过”。

## 新发现与修复

| 问题 | 修复 | 改前证据 / 改后验证 |
|---|---|---|
| PNG 导出保存后报 Load failed；打包 CSP 不允许 fetch(data:) | toBlob 直接读取 PNG 字节，保存对话框异常也展示失败反馈 | 实机旧包没有生成文件；导出 Hook 旧实现 3 失败 / 1 通过，修复后通过 |
| 图片背景变黑/透明，连线丢失 | 使用已计算的画布底色；SVG 子路径/箭头临时保存实际 CSS 样式，结束后恢复 | 旧导出 PNG/SVG 留存；样式测试旧实现 2 失败 / 4 通过，修复后通过 |
| 画布 color-mix 引用 --app-bg 渐变，CSS 底色无效 | 使用六主题均为实色的 --card-bg 与 --text-primary 混色 | 真实六主题令牌守卫改前失败，改后通过 |
| WebKit 图片编码把节点模糊阴影画成硬边矩形 | 图片出口临时去掉节点装饰阴影，编辑器结束/失败后恢复 | 成品旧 PNG 留存，外层与内部节点阴影分别先复现失败，内部节点/过渡/恢复测试修复后通过 |
| Mac 原生托盘有录屏入口却只编译 Windows 路由，上次区域不进入快照 | 三处门禁接通 Mac，共用现有 rec 模块；区域进入缓存指纹 | 四项源码守卫改前失败、改后通过；Universal 两架构编译通过，真实托盘点击仍待测 |
| 截图热键启动默认 Ctrl+Q，重注册却默认 Ctrl+Alt+A | HotkeyConfig::from_saved 统一默认值与读取；保留空串禁用 | 两处实际调用守卫改前失败，改后通过；两个 Rust 单测覆盖缺省/非法值/自定义/禁用 |
| 工具分类栏吸顶后透出下面的文字；OCR 校对缩略图背景声明也失效 | 查全实际样式中 color-mix 对渐变 --app-bg 的误用；工具栏改用实底 --section-bg，校对缩略图用 --input-bg | 滚动实机复现；全样式守卫改前失败，改后通过 |

PNG/SVG 同用一个导出 Hook，内嵌与全屏编辑器都走此路径；没有放宽 CSP。
Mac 物理 Control/Option 热键与本地编辑 Command 快捷键仍分别遵循原配置。
