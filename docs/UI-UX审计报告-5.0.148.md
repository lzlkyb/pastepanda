# PastePanda UI/UX 体验审计报告（v5.0.148）

> 审计日期：2026-07-22
> 审计范围：全部前端组件（React/TS）+ Rust 侧用户可感知行为（窗口/托盘/热键/粘贴引擎/剪贴板监控）
> 审计方法：三路并行代码走查 + 关键发现人工复核（抽查 8 项全部属实）
> 发现总数：**58 项**（High 10 · Medium 26 · Low 22）
> 编号规则：U1–U58，供后续修复引用

---

## 一、High（严重影响信任或导致误操作，应优先修复）

### U1. 粘贴失败仍弹"已粘贴"成功提示
- 位置：`src/App.tsx:514-524`、`src/components/Card.tsx:735-751`、`src/lib/api.ts:281-282`
- 问题：`pasteText()` 返回布尔值并自行弹"粘贴失败"错误 toast，但所有调用方忽略返回值、无条件再弹"已粘贴"成功 toast。
- 影响：失败时用户看到两条矛盾提示，且误以为内容已粘进目标应用——对剪贴板工具是核心信任问题。
- 方向：按返回值分支，仅成功时弹 toast。

### U2. 鼠标点"收藏/置顶"不持久化，重启即丢失
- 位置：`src/components/Card.tsx:332,362,508,538,583,755`（store `togglePin`）vs `src/App.tsx:542`（api `togglePin`）
- 问题：所有鼠标路径（悬浮 ☆、行内 ☆、右键菜单"置顶"）调用的是 store 的 `togglePin`（`appStore.ts:286-293`，仅改本地状态，无 `invoke("toggle_pin")`）；只有 Ctrl+D 走 api 持久化。
- 影响：用户用鼠标收藏的条目重启后全部丢失；同一操作两种输入方式行为不一致。
- 方向：全部路径统一走 api 函数。

### U3. 右键菜单打开时键盘事件双重处理（危险）
- 位置：`src/App.tsx:461-470` + `src/components/ContextMenu.tsx:122-172`
- 问题：App 与 ContextMenu 各自注册 window keydown，互不排斥（App 的弹窗守卫不含右键菜单）。菜单打开时：Enter 既激活菜单项**又**粘贴选中卡片；↑↓ 同时移动菜单高亮和列表选中；Esc 既关菜单**又**隐藏整个窗口。
- 影响：在"删除"上按 Enter 可能同时把内容粘贴进前台应用——真实误操作风险。
- 方向：菜单打开期间 App 的处理器整体让位（或菜单 stopImmediatePropagation）。

### U4. Esc 无分层优先级，直接隐藏窗口
- 位置：`src/App.tsx:477-484`、`App.tsx:694-738`（移动到分组弹窗）
- 问题：Esc 直接 `toggleWindow()`。"移动到分组"弹窗未登记进 `dialogStatesRef`，Esc 会带着打开的弹窗一起隐藏窗口；选中 30 项时按 Esc 想取消选择，结果整个应用消失。
- 方向：Esc 阶梯——关最上层浮层 → 清多选 → 隐藏窗口。

### U5. 每次启动（含开机自启）窗口弹出并抢焦点，与设置承诺矛盾
- 位置：`src-tauri/src/lib.rs:239-246`、`commands.rs:870-894`（set_startup）、`GeneralTab.tsx:336,340`
- 问题：`setup()` 无条件 `window.show() + set_focus()`；注册表自启不带静默参数，single-instance 回调忽略启动参数。而设置界面明确承诺"开机后自动在后台运行，托盘图标常驻""启动后自动最小化到托盘"。
- 影响：开了自启的用户每次开机被弹窗抢焦点——正是设置文案说不会发生的事。
- 方向：自启命令追加 `/silent` 标志，或增加"启动时最小化到托盘"选项并在 setup 中读取。

### U6. 首次"隐藏到托盘"提示发进已隐藏的窗口，永远看不到
- 位置：`src/components/TopBar.tsx:32-42`（已人工复核）
- 问题：`hideWin()` 先 `hide()` 再 dispatch `first-time-tip`，toast 渲染在已隐藏的 webview 里；但 localStorage 已标记"已展示"，永不再现。且顶栏"隐藏窗口"用的是 **X 图标**（通用语义=关闭/退出）。
- 影响：这是全应用唯一教用户"隐藏≠退出、去托盘找回"的地方。新用户点 X，窗口消失，解释性提示被烧毁，以为应用崩了或退了。
- 方向：提示改原生/托盘通知，或确认展示后才标记；X 改"隐藏"语义图标（如眼睛/向下箭头），或提供"X 行为=隐藏/退出"配置。

### U7. 默认全局热键劫持常用系统快捷键
- 位置：`src-tauri/src/hotkey_manager.rs:23-33`（已人工复核）
- 问题：默认 `Ctrl+Shift+V`（Chrome/Edge/VS Code/Office 的"粘贴为纯文本"）、`Ctrl+Q`（大量应用的退出/关标签）、`Ctrl+Shift+P`（VS Code 命令面板、Firefox 隐私窗口），外加 `Ctrl+Alt+1~9` 共 12 个全局绑定。
- 影响：全局注册会**成功**（不触发"注册失败"提示），静默抢走其他应用的快捷键，用户毫无察觉。
- 方向：换低冲突默认值（Win/Alt 系或 F 键）；首次启动展示一次"已占用快捷键清单 + 去设置修改"。

### U8. 内容提取对话框：复制/存片段零反馈
- 位置：`src/components/ExtractDialog.tsx:63-98`（已人工复核）
- 问题：`copySelected`/`copyAll`/`saveSelectedAsSnippets`/`saveSingleAsSnippet` 成功无 toast，失败仅 `logger.warn`。
- 影响：复制是该对话框的唯一目的，用户点了"复制"不知道成没成功。
- 方向：成功/失败均 toast。

### U9. 正则规则：编辑预置规则静默失败；删自定义规则无确认
- 位置：`src/components/RegexRulesDialog.tsx:138,59-74,44-47,140`
- 问题：预置规则（p1~p8）显示编辑按钮，但 `handleSave` 对预置 id 查不到、什么都不写（代码注释已承认），用户编辑→保存→关闭→规则没变；删除自定义规则一键即删，无确认。
- 方向：预置规则隐藏/禁用编辑（或实现"自定义覆盖"）；删除加 ConfirmDialog。

### U10. 片段库批量删除无确认（单条有）
- 位置：`src/components/SnippetsDialog.tsx:151-165` vs `418-426`
- 问题：单条删除弹 ConfirmDialog，批量删除直接执行。
- 方向：批量走同一确认流程。

## 二、Medium（明显影响体验，应排期修复）

### 核心列表与粘贴

**U11. 删除确认策略四路径不一致**：键盘 Delete 直接删（`App.tsx:527-534`）、悬浮/行内 🗑 直接删（`Card.tsx:372-377,548-553`）、右键菜单弹确认（`Card.tsx:773-781`）、批量弹确认（`CardList.tsx:1538-1546`）。同一破坏性操作摩擦力随机。方向：统一为"直接删 + 显眼的撤销 toast"或全部确认。

**U12. 多选状态是个陷阱，没有直觉出口**：普通点击刻意不清多选（`appStore.ts:357-381`）；点空白无反应；Esc 隐藏窗口而非取消选择（U4）。唯一出口是批量工具条的"取消全选"或再按 Ctrl+A。方向：有选中时普通点击应清空；Esc 先清选中。

**U13. 删除后键盘焦点跳回列表顶部**：`removeItems` 把 `focusId` 置 null（`appStore.ts:264-275`），下次 ArrowDown 从 -1→0。逐条删着走每次都要从头导航。方向：焦点移到最近的存活邻居。

**U14. Home/End 选中首/尾项但不滚动**（`App.tsx:579-584`，对比方向键 494-505 有 scrollIntoView）。长列表按 End 选中不可见，下一次 Enter 粘贴了看不到的内容。

**U15. 依次粘贴 FAB 计数与实际行为不符**：FAB 显示 `{seqPointer}/{seqTotal}`，`seqTotal` 统计**未过滤**历史（`App.tsx:45`），但实际粘贴遍历 `getFilteredItems()`（`api.ts:209`）。有搜索/筛选时计数失真；且 `seqPointer` 不随筛选重置，产生误导性"已到最后一条"。方向：计数与遍历用同一数据源；筛选变化时重置指针。

**U16. FAB 重置按钮是嵌套在 button 里的 span**（`App.tsx:683-686`）：非法嵌套交互元素、键盘不可达、无 tooltip。方向：改为独立 button + title。

**U17. 快捷键面板文档与默认配置不符**：面板写"双击复制到剪贴板"（`App.tsx:780`），但默认 `double_click_action="preview"`（`appStore.ts:173`），文本双击实际打开编辑框。新用户照帮助操作会困惑。方向：面板行从实际配置渲染。

**U18. 单击延迟 200ms**（`Card.tsx:163-183`）：为区分单双击，onClick 走 200ms 定时器，选中反馈永远慢 0.2 秒——对以"快"为本的工具是硬伤。方向：单击立即选中，双击独立处理（或单击=粘贴）。

**U19. 文件卡片标题显示原始 JSON**（`Card.tsx:89-93`）：多文件复制时卡片显示 `["C:\a.txt","C:\b.txt"]` 带括号引号（悬浮层已正确解析，卡片标题没有）。方向：用 `parseFilePaths` 生成"a.txt 等 3 个文件"。

**U20. 空状态无视时间/来源/分组/标签筛选，说谎**（`CardList.tsx:1077-1121`）：只分支 searchKeyword 和 filterType。开了"今天"/来源/分组/标签筛选导致零结果时，显示"剪贴板是空的"——事实错误，且无一键清除。方向：检测任意活动筛选，说明原因 + "清除全部筛选"按钮。

**U21. 悬浮操作弹层不翻转，顶部卡片按钮够不着**（`Card.tsx:393-405` + `CardList.module.css:707-724`）：`.flipDown` CSS 存在但 TSX 从未应用，弹层永远向上展开，被 `.contentArea{overflow:hidden}` 裁掉——最顶上几张卡片的收藏/复制/删除不可见。方向：按视口位置接上翻转逻辑。

**U22. 右键菜单"正则替换"子菜单是死的可点击行**（`ContextMenu.tsx:415,257-267`）：伪表头被渲染成 button，点击后菜单静默关闭、无任何动作。方向：真分隔/标题渲染为非交互元素。

**U23. 每次剪贴板捕获都弹 4 秒 toast**（`api.ts:108-126`）："已记录文本/图片/文件"在快速复制时刷屏（上限 5 条堆叠），淹没真正重要的粘贴反馈。方向：静默记录（卡片出现在顶部本身就是反馈）。

**U24. 栈模式不可发现**：仅热键进入（Ctrl+Shift+K）；快捷键面板（`App.tsx:771-788`）完全没列栈模式两个热键；激活后 FAB 消失（`App.tsx:678`）无解释。方向：面板补全 + 增加可见入口。

### 对话框与设置

**U25. SnippetsDialog 多处细节失守**（`SnippetsDialog.tsx`）：「已复制 0 次」硬编码 0（327-328）；"最近使用"实为前 5 条（357-365）；空名称保存静默失败、按钮不 disable（110-111）；编辑无未保存确认（285，EditDialog 有）；复制无 toast（141-143）。

**U26. HotkeyRecorder 体验缺口**（`HotkeyRecorder.tsx`）：已分配的热键无法清除/禁用（110-118）；Esc 取消录制从不提示（52-55）；校验提示 1.8s 自动消失易错过（28）；热键显示为原始小写 `ctrl+shift+k` 而非 `Ctrl + Shift + K`（GeneralTab.tsx:381-457）。

**U27. 设置无"恢复默认"**：涉及自动清理天数、热键、置顶等行为配置，改错后无恢复路径。

**U28. "栈"字术语对普通用户不友好**（`GeneralTab.tsx:417-457`）："栈模式开关""栈顶粘贴""粘贴栈顶内容并出栈"。方向：改"收集模式""粘贴最近收集的内容"等。

**U29. QRCodeDialog 失败态只有"生成失败"三个字**（`QRCodeDialog.tsx:99-100`）：无原因（多为文本超长）、无重试、无指引。方向：检测长度给出"文本过长"+ 重试。

**U30. ExtractDialog"全部存为片段"实为存选中**（`ExtractDialog.tsx:212-215`）：与旁边"复制选中"并列，"全部"强烈暗示所有结果。方向：改名"存为片段（已选）"。

**U31. 所有对话框无焦点陷阱、无 aria-modal**：Tab 会把焦点移出对话框进入背景内容；屏幕阅读器不知道对话框已打开。方向：共享 focus-trap 包装。

**U32. SettingsDialog 残留死保存逻辑 + 无"自动保存"提示**（`SettingsDialog.tsx:28,65-81`）：`handleSave`/`saved` 定义了但没接到任何按钮（页脚只有"关闭设置"）；设置实际即时生效但用户不知情。方向：删死代码 + 加"已自动保存"微提示。

### 系统级

**U33. 托盘弹窗点图片/文件条目粘贴的是占位文本**（`tray_manager.rs:29-60` + `TrayPopup.tsx:419,528`）：`get_recent_texts_public` 返回 `item.text`，图片是 `"[图片] WxH"`、文件是裸文件名；点击"粘贴"把这段字面文本打进用户文档。方向：图片/文件走 `item.content` + 对应粘贴通道。

**U34. 热键注册失败 toast 不可操作**（`App.tsx:371-373` + `hotkey_manager.rs:254-260`）：Rust 把所有失败绑定 join 成长串塞进一条 toast，说"请前往设置更换"但没有跳转按钮。方向：摘要"N 个快捷键被占用"+「去设置」动作按钮，详情写日志。

**U35. 热键冲突静默回滚，UI 与实际不符**（`hotkey_manager.rs:104-125`）：新热键冲突时静默恢复旧配置（仅日志），设置界面若仍显示新值，用户看到的与生效的不一致。方向：冲突时明确告知哪个绑定冲突、变更未生效，UI 回显实际值。

**U36. 敏感内容无防护**（`clipboard_monitor.rs:164-350` + `content_classifier.rs:208-210`）：密码管理器/密码框内容照常被记录、打"密钥"标签、写入 SQLite，开了局域网同步还会广播。无应用排除名单、无敏感模式开关、无自动清除。方向：应用排除名单 + "不记录匹配密钥模式的内容"开关 + 同步跳过敏感条目。

## 三、Low（细节打磨，可批量处理）

**U37. 索引粘贴（Ctrl+Alt+1~9）越界静默失败**（`api.ts:270-283`）：无任何 toast，用户分不清热键坏了还是槽位空。

**U38. 图片预览提示与实际不符**（`CardList.tsx:1328,1529`）：工具条写"滚轮缩放·双击重置"，实际滚轮=平移、无双击处理器；"1:1"按钮 title 说"适应窗口"实为 100%。

**U39. 方向键导航与 Lenis 滚动控制器打架**（`App.tsx:494-505` vs `CardList.tsx:611-664`）：原生 scrollIntoView 与 Lenis 争抢滚动位置，键盘导航可能卡顿/定位不准。已有正确实现 `handleScrollToIndex` 可复用。

**U40. Shift+F10 菜单弹在列表中央**（`ContextMenu.tsx:104-116`）：远离焦点卡片；wrapper 的 `tabIndex=0` 是无意义 Tab 停靠点。

**U41. 搜索两处误导**（`SearchBox.tsx:113` + `appStore.ts:483-488`）：占位符写"(Enter 搜索)"但搜索是实时防抖的；搜索只匹配文本/拼音，图片文件名、文件路径完全搜不到且不提示。

**U42. 悬浮弹层无打开延迟**（`Card.tsx:157-160`）：鼠标扫过列表连续弹出弹层。方向：150-250ms 悬停意图延迟。

**U43. aria-live 挂在整个虚拟列表容器上**（`CardList.tsx:1066-1074`）：每次插入/筛选都向读屏器重播列表内容，极吵。方向：移到专用状态节点。

**U44. Space 快速预览对图片/文件静默无效**（`App.tsx:585-595`）：仅 text 分发预览事件，按键被吞、零反馈。方向：支持图片/文件预览或给提示。

**U45. ConfirmDialog 宽度类未定义 + 对话框固定宽不响应式**（`ConfirmDialog.tsx:40` + `dialog.css:24-27`）：`w400` 不存在；`w500`→420px 名实不符；窄窗口下 EditDialog/Extract/Snippets/Settings 可能溢出。

**U46. DiffDialog 细节**（`DiffDialog.tsx:53-55,155-159`）：跳转硬编码行高 20px 且只滚左栏；列标"旧文本/新文本"但按钮写"复制左侧/右侧"。

**U47. EditDialog 打开无初始焦点**（`EditDialog.tsx:280-294`）：键盘用户必须先点一下（ConfirmDialog 已正确用 autoFocus）。

**U48. 正则规则管理器内无法试规则**：预览在独立的 RegexPreviewDialog 且只能从真实内容进入，缺内联"试一试"输入框。

**U49. RegexPreviewDialog 调好的参数无法存回规则**（`RegexPreviewDialog.tsx:17-19`）：关闭即丢弃。

**U50. SnippetsDialog 空状态文案与按钮不符**（`SnippetsDialog.tsx:294` vs `216`）：空状态说"点击 + 添加"，实际按钮叫"新建"。

**U51. FileDetailDialog 无 Esc 处理**：且未登记进 `dialogStatesRef`（见 U4）。

**U52. 设置"通用"标签页是一整条长列**（`GeneralTab.tsx`）：数据统计→外观→通用→局域网→快捷键→数据管理无搜索，找配置靠肉眼扫。

**U53. Toast 遮挡右上角窗口控制按钮**（`Toast.module.css:2-20`）：top-right 正是设置/最小化/隐藏按钮位置，toast 期间（4-5s）拦截点击。

**U54. 托盘图标双击=两次 toggle**（`tray_manager.rs:466-492`）：窗口闪烁后停在相反状态，不符合"双击=打开"惯例。方向：去抖或显式处理双击。

**U55. 未处理的 Promise 拒绝原样弹技术文本**（`main.tsx:41-48`）：`后台任务异常：{原始 Error.message}`，可能是英文/堆栈式文本。方向：映射友好文案 + 详情写日志。

**U56. QuickPreview 长行换行后行号错位**（`QuickPreview.tsx:128-139` + `dialog.css:208-249`）：pre-wrap 换行使行号列与内容列垂直失步。方向：禁换行横向滚动。
