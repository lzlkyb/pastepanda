# 手机端 B 分层毛玻璃实施记录

用户确认整体 B 材质方案与连续动效修订后，已接入正式手机页面。布局继续使用已确认的 C 方案，颜色、设备名称与类型图标保持桌面同源。

## 已完成

- 导航、页面标题和控制工具采用轻透材质，配对、设备操作、文件选择、历史、外观、控制设置等共享弹层采用厚透材质；正文与电脑画面保持清晰。
- 浮动导航增加独立选中底片，以统一弹簧平移，快速反向操作保留位置与速度。
- 页面切换加入 200ms 短距离转场，动画中再次切换接当前画面状态；文件页保留原有状态，不因转场重新挂载。
- 标题随滚动收拢，使用 transform 而不是逐帧改变字号。
- 按压立即响应；设备与设置行只轻微压缩，松开恢复。
- 弹层从屏幕底部进入、滑出后卸载，退出期间保留最后内容，重开取消旧退出动作。
- 手柄跟手移动，短拖回弹，距离或释放速度决定收起；支持系统返回、Esc 和键盘激活手柄。
- 弹层完全滑出屏幕后释放焦点，不等待不可见的弹簧尾段；尺寸变化时重新读取终点并保留运动状态。
- 横屏或软键盘压缩可用空间时，弹层正文独立滚动，手柄和关闭按钮保持在顶部。

## 架构与性能边界

`src-mobile/ui/mobileSpring.ts` 统一位移模型，遵循项目 U2 的 m=1、k=130、c=16；颜色与遮罩不使用弹簧。每次操作有终点和 1200ms 上限，不增加常驻动画循环。

`useSheetDrag` 管理手柄与动画生命周期，`MobileSheet` 保留 Radix 的焦点和弹窗语义；`useMobileTabMotion` 管理导航位移与可中断页面转场。未增加运行时依赖。

模糊不加到设备行、文件任务或远程画面上。弹层出现时暂停下层标题、导航和控制工具的模糊；隐藏的横屏工具栏也关闭模糊。弹层几何只在打开、关闭和尺寸变化时读取，动画帧不逐帧读取高度。

系统减少动态效果会结束位移与转场；减少透明度使用实底并关闭模糊。浏览器页面隐藏时结束进行中的动效，卸载时释放动画、媒体偏好监听和 ResizeObserver。
