# 手机知识库：收集与轻维护交付记录

2026-10-08。接续首版本机查阅与独立记录，按用户已确认方案实施。附件沿用 A：缺图时单张补齐、兼容旧电脑。版本保持 7.2.10。

## 本次已实现

| 用户任务 | 入口与行为 |
| --- | --- |
| 修改已有笔记 | 全文 → 更多 → 修改笔记；支持标题、Markdown 正文预览、已有文件夹和标签选择。修改草稿独立落盘，不占用新建记录草稿。保存后立即显示新正文与本机成功回执。 |
| 处理版本变化 | 保存时在同一数据库事务中核对基础版本。原笔记已更新或删除时保留手机输入；用户可继续修改或明确另存手机副本。超时重试核对同一回执，不重复创建、不复活已删除笔记。 |
| 收集文字、链接与图片 | Android 系统分享进入持久待处理队列；预览后转为手机草稿，再由用户保存笔记。新建草稿已有内容时禁止覆盖；编辑时收到分享有可见入口。多条待处理内容可选择。 |
| 给草稿加图片 | 新建/修改页 → 添加图片；系统选择器结果与选取时的草稿和此次载荷对应。图片私有复制、格式/尺寸/哈希校验后持久保存。取消选择不改草稿。 |
| 重试收集清理 | 内容落盘后才清理待收集队列。清理失败可继续编辑、保存笔记；重试不会重复追加或创建空白编辑页。 |
| 阅读与分享图片 | 全文可以打开本机图片预览；更多中可分享正文文字或文字与本机图片。FileProvider 只读授权；系统面板打开只显示打开结果，不冒充对方已接收。 |
| 补齐缺图 | 图片读取失败后手动打开补图面板，从知识库授权电脑获取单张图片；可停止，成功后返回正文。不会因打开文章自动联网。旧端不支持时解释升级/完整同步路径。 |
| 跨平台附件 | 统一 Windows/POSIX/file URL/便携及 images 相对引用；手机新采集图片参与原完整同步。规范化回声比较，减少路径差异造成的无效冲突。 |

入口均复用手机统一提示和面板。阅读中无正文替换；本机保存、图片落盘、电脑同步、系统分享四种结果分别呈现。编辑底部反馈限定高度并独立滚动，保存按钮保留可见位置。没有新增 AI 调用。
