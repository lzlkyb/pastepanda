# 手机端连续动效修订

本次更新整体毛玻璃设计稿，正式 UI 尚未接入。沿用现有布局、颜色、设备识别和触控语义。

## 从苹果设计中采用的原则

- 位置连续、速度连续：动画中再次操作时从当前位置转向；手势结束后传递释放速度。
- 弹簧的意义是自然衔接和逐渐停稳，不是所有控件都夸张反弹。
- 直接操控先跟手：拖动时不加缓动，松开才进入弹簧。
- 动效为状态关系服务，内容无需等待动画结束即可操作。

来源：[Animate with springs, WWDC23](https://developer.apple.com/videos/play/wwdc2023/10158/)、[Designing Fluid Interfaces, WWDC18](https://developer.apple.com/videos/play/wwdc2018/803/)。这是 Web 设计稿对上述原则的应用，不是苹果原生动画引擎的复刻。

## 本稿修订

| 场景 | 原设计稿 | 修订 |
|---|---|---|
| 切页 | 内容直接替换 | 短距离方向转场，200ms；重复操作接当前画面状态 |
| 导航选中底片 | 固定时长位移 | 弹簧转向，保留当前位置与速度 |
| 弹层打开 | 从 35px 偏移出现 | 从屏幕底边完整进入 |
| 弹层关闭 | 立即隐藏 | 滑出结束后隐藏，期间可反向打开 |
| 手柄拖动 | 跟手，但释放固定缓动 | 抓住即接管；松手按距离和速度决定回弹或收起 |
| 快速下甩 | 仅看拖动距离 | 大于 16px 且下甩速度大于 600px/s，或距离大于 80px 即收起 |
| 标题收拢 | 动画修改字号 | transform 缩放，避免逐帧文字重排 |
| 按压 | 逐渐缩小 | 按下立即轻压，松开恢复；行只轻微压缩 |

位移使用项目 U2 的统一弹簧 m=1、k=130、c=16，不增加可调参数。颜色和遮罩保持 150ms 贝塞尔，内容转场 200ms；它们不使用弹簧。大弹层打开时顶部过冲被边界限制，避免底边露缝。

## 实现与验收边界

- 解析弹簧按经过的时间采样，避免刷新率改变轨迹。每次操作最多运行 1200ms，停稳后不继续请求动画帧。
- 快速反向操作取消旧完成回调，避免旧关闭回调误隐藏已经重开的面板。
- 页面隐藏或系统启用减少动态效果时完成当前位移、停止动画；拖动取消时回位。
- 模糊半径、颜色与布局尺寸不逐帧动画。此稿只有 3 个固定对比面板，不代表生产页可以无限增加动画或毛玻璃层。
- 设计稿可试验按钮快速连点、弹层开合、下拉回弹、下甩关闭、Esc 和手柄键盘收起。
- 远程指针、触控滚动、屏幕缩放继续直接响应，不给远程输入增加视觉惯性。
- 当前仅验证浏览器原型行为，未测真实 iPhone/Android 的帧率与掉帧，不宣称达到原生性能。

正式实施顺序：先把弹层的跟手、中断、速度衔接接入共享组件，再统一导航和按压，最后做设备与软键盘场景验证。配对、控制权限和网络业务保持既有逻辑。
