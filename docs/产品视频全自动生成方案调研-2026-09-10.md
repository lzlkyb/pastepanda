# 软件产品视频「全自动生成」方案调研

> 撰写日期：2026-09-10  
> 问题：如何尽量自动生成 PastePanda 产品介绍视频（脚本 → 画面 → 配音 → 成片）  
> 约束：不伪造产品 UI；Windows 本机可跑；尽量少手工剪辑

---

## 1. 结论先说

| 路线 | 自动化程度 | 成本 | 可信度 | 适合 |
|---|---|---|---|---|
| **A. HyperFrames + Agent 技能（推荐）** | 高（脚本→HTML→TTS→MP4） | 开源免费 | 真截图 + 动效，中高 | 官网/B站通用底版 |
| **B. Arcade 等 SaaS「AI 产品视频」** | 很高（网页/截图→成片） | 订阅 | 中（偏营销模板） | 要快、接受品牌模板感 |
| **C. 传统录屏 + 剪辑工具** | 低 | 时间贵 | 最高 | 信任向长片/真操作演示 |
| **D. 纯 AI 文生视频** | 高 | 按分钟计费 | **低（UI 会画假）** | 只适合 2–3s 抽象 B-roll |

**PastePanda 建议主走 A**，B 可作并行试验（交互 demo），C 作升级替换，D 只做片头氛围。

---

## 2. 方案 A：HyperFrames（本机已装）——最适合「可重复全自动生成」

已验证本机：`design/promo/hyperframes/` 内 `hyperframes@0.8.33` 可用（Node 24 + 可接 imageio-ffmpeg）。

### 2.1 能力拼图（一条流水线）

| 步骤 | 命令/能力 | 作用 |
|---|---|---|
| 素材 | `hyperframes capture <URL>` | 把网页/产品页抓成可编辑组件与截图（最多 24 屏） |
| 分镜 | HTML + `data-*` 时间轴 + GSAP | 定动画，**无构建步骤**，浏览器可预览 |
| 配音 | `hyperframes tts`（Kokoro 本地） | 文本→wav；含中文声 `zf_xiaobei` |
| 字幕 | `hyperframes transcribe` | 词级时间戳，可对硬字幕 |
| 校验 | `lint` / `check` / `snapshot` / `inspect` | 渲染前验布局与关键帧 |
| 成片 | `hyperframes render` | 本地或 Docker → MP4/WebM；可选云端 |
| 增强 | `remove-background`、音频总线 | 透明素材、人声闪避 BGM |

### 2.2 Agent 技能（官方有产品片工作流）

`hyperframes skills` 可安装给 Claude/Cursor 等；与「产品介绍」直接相关：

- **`/product-launch-video`** — 从 URL/简报/脚本做产品介绍片（约 30–90s 最合适，最长 ~3min）
- `/general-video` — 多场景/品牌 sizzle
- `/faceless-explainer` — 纯解说概念片
- `/motion-graphics` — 片头、标题卡、转场
- `/embedded-captions` / `/talking-head-recut` — 后期字幕与包装
- 域技能：`/hyperframes-core` `/hyperframes-animation` `/media-use` `/hyperframes-cli`

> 本机 `hyperframes skills check` 需联网；安装后**新开对话**才会被 agent 读到。  
> 可用：`npx hyperframes skills update` 或 `npx skills add heygen-com/hyperframes`。

### 2.3 内置模板

`hyperframes init --example`：`blank` / `title-card` / `video-edit`  
可直接复制做片头卡、时间轴样例。

### 2.4 全自动流水线（PastePanda 落地）

```
1. 文案事实源          docs/知识库-推广文案.md + 分镜表
2. 真机截图（原尺寸）   脚本截 PastePanda 窗口，敏感区遮罩
3. 起 composition      HTML 分镜（钩子→剧场→信任→CTA）
4. hyperframes tts     中文旁白 wav（zf_xiaobei，语速 1.1）
5. hyperframes lint/check/snapshot
6. hyperframes render  → design/promo/pastepanda-intro-120s.mp4
```

改文案 → 改 HTML 常量 → 重渲，**无需重录屏**（静态镜头）。  
有真操作录屏后，把 `<video class="clip">` 塞进对应时间点即可。

## 3. 方案 B：Arcade（SaaS AI 产品视频 / 交互 Demo）

**产品形态**（arcade.software）：

1. 从网站拉 Brand Kit（logo/色/字体/文案风格）  
2. 附上截图、messaging 文档  
3. Prompt 生成产品介绍片 / social sizzle  
4. 可再 AI 分镜改或手工改  
5. 导出视频/GIF，或做**可点击交互 demo** 嵌官网  

宣称平均 6 分钟出一条；有浏览器扩展 + 桌面捕获；偏 GTM/营销场景。

**对 PastePanda：**

| 优点 | 缺点 |
|---|---|
| 最快出「能看」的片 | 订阅制；中文产品工具向可能模板感重 |
| 交互 demo 转化好（调研里也提过 1.7×） | 画面/口播控制不如 HyperFrames 精细 |
| 不用自己写时间轴 | 真 UI 细节仍可能被美化/改写 |

**用法建议**：官网「交互 demo」用 Arcade/Storylane 试水；**主宣传片仍用 HyperFrames** 保可控。

同类：Storylane、Guidde、Supernormal、Loom AI 等，思路接近，不重复展开。

## 5. 推荐决策

1. **主产线：HyperFrames 全自动底版**（通用 60–120s 横屏）  
   - 输入：分镜文案 + 窗口原尺寸截图（遮罩）  
   - 输出：可重复生成的 MP4  
2. **官网交互 demo：Arcade 免费档试水**（与片并行，不占主产线）  
3. **信任升级：后期把 2–3 个静态镜头换成 Cap 真录屏片段**  
4. **禁用纯文生 UI 视频**做演示画面（项目红线：演示必须真）

### 自动化程度预期

| 项目 | 自动 | 半自动 | 人工 |
|---|---|---|---|
| 脚本/分镜 | 模板+改写 | | 终审事实红线 |
| 截图 | 脚本截窗 | 遮罩敏感 | 首次定演示库 |
| 动效/字幕/配音 | HTML+TTS | | 旁白终审 |
| 渲染 | CLI | | |
| 发布文案/封面 | 模板 | | 平台上传 |
