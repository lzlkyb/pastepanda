# 卡片悬浮行为：统一复制入口

## 已确认范围

按方案①移除常驻复制，统一服从既有 `hover_mode`，不新增设置、不改版本号。
设计稿：`design/卡片复制-统一悬浮行为-2026-10-18.html`。

- `off`：不渲染复制按钮和气泡；右键菜单及双击配置仍可用。
- `inline`：悬停立即展开操作，复制补回内嵌操作栏；选中卡片可以通过 Tab 进入操作。
- `popover`：鼠标停留 180ms 后展开；移出保留 150ms 衔接窗口，进入气泡取消关闭。
- 只有键盘焦点保持展开；鼠标点击留下的按钮焦点不让操作栏常驻。
- 复制中、成功提示的 1500ms 内保持反馈可见，失败仍由可重试 toast 展示。

## 动画与结构

操作栏使用 150ms 透明度、200ms 小幅位移；叠层接替时间位置，不改变正文宽度和行高。
减少动态效果时去掉操作栏位移；气泡退出遵循已有 MotionPolicy。
不添加循环动画、逐帧循环或卡片背景模糊。关闭模式及禁用预览时不启动悬浮定时器，卸载会清理未完成任务。

原 `Card.tsx` 有 1120 行。按组件文件限制拆出展示、图标、气泡、操作栏，以及悬浮和上下文菜单 Hook；保留原公开导出。
上下文菜单正文和高亮组件与移动前源码做了逐字比较；OCR 与条码复制仍各保留一份共享实现。

## 红绿证据

1. 修改前运行 `npx vitest run src/components/card/CardHover.test.tsx --maxWorkers=1`：**6 failed / 6**。
   关闭模式仍渲染复制；内嵌复制常驻且可 Tab；选中卡片不可聚焦；气泡有重复复制入口；切换记录或关闭模式仍残留常驻入口。
2. 连续复制反例：`npx vitest run src/components/card/CardCopyButton.test.tsx --maxWorkers=1`：**1 failed / 4 passed**。
   第一次成功后 1400ms 再复制，旧的 1500ms 定时器把第二次「复制中」重置为「复制」。修复为新请求开始时取消旧确认定时器。
3. 鼠标焦点反例：`npx vitest run src/components/card/CardHover.test.tsx -t '鼠标点击留下' --maxWorkers=1`：**1 failed / 12 skipped**。
   鼠标按下后聚焦按钮再移出，原先仍保留 `tabIndex=0`。现区分鼠标与键盘焦点。
4. 最终相关用例：**5 files / 73 passed**，命令如下，输出保存在本会话 `.cache/card-hover-green.log`：

```powershell
npx vitest run src/components/card/CardHover.test.tsx src/components/card/CardCopyButton.test.tsx src/__tests__/highlightText.test.tsx src/__tests__/CardMenuBuilder.test.tsx src/__tests__/settingsOrganization.test.tsx --maxWorkers=2
```

`npx tsc --noEmit` 通过；本轮改动文件 ESLint 通过；`npm run lint:ui` 无 block，剩余建议包括其他会话的录屏间距和移动前已有的图片重试图标。Impeccable 对四个主要卡片组件的扫描返回 `[]`。

浏览器使用正式组件及样式、模拟剪贴板 IO 验证：键盘展开、浅深主题、关闭模式、失败重试、减少动画。展开前后三张卡片高度均为 72px，正文宽度保持不变。该验证不替代系统剪贴板或桌面原生窗口的端到端检查。
