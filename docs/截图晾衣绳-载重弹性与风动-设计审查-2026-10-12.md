## 五项优先问题

1. **P1：载重与弹性尚未接通。** HTML 583–588 行的 `sag` 只跟跨距和档位有关。直接运行原几何函数，1440 宽度、默认中档、有灵动岛时，1/3/5/8 张最大下垂全部为 23.76px；浏览器从 5 挂到 7 张，`ropePath` 完全不变。79–98 行只摆新卡，649–655 行直接更新绳路径。建议负载决定平衡形状，挂图时夹点先拉低、绳整体回弹，邻近照片跟随；取下时卸载也回弹。空绳保留浅弧，最多张数时下垂封顶。
2. **P1：收衣不是贴图，动作含义分裂。** HTML 1089–1093 行 `gather()` 只执行 `addPanel()`；浏览器验证收衣后 0 挂图、7 管理行、0 `pinGhost`。真实 `PinnedPanel.tsx:26` 调用 `list_pinned_images`，`pinned_window.rs:1255` 只枚举当前原生贴图窗口，不能直接当关闭贴图的存档。单张与整绳收衣均应创建真实桌面贴图，成功后才卸下；部分失败保留失败卡并就地重试。批量落点限制在工作区内，避免全部堆叠或抢焦点。
3. **P1：取消和撤销不可靠。** 1060–1080 行超过 4px 即转贴图，没有判断是否离开绳带，没有 `pointercancel` 收尾；1083–1087 行全局 Esc 会整绳收衣；993–996 行撤销 `pop()` 最后一张，期间新挂图会改变目标。4px 只作为拖动识别，真正离开绳带才显示脱绳预览，松手采纳；Esc/捕获丢失还原拖动；Esc 只取消当前层级；撤销绑定 ID 和操作快照。
4. **P2：轻风、大风及退出语义需要一体设计。** 现稿无风动入口。轻风建议可见、非空时每 20–45 秒偶发一次，绳位移约 2–4px、照片摆角约 1–2°，方向与相位有微小差异，固定端点保持不动。鼠标靠近、键盘聚焦、拖动、预览时暂停，命中区域跟随实际位置。大风仅由明确的“清空绳子”入口触发：夹子松开、照片顺同一风向错峰飞走、卸载后的绳回弹；立即给出“已清空，历史仍保留”和约 8 秒撤销。只移出绳子，不删除剪贴板历史，不等同收衣。动画不得阻塞后续截图，连续操作按快照区分新旧卡片。
5. **P2：稿子的可读性与性能证据需修正。** 浏览器深色主题下 html/body/正文背景透明，正文颜色 `rgb(228,228,231)` 落在白画布上，正文难读。舞台缩放后小字和管理行过小；应显式使用主题背景，提供真实 100% 查看方式，使用实际截图素材检验识别度。486/523 行从 `getAnimations() === 0` 推导“合成层数为 0”不成立。加入微风后，需重新测隐藏/关闭/空绳时调度停止，以及最多卡片时 CPU、内存、帧时间，不能沿用旧性能声明。

## 操作闭环

| 动作 | 结果 | 反馈与恢复 |
|---|---|---|
| 新图挂上 | 负载增加，绳与挂点回弹后稳定 | 保留可见状态；动画过程中仍能操作 |
| 单击照片 | 查看原图 | 预览内可见“取下为贴图”；Esc 关预览 |
| 拖出绳带 | 落点预览；松手转真实贴图 | 创建成功才移除；取消回到原挂点 |
| 收衣 | 单张/全部转桌面贴图 | 成功数量明确，失败卡留绳并可重试 |
| 清空绳子 | 大风吹离，只移除绳上归属 | 历史保留，撤销恢复对应快照 |
| 关闭功能 | 停止绳显示、风调度与运动 | 不改变原有采集能力；现有照片处置应明确 |

收下动作使用 Pin 图标与文字，避免用危险色 × 表达“收藏/贴图”。管理列表“挂回”当前只向绳追加，未移除行（1041 行）；应统一卡片归属与 ID，防止重复挂回。

湿/半干/干可保留为视觉语言，但可用性必须由真实状态决定，不能靠固定等待时间假装处理中；失败显示“读取失败 · 重试”，避免只说“沾污”。自有截图应在实际捕获前隐藏绳和预览，并在结束后恢复，遵守预览不进入产出的规则；外部截图工具无法统一控制，应提供可达的临时隐藏入口，不宣称已解决所有外部捕获。

## 两种实施方向

| 方向 | 方法与优点 | 代价 |
|---|---|---|
| A：受控受力曲线，推荐默认 | 负载/挂点决定平衡形状；统一弹簧驱动绳与照片位移；有限轻风扰动。操作稳定，几何边界与性能较容易验证 | 局部扭动采用近似，真实性依赖设计调校 |
| B：逐段绳索求解 | 少量绳节点、挂点重量和约束统一求解，再带动照片摆动。局部压绳、波传播和风动更真实 | 更新、碰撞与稳定性测试成本更高；必须实测，不能预先承诺帧率 |

两种方向均满足“越多越垂、挂上弹性、偶发轻风、大风清空、收衣到贴图”；区别是物理真实性与工程成本。按 AGENTS.md 第 1/4 条，确认方向后先完善 HTML 交互稿，再确认产品落地。
