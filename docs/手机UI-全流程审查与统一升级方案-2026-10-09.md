# 手机 UI 全流程审查与统一升级方案

日期：2026-10-09。范围：设备、文件、远程会话、知识库、设置，以及公共导航、弹层和提示。本文是当前源码审查与待确认的升级方案，**不是已完成的生产改动**。

## 1. 结论与方向选择

手机端已有可复用的基础：实底分组、移动字号与主题令牌、公共 Sheet / Notice / Toast、画面优先远控、独立 Android 构建。主要问题是新增功能没有充分收口：入口重复、返回层不统一、操作回执没有绑定正确对象、相同任务用了不同控件。

| 方案 | 范围 | 优点 | 代价与局限 |
|---|---|---|---|
| A：修错与局部清理 | 状态归属、返回栈、误导文案、禁用条件、字号 | 回归范围小，较快解决明确问题 | 多套编辑器、重复入口和使用文件的流程缺口仍存在 |
| **B：统一高频任务，推荐** | A + 统一选择控件/反馈/返回 + 设备/远控入口收口 + 知识库编辑与同步层级 + 文件完成出口 | 延续已确认视觉，解决使用成本，有利于二期扩展 | 跨页面联动；文件打开与导出需要 Android 能力；快捷收集与新建分类需要数据流程补充 |
| C：全面重排产品架构 | 重做主导航、页面组织和整套视觉 | 可系统重定产品结构 | 改变已有习惯、风险与验证成本最高，现阶段没有必要 |

B 的可交互设计稿：[mobile-ui-unification-2026-10-09.html](../design/mobile-ui-unification-2026-10-09.html)。可查看六个主要场景、小屏/短横屏/竖屏、大字、深色、成功与失败反馈。所有数据和回执都是模拟，不连接电脑，不修改真实笔记或手机设置。

## 2. 证据与验证边界

- 已读取真实 TSX / CSS / 状态 Hook；使用 UI UX Pro Max、impeccable 和项目交互/UI规则核对。
- 按项目规则执行自定义 `codex review`，只审 App、主导航、返回、Sheet 与相关测试。审查通过真实 Hook 的内存 jsdom 场景复现了“收件箱抢页”和“主导航返回层抢先”两项问题；没有修改应用源码。
- 知识库隔离验收页使用真实组件、模拟 IPC。390×844 的全部列表中，同步入口顶部位于约 **3274px**，在首屏之外；短横屏 740×360 的新建页仍可看到保存按钮，不能把它笼统判为横屏不可用。
- 远控侧栏和 Android 系统返回的具体真机显示、原生文件打开/导出、系统栏沉浸状态，本轮未操作手机；源码推导与待真机验证项分别列明。
- 机械检测命中 Markdown 引用左边框，人工判为正常引用语义，不纳入问题。更新页的版本号渐变与字体漂移纳入低优先级。检测器未能解析 boot CSS，不能据此宣称全端视觉/可访问性已通过。

## 6. 统一组件与边界

沿用现有模块，增量收口，不建设一套平行“新 UI”。以下为拟实施职责名，最终命名按仓库风格确定。

| 职责 | 现有基础 | 拟收口内容 |
|---|---|---|
| 页面与编辑页头 | MobilePage / 各知识库 head | 同一高度、返回/标题/动作结构；新建与修改允许语义差异 |
| 单选与多选 | 各页 radio / 分类 checkbox | 相同选择视觉；单选与多选行为独立，大量项目时再提供搜索 |
| 反馈 | MobileNotice / MobileToast | tone、对象/批次、短回执/长期异常、当前可见域；不擅自把本地成功变成对端成功 |
| 面板与返回 | MobileSheet / useMobileBack / useMobileNavigation | 单一面板所有者，子流程返回、关闭全部、退出动画与焦点回归；低优先级主导航 |
| 编辑工作区 | KnowledgeEditor / KnowledgeEditPanel | 同一排版与工具壳；持久化、冲突副本、保存锁继续按各自模型处理 |
| 远控操作层 | SessionToolbar / MouseAssist / FloatingMouse | 每模式操作映射、单一点击守卫、反馈与工具滚动分开 |
| 已接收文件操作 | RcFileTaskList / Android 插件 | 打开/分享/导出真实文件；取消、权限拒绝、无应用、文件失效可恢复 |

所有新 TSX 遵守 300 行限制；跨组件纯工具进入 src/lib/utils.ts；AI 开关/密钥门控不因美化改变。新增平台能力要独立于纯视觉组件，不能让 UI 自行拼 file:// 路径访问私有存储。

## 7. 分批实施与验收

### 批次 1：修确定的状态与导航错误

- F01/F02/F04/F06/F08/F09：先写能复现的行为测试再修。
- 导航父子集成测试必须使用真实 useMobileBack，覆盖 React 子/父 Effect 注册、Sheet 退出动画、键盘/页面隐藏恢复、重复返回。
- A 发送失败→选 B：B 不能展示 A 的恢复按钮；A 历史仍可查。失败回执重试始终保持原对象。
- 加载更多期间，已取得笔记可打开；滚动态左右键行为无论哪个入口都一致。

### 批次 2：公共视觉与高频流程

- 统一选择/编辑壳/提示语义，收口设备添加、远控工具、知识库收藏。
- 同步摘要始终可发现；普通成功反馈收起后内容不被长期挤占；重要异常在同一可见域可恢复。
- 更多→画质→返回回更多，关闭全部回画面；设备管理/扫码/确认依次退回。
- 文字模式一键恢复中文；模式帮助不长期盖住画面；收起辅助条的偏好被保留。

### 批次 3：补全对用户有用的出口

- 已收到文件：真机可打开/分享/导出；取消不丢源文件；文件缺失、无处理应用、授权拒绝均提供准确反馈。
- 分享快捷保存：保持草稿与队列的持久化顺序和重复调用幂等性；已有草稿不覆盖；部分图片失败可以保留已有内容。
- 新建分类：同步/未知分类处理、已删除分类、草稿恢复与保存重试不造成重复笔记；不增加首屏必填负担。

### 所有批次共同验收

- 320×568、390×844、740×360、844×390、大屏可用高度；系统字号 100%/125%/150%；浅色/深色；安全区/键盘打开/横竖屏旋转。
- 正文、远程画面和首要操作不被遮住；错误在短横屏无需寻找工具列表底部。
- 控件触控面积沿用至少 48px；焦点可见，读屏能识别当前选择/加载/结果；避免只靠颜色。
- Android 返回、返回按钮、下拉关闭的层级语义一致；退出弹层不清空未保存输入。
- 只使用 transform/opacity 等短进出动画，尊重减少动态效果；无隐藏页面常驻动画/轮询，不宣称未测性能。
