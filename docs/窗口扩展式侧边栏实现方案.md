# 窗口扩展式侧边栏 — 实现方案

> 目标效果：点击 ☰ → 窗口从 480px 平滑扩展到 680px，TopBar 纹丝不动，侧边栏在 TopBar 下方展开。

## 设计稿核心动画机制

`p0-sidebar-below-topbar.html` 第 57-69 行：

```css
.app-shell { width: 480px; transition: width 0.35s cubic-bezier(0.4, 0, 0.2, 1); }
.app-shell.expanded { width: 680px; }

.sidebar { width: 0; transition: width 0.35s cubic-bezier(0.4, 0, 0.2, 1); }
.sidebar.open { width: 200px; }
```

**关键：窗口 +200px 同时侧边栏展开 200px，卡片区域不变化。**

## 实现策略

HTML 设计稿用 CSS transition 改变 `.app-shell` 宽度只是视觉模拟。在真实的 Tauri 应用中，我们需要**调用 `window.setSize()` 来改变原生窗口大小**，同时用 CSS transition 让侧边栏同步展开。

### 涉及的文件

| 文件 | 改动 |
|------|------|
| `src/components/Sidebar.tsx` | **新建** — 侧边栏组件 |
| `src/components/Sidebar.module.css` | **新建** — 侧边栏样式 |
| `src/App.tsx` | 集成侧边栏 + 窗口大小管理 |
| `src/App.module.css` | 添加内容区 flex 布局 |
| `src/components/TopBar.tsx` | 添加 ☰ 按钮 + 回调 |

## 实现步骤

### 步骤 1：创建 Sidebar 组件

新建 `src/components/Sidebar.tsx`：

- Props: `open: boolean`, `onClose: () => void`
- 内容: 分组列表（全部/未分组/收藏 + 用户自定义分组）
- 动画: `width` 从 0 到 200px，`transition: width 0.35s cubic-bezier(0.4, 0, 0.2, 1)`
- 子元素（header/list/footer）用 `opacity` 延迟淡入，防止宽度变化时文字折行闪现

### 步骤 2：窗口大小管理

在 `App.tsx` 中：

```typescript
const SIDEBAR_WIDTH = 200;
const BASE_WIDTH = 480;

async function toggleSidebar() {
  const { getCurrentWindow } = await import("@tauri-apps/api/window");
  const win = getCurrentWindow();
  const isOpen = sidebarOpen;
  
  if (isOpen) {
    // 先收侧边栏 → CSS transition 0.35s
    setSidebarOpen(false);
    // 等 CSS 动画结束后再缩小窗口
    await new Promise(r => setTimeout(r, 50));
    await win.setSize(new LogicalSize(BASE_WIDTH, 700));
  } else {
    // 先扩展窗口
    await win.setSize(new LogicalSize(BASE_WIDTH + SIDEBAR_WIDTH, 700));
    // 然后展开侧边栏
    setSidebarOpen(true);
  }
}
```

**时序说明**：
- 打开：先 `setSize(680)` → 窗口变大 → 再 `setSidebarOpen(true)` → CSS transition 展开 200px
- 关闭：先 `setSidebarOpen(false)` → CSS transition 收起 → 再 `setSize(480)` → 窗口变小

### 步骤 3：CSS 布局改造

`App.module.css` 新增：

```css
.contentArea {
  flex: 1;
  display: flex;
  overflow: hidden;
  min-height: 0;
}
```

`App.tsx` JSX 结构：

```tsx
<div className={appStyles.appShell}>
  <TopBar onToggleSidebar={toggleSidebar} sidebarOpen={sidebarOpen} />
  <div className={appStyles.contentArea}>
    <Sidebar open={sidebarOpen} onClose={() => toggleSidebar()} />
    <div className={appStyles.cardPanel}>
      <ScrollProvider>
        <CardList />
      </ScrollProvider>
    </div>
  </div>
</div>
```

### 步骤 4：TopBar 添加 ☰ 按钮

在 `TopBar.tsx` 标题区域左侧添加 sidebar toggle 按钮（36×36 圆角按钮），传入 `onToggleSidebar` 和 `sidebarOpen` props。

## 关键注意事项

1. **Tauri `setSize` 使用 `LogicalSize`**，不是 `PhysicalSize`（避免 DPI 缩放问题）
2. **打开时先扩窗口再展侧边栏**，关闭时先收侧边栏再缩窗口，避免侧边栏内容在窄窗口闪现
3. **过渡时间保持一致**：CSS `0.35s` + `cubic-bezier(0.4, 0, 0.2, 1)` = Material Design 标准缓动
4. **TopBar 完全不受影响**：它是 `flex-shrink: 0`，在 `contentArea` 上方独立存在
5. **窗口 `resizable: true`** 已在 tauri.conf.json 中配置，`setSize` 可以直接工作

## 对比：为什么不用纯 CSS 方案

| | CSS `width` transition | Tauri `setSize` |
|---|---|---|
| 窗口大小 | 不变（内部模拟） | **真正改变窗口** |
| 其他应用遮挡 | 不会 | 会推开其他窗口 |
| 实现复杂度 | 简单 | 需要异步 API 调用 |
| 用户体验 | 视觉正确 | **完整正确** |
