快速开始

PastePanda 是一个常驻系统的剪贴板增强工具：自动记录你复制过的所有内容，并叠加截图标注、OCR、开发者转换、AI、跨设备同步等能力。复制即记录，粘贴即执行。

第一步 · 启动与常驻

  • 安装后启动 PastePanda，它最小化到系统托盘（任务栏右下角），不占任务栏空间，可随系统开机自启（设置里可关）。
  • 点击托盘图标或按 Ctrl+Alt+V 打开主窗口；主窗口关闭后程序继续在后台记录剪贴板。
  • 首次使用建议先确认「设置」里的全局热键（见快捷键一览），之后全程用键盘操作，几乎不用碰鼠标。
💡
隐私优先：所有内容默认只存在你这台电脑上。OCR 用本地 PP-OCRv6 引擎离线识别，AI 默认关闭——开启前不会把任何内容发往外部；只有你主动对某条内容执行 AI 动作时，那一条才会被发送到所选服务商，且密钥/凭证类内容会先拦下来请你确认。

第二步 · 复制点什么

像平常一样复制文本、链接、图片、文件、代码……PastePanda 会在后台自动归档。打开主窗口，刚复制的内容就在最上方。

第三步 · 粘贴它

  1. 主窗口里 单击 任意一条即可复制回剪贴板，再 Ctrl+V 粘贴。
  2. 或 双击 条目，多数类型会直接粘贴到上一次聚焦的应用（复制即执行）。
  3. 挑着粘贴多条？用 Alt+V 唤起快捷粘贴面板，方向键浏览、回车粘贴。

顶栏（自左向右）

  • ☰ 侧边栏开关 + 应用名 + AI 品牌上标 + 更新红点（有新版本时）。
  • 📚 收集模式（栈模式）：一键开关，开启时顶部出现收集横幅，Ctrl+C 逐条收进粘贴栈。
  • 🧰 工具箱：下拉分组面板（详见「开发者工具箱」），收纳依次粘贴 / 片段库 / 内容提取 / 新建流程图 / 编码转换 / 批量替换 / 配置对比。
  • AI 胶囊（未配置时显示，点击进 AI 设置）+ ⚙ 设置（已配置 AI 时带 6px 绿点）+ 最小化 / 隐藏到托盘。
  • 搜索 + 时间筛选 + 来源筛选 同行；下方是分类 Tab（全部 / 文本 / 图片 / 文件 / 收藏，带计数，可在设置切换「分段控件 / 圆形图标」两种样式）与标签筛选栏（🤖 智能标签 / 🏷️ 我的标签 chips）。

侧边栏（分四区）

  • 内置分组：全部 / 未分组 / 收藏。
  • 分组：用户自建分组，可设颜色与图标；右键重命名 / 改色 / 删除。
  • 智能分类：AI 自动标签作为虚拟分组（本地标签引擎，未开启 AI 也工作）。
  • 来源：按复制来源应用自动分组，显示真实应用图标（可切换 Emoji 模式）。

剪贴板管理

主窗口的卡片流就是你的剪贴板历史。每种内容有独立图标与配色，支持搜索（含拼音首字母）、置顶、分组、标签、批量操作与深度清理。

展开详解3 小节 · 共 11 项

先看类型：它决定了这条能做什么

识别出的类型不只是换个图标——右键菜单的主操作是什么、有哪些变换可用、要不要自动 OCR，都由类型决定。所以遇到「这条怎么没有那个选项」，先看它被识别成了什么。

  • 文本 / 链接 / 邮箱 / 电话 / 颜色 / 数字：纯文本及其子类型，链接可一键打开、邮箱电话可直拨、色值显示色块（HEX/RGB/HSL 互转）。
  • 代码 / JSON / 配置 / 日志 / SQL：紫底图标，悬停预览带语法高亮。
  • 图片 / 图文混排：显示缩略图；截图图片自动 OCR，徽标显示「已识别 N 行」。图文混排（Word/网页复制）完整保留图片与文字顺序，可编辑。
  • 文件 / 文件路径：绿色图标，可「用默认应用打开」或「在资源管理器中显示」。
  • 密钥 / 密码：自动脱敏遮罩，双击在编辑器内查看。
  • 流程图：粘贴 Mermaid 等 Diagram，卡片显示节点/连线数，可展开可视化编辑。

找回一条，或让它别被清掉

什么时候用：刚复制的东西被后面的复制顶下去了；或者要找上周贴过的那段；或者有几条常用内容希望永远在手边。

  1. 还在最近几条——Ctrl+Alt+V 打开主窗口，最新的就在最上方。单击复制回剪贴板，双击直接粘贴到上一个应用（复制即执行）。
  2. 只记得几个字——顶栏输入框实时过滤，命中处高亮。中文可以只打拼音首字母：搜 th 能命中「腾讯」。搜索历史会记忆，下次不用重打。
  3. 要一直留着——悬停浮层 ☆ 或 Ctrl+D 置顶（收藏），钉在顶部，重启不丢。

注意什么：设置里的「自动清理」（关 / 7天 / 15天 / 30天 / 60天）会按时间清掉旧记录，但它不动置顶项；而且默认还开着「保护常用内容」——被打过标签、被粘贴过、或被你搜索找回过的内容，即使超期也不会被清。真怕丢就置顶，那是最硬的一道保险。

一次处理多条

什么时候用：要把几条拼成一段贴出去、导出一批记录、或者比较两份文本的差异。

  1. Ctrl+点击 逐条多选，Shift+点击 选中一整段范围。
  2. 底部出现批量工具栏：全选 / 合并（合并粘贴）/ 导出（导出选中记录）/ 对比（对比差异，需恰好选中 2 条文本）/ 删除（Ctrl+Z 可撤销）。

要清得更彻底：用「深度清理」——按时间 / 类型 / 来源组合条件批量删除，先预览再删，自动跳过置顶项，同样支持 Ctrl+Z 撤销。

高效粘贴

不只是「存下来」，更要「贴得顺」：快捷粘贴面板、粘贴栈、依次粘贴、粘贴守卫与默认格式，把粘贴过程做成可编排的工作流。

展开详解4 小节 · 共 7 项

快捷粘贴面板（Alt+V）

类 Win+V 的浮层：列出最近记录，方向键浏览、回车粘贴、Esc 关闭。适合「从一堆里挑一条贴」的场景，不用先开主窗口。

粘贴栈（Ctrl+Alt+K）

  1. 按 Ctrl+Alt+K（或点顶栏 📚）开启栈模式，顶部出现收集横幅。
  2. 逐条 Ctrl+C 把要拼接的内容收进栈（可跨应用、跨多次复制）。
  3. 按 Ctrl+Alt+P 逐条粘贴，或「全部粘贴」一次输出；横幅显示进度，可随时中止。

依次粘贴（Ctrl+Alt+Q）

把多条文本按顺序逐条粘到目标（适合填表单、SQL 参数）。可先选好多条再触发；设置里可开「依次粘贴循环」与「表格自动拆行入栈」（拆行格式：原始行 / 字段: 值；表头：排除 / 包含）。

粘贴格式与粘贴守卫

  • 默认粘贴格式：设置里选「保留格式粘贴」开/关——关闭时默认以纯文本输出，避免网页/Word 样式。
  • 粘贴守卫：粘贴内容包含密钥/凭证特征时，先弹出确认（脱敏展示），确认后才真正输出，防止敏感内容误贴。
  • 粘贴脱敏变换：右键「变换为 → 粘贴脱敏」，把内容中的敏感字段打码后再粘贴。
  • 主粘贴热键 Ctrl+Shift+V 已不存在：旧文档写法有误，真实对应为「唤出窗口 Ctrl+Alt+V」，粘贴当前记录用 Enter。

变换与正则

对任意文本/JSON/表格/日志，右键「粘贴并变换」或「变换为…」打开变换枢纽——按内容智能推荐可用变换并按匹配度排序，全部本地即时完成。

展开详解1 张演示图 · 4 小节 · 共 18 项

怎么用：记住两个入口就够

什么时候用：手里的内容格式不对，贴过去还要手动调——JSON 要格式化、一列 ID 要拼成 SQL 的 IN、时间戳要看成日期、Word 复制过来要洗掉格式。

  1. 先变换、再贴——右键「粘贴并变换」：选一个变换，结果直接输出到当前应用，剪贴板里那条原文不动。
  2. 只想拿到结果——右键「变换为…」：打开变换枢纽，推荐匹配那一组是按你手里的内容类型排出来的，通常第一个就是你要的。

注意什么：能用哪些变换取决于内容被识别成什么类型，所以同一个菜单在不同卡片上长得不一样（见下方清单末尾那条说明）。全部变换都在本地算完，不出网。

变换清单（真实注册表，按组）

按「我手里是什么」找：下面的分组名就是内容类型。这是完整注册表，不是节选。

  • 文本：大写 / 小写 / 去空白 / 去空行 / 剥离 HTML 标签 / Markdown 链接 / 代码块（```围栏）/ HEX / RGB / HSL / 反斜杠路径 / 正斜杠路径 / 文件名
  • JSON / 配置：JSON 格式化 / INSERT 语句 / 转为 YAML / 转为 JSON / 转为 Properties / 表格 → INSERT（表名可选）
  • SQL：SQL IN（引号：单/双/反引号，包裹：IN/括号/VALUES）/ SQL IN（按列）/ SQL IN（分隔值）/ 拆解 IN 列表（每行一个 / JSON 数组 / 逗号分隔）/ SQL 格式化 / SQL 压缩 / SQL 关键字大写
  • 编解码：Base64 编码/解码 / URL 编码/解码 / Unicode 编码/解码 / HTML 转义/反转义 / JWT 解析 / 时间戳 → 日期 / 日期 → 时间戳
  • 数字：进制转换 / 字节换算 / 千分位 / 时间戳解读
  • 文档：格式清洗 / 转 Markdown / 表格 → Markdown / PDF 断行修复
  • 日志：日志统计 / 提取错误行
  • 安全：粘贴脱敏
  • 执行类动作（不产出文本，直接产生副作用）：打开链接 / 在资源管理器打开 / 发送邮件 / 查询 IP 域名（whois）

同一内容可用的变换会随内容类型智能出现：链接卡片主操作是「在浏览器中打开」，JSON 卡片主操作是「变换为…」，图片是「粘贴为 Markdown 图片」，文件/路径是「在资源管理器中显示」。

正则替换与规则库

什么时候用：同一种清洗要反复做——每次都从日志里挑出错误行、每次都把某个前缀去掉。存成规则，之后右键两下就完事。

  • 右键「正则替换」子菜单列出你的已启用规则，点击即对当前内容套用并预览（提取 / 替换）。
  • 「管理正则规则…」打开规则库：自定义规则（名称 + 正则 + 替换模板），可启停；内置预置规则用 🔤 图标、自定义用 🏷 图标。
  • 工具箱「批量替换」：正则查找替换，支持多条规则依次应用。

注意什么：子菜单里只出现已启用的规则。写好的规则不在菜单里，先去规则库看它是不是被停用了。

编码转换 / 内容提取 / 配置对比

什么时候用：这四件事都在顶栏 🧰 工具箱里，不针对某一条记录，而是对一批内容或两份内容做处理。

  • 编码转换（工具箱）：Base64 / URL / Unicode / HTML 实体等编解码，即时预览。
  • 内容提取（工具箱）：从记录中批量提取链接 / 邮箱 / 电话等结构化信息。
  • 配置对比（工具箱）：两份配置语义级差异高亮（不是粗暴按行 diff），对 JSON/YAML 排序差异也能识别。
  • 文本对比：选中恰好 2 条文本 → 「对比差异」，按行 / 按词，可忽略空白，上一处 / 下一处跳转。

注意什么：「文本对比」要求恰好选中 2 条文本记录，多选一条或少选一条，入口不会出现。

选区与窗口吸附
