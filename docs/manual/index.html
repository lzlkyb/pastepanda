快速开始

PastePanda 是一个常驻系统的剪贴板增强工具：自动记录你复制过的所有内容，并叠加截图标注、OCR、开发者转换、跨设备同步等能力。复制即记录，粘贴即执行。

第一步 · 启动与常驻

  • 安装后启动 PastePanda，它会最小化到系统托盘（任务栏右下角）。不会占用任务栏空间，随系统开机自启（可在设置关闭）。
  • 点击托盘图标可打开主窗口；主窗口关闭后程序继续在后台记录剪贴板。
  • 首次使用建议先在设置里确认 全局热键（见下方快捷键一览），之后全程用键盘操作，几乎不用碰鼠标。
💡
隐私优先：所有内容默认只存在你这台电脑上。OCR 用本地 PP-OCRv6 引擎离线识别，AI 功能默认关闭——开启前不会把任何内容发往外部。

第二步 · 复制点什么

像平常一样复制文本、链接、图片、文件、代码…… PastePanda 会在后台自动归档。打开主窗口，你刚复制的内容就在最上方。

第三步 · 粘贴它

  1. 主窗口里 单击 任意一条记录即可复制回剪贴板，再 Ctrl+V 粘贴。
  2. 或直接 双击 条目，多数类型会直接粘贴到上一次聚焦的应用（复制即执行）。
  3. 需要挑着粘贴多条？用 Alt+V 唤起快捷粘贴面板（类 Win+V），方向键浏览、回车粘贴。

卡片能装什么

每种内容有独立图标与配色，一眼区分：

  • 文本 / 链接 / 邮箱 / 电话：纯文本及其子类型，链接可一键打开、邮箱电话可直拨。
  • 代码 / JSON / 配置 / 日志：紫底图标，悬停预览带语法高亮（深色代码块）。
  • 图片 / 图文混排：显示缩略图；截图图片自动 OCR，徽标显示「已识别 N 行」。图文混排（Word/网页复制）完整保留图片与文字顺序。
  • 文件 / 文件路径：绿色图标，可「用默认应用打开」或「打开所在文件夹」。
  • 颜色值：复制 #0284C7 这类色值，卡片直接显示色块与格式。
  • 流程图：粘贴 Mermaid 等Diagram，卡片显示节点/连线数，可展开编辑。

常用操作

  • 单击复制回剪贴板，双击直接粘贴到上一个应用。
  • 置顶（收藏）：悬停出现的 ☆ 或右键「置顶」，常用内容永远钉在顶部，重启不丢。
  • 搜索：顶栏输入框实时过滤，支持关键词高亮与拼音首字母（如搜 th 可命中「腾讯」）。搜索历史也会记忆。
  • 右键菜单：编辑、复制、粘贴、变换为…（内置 19 项文本变换 + SQL IN 子句等）、打开 URL、打开文件、生成二维码、正则预览、移动到分组、添加到片段库。
  • 侧边栏分组：按「智能分类 / 来源应用 / 标签」筛选。可自建分组、自定义颜色与图标。
  • 深度清理：按时间 / 类型 / 来源组合条件批量删除，可先预览再删，自动跳过置顶项，支持 CtrlZ 撤销。

高效粘贴

不只是「存下来」，更要「贴得顺」。PastePanda 把粘贴过程本身做成了可编排的工作流。

纯文本 / 原格式

全局设置里可指定默认粘贴格式：纯文本（去掉网页/Word 带来的样式）或原格式（保留富文本）。也可以在粘贴前按需切换，敏感内容会先脱敏确认再粘贴（粘贴守卫）。

快捷粘贴面板（Alt+V）

类 Win+V 的浮层：列出最近记录，方向键浏览、回车粘贴、Esc 关闭。适合「从一堆里挑一条贴」的场景，不用先开主窗口。

粘贴栈（Ctrl+Shift+K）

  1. 按 CtrlShiftK 开启栈模式，顶部出现收集横幅。
  2. 逐条 CtrlC 把要拼接的内容收进栈（可跨应用、跨多次复制）。
  3. 按 CtrlShiftP 逐条粘贴，或「全部粘贴」一次输出，横幅显示进度，可随时中止。

变换与正则

  • 变换枢纽：右键「变换为…」打开卡片流，按内容智能给出可用变换（大小写、JSON 格式化、URL 编码、Markdown↔HTML 等）。
  • 正则预览：对文本套用正则规则提取/替换，可管理自己的规则库，悬停即看结果。
  • 引号包裹 / 变量替换：批量给多行加引号、做占位符替换，适合拼 SQL、CSV。

截图标注全家桶

按 CtrlQ 进入截图。对标微信 / QQ / Snipaste：自动框选窗口、全套标注工具、本地 OCR、贴图置顶、长截图，全部离线可用。

选区与窗口吸附

  • 进入截图后，自动框选光标所在窗口（可在设置关闭）。移动鼠标即切换目标窗口。
  • hover 即选区：停在窗口上高亮蓝框，单击进入标注，双击 / 完成直接输出。
  • 拖选自定义区域；选中后可平移、八向缩放，边缘磁吸（8px）对齐窗口边界。
  • 支持 UI 控件级吸附（用完整 IUIAutomation），能精准框住按钮、输入框等子控件。

标注工具（全套）

矩形 / 椭圆 / 箭头（单双箭头）/ 画笔 / 高亮 / 马赛克 / 模糊 / 文字 / 序号 / 橡皮擦 / 吸管取色。元素可点击选中、移动、缩放、删除；Shift 多选批量操作。马赛克 / 模糊滚轮回强度，橡皮擦真正擦除像素。

OCR 文字识别

  • 本地离线 PP-OCRv6：框选后点「取文字」，识别结果进右上抽屉，点任意一行即复制该行。
  • 表格识别：自动几何聚类还原表格结构，可导出 CSV。
  • 二维码识别：截到二维码自动解析，一键复制内容或打开。
  • 识别文字可全文编辑改错字，并存入剪贴板历史做语义检索。

贴图置顶 & 长截图

  • 贴图：截图后选「贴图」，图片以半透明悬浮窗钉在桌面最上层，可多张并存、T 循环透明度、双击重编辑、右键管理。
  • 长截图：工具栏「长截图」后滚动页面，自动拼接，预览即默认，Esc 取消可靠。
🪟
交互模型对标微信：自动框选 → hover 即选区 → 单击进标注 → 标注 → 双击/完成直接复制关闭。低频出口（二维码、表格）收进「⋯」面板，主工具栏只放高频工具。

编辑与预览

双击任意文本/图文/流程图条目即可打开编辑器，所见即所得。

  • Markdown 预览：支持标题、列表、表格、代码块，实时渲染。
  • 代码高亮：多种语言语法着色，深色代码块。
  • 图文编辑：加粗 / 斜体 / 删除线 / 列表，可删图、可 CtrlV 粘贴或插入新图。
  • 全屏编辑：内容多时切独立窗口，CtrlS 保存、Esc 关闭，有未保存会先提醒。
  • 流程图：粘贴 Mermaid 等，可视化编辑节点与连线。

系统同步

在多台设备间保持一致。支持 WebDAV 等私有云同步，数据掌握在自己手里。

  • WebDAV 同步：填入你的 WebDAV 地址与账号，自动上传/拉取剪贴板库。
  • 冲突处理：同文件冲突时按时间戳合并，关键记录（置顶/标签）优先保留。
  • 本地优先：无网络时全部本地工作，恢复连接后自动续传。
🔒
同步加密：开启同步的内容在本机加密后再上传，服务端看不到明文。密钥不离开你的设备。

重点设置项

  • 主题：海洋（浅）/ 午夜（深）/ 森林（护眼绿）/ 美乐蒂（甜系粉）/ 晨曦 / 海洋深色，共 6 套，可跟随系统。
  • 热键：截图、快捷粘贴、粘贴栈、主粘贴格式均可重绑。
  • AI：默认关闭。开启后可选内置模型或接入 Ollama 本地模型；只有本地模型才真正「内容不出本机」。
  • 数据：查看占用、导出/导入备份、深度清理、按价值自动清理旧记录。
