快速开始

PastePanda 是一个常驻系统的剪贴板增强工具：自动记录你复制过的所有内容，并叠加截图标注、OCR、开发者转换、AI、跨设备同步等能力。复制即记录，粘贴即执行。

第一步 · 启动与常驻

  • 安装后启动 PastePanda，它最小化到系统托盘（任务栏右下角），不占任务栏空间，可随系统开机自启（设置里可关）。
  • 点击托盘图标或按 Ctrl+Alt+V 打开主窗口；主窗口关闭后程序继续在后台记录剪贴板。
  • 首次使用建议先确认「设置」里的全局热键（见快捷键一览），之后全程用键盘操作，几乎不用碰鼠标。
💡
隐私优先：所有内容默认只存在你这台电脑上。OCR 用本地 PP-OCRv6 引擎离线识别，AI 默认关闭——开启前不会把任何内容发往外部；只有你主动对某条内容执行 AI 动作时，那一条才会被发送到所选服务商，且密钥/凭证类内容会先拦下来请你确认。

第二步 · 复制点什么

像平常一样复制文本、链接、图片、文件、代码……PastePanda 会在后台自动归档。打开主窗口，刚复制的内容就在最上方。

第三步 · 粘贴它

  1. 主窗口里 单击 任意一条即可复制回剪贴板，再 Ctrl+V 粘贴。
  2. 或 双击 条目，多数类型会直接粘贴到上一次聚焦的应用（复制即执行）。
  3. 挑着粘贴多条？用 Alt+V 唤起快捷粘贴面板，方向键浏览、回车粘贴。

剪贴板管理

主窗口的卡片流就是你的剪贴板历史。每种内容有独立图标与配色，支持搜索（含拼音首字母）、置顶、分组、标签、批量操作与深度清理。

卡片能装什么

  • 文本 / 链接 / 邮箱 / 电话 / 颜色 / 数字：纯文本及其子类型，链接可一键打开、邮箱电话可直拨、色值显示色块（HEX/RGB/HSL 互转）。
  • 代码 / JSON / 配置 / 日志 / SQL：紫底图标，悬停预览带语法高亮。
  • 图片 / 图文混排：显示缩略图；截图图片自动 OCR，徽标显示「已识别 N 行」。图文混排（Word/网页复制）完整保留图片与文字顺序，可编辑。
  • 文件 / 文件路径：绿色图标，可「用默认应用打开」或「在资源管理器中显示」。
  • 密钥 / 密码：自动脱敏遮罩，双击在编辑器内查看。
  • 流程图：粘贴 Mermaid 等 Diagram，卡片显示节点/连线数，可展开可视化编辑。

常用操作

  • 单击复制回剪贴板，双击直接粘贴到上一个应用（复制即执行）。
  • 置顶（收藏）：悬停浮层 ☆ 或 Ctrl+D，常用内容永远钉在顶部，重启不丢。
  • 搜索：顶栏输入框实时过滤，支持关键词高亮与拼音首字母（搜 th 可命中「腾讯」），搜索历史会记忆。
  • 多选与批量工具栏：Ctrl+点击 多选、Shift+点击 范围选，底部出现工具栏：全选 / 合并（合并粘贴）/ 导出（导出选中记录）/ 对比（对比差异，需恰好选中 2 条文本）/ 删除（Ctrl+Z 可撤销）。
  • 深度清理：按时间 / 类型 / 来源组合条件批量删除，先预览再删，自动跳过置顶项，支持 Ctrl+Z 撤销。

高效粘贴

不只是「存下来」，更要「贴得顺」：快捷粘贴面板、粘贴栈、依次粘贴、粘贴守卫与默认格式，把粘贴过程做成可编排的工作流。

快捷粘贴面板（Alt+V）

类 Win+V 的浮层：列出最近记录，方向键浏览、回车粘贴、Esc 关闭。适合「从一堆里挑一条贴」的场景，不用先开主窗口。

粘贴栈（Ctrl+Alt+K）

  1. 按 Ctrl+Alt+K（或点顶栏 📚）开启栈模式，顶部出现收集横幅。
  2. 逐条 Ctrl+C 把要拼接的内容收进栈（可跨应用、跨多次复制）。
  3. 按 Ctrl+Alt+P 逐条粘贴，或「全部粘贴」一次输出；横幅显示进度，可随时中止。

依次粘贴（Ctrl+Alt+Q）

把多条文本按顺序逐条粘到目标（适合填表单、SQL 参数）。可先选好多条再触发；设置里可开「依次粘贴循环」与「表格自动拆行入栈」（拆行格式：原始行 / 字段: 值；表头：排除 / 包含）。

粘贴格式与粘贴守卫

  • 默认粘贴格式：设置里选「保留格式粘贴」开/关——关闭时默认以纯文本输出，避免网页/Word 样式。
  • 粘贴守卫：粘贴内容包含密钥/凭证特征时，先弹出确认（脱敏展示），确认后才真正输出，防止敏感内容误贴。
  • 粘贴脱敏变换：右键「变换为 → 粘贴脱敏」，把内容中的敏感字段打码后再粘贴。
  • 主粘贴热键 Ctrl+Shift+V 已不存在：旧文档写法有误，真实对应为「唤出窗口 Ctrl+Alt+V」，粘贴当前记录用 Enter。

能做什么

  • 内容动作：选中任意文本/代码/截图识别文字，一键总结 / 翻译 / 改写润色 / 解释 / 提炼要点 / 找 Bug 等（内置动作集）。
  • 自定义动作：在 AI 设置里编写自己的动作（名称 + 系统提示词），出现在右键「粘贴并变换」与 AI 快捷栏；可设本地 / 联网、可放进动作链。
  • AI 快捷栏：卡片上 ✨ 唤起，结果可复制 / 粘贴到前台 / 追问（仅 AI）/ 还原原文；敏感内容先确认再发送。
  • 截图 OCR 后 AI：OCR 抽屉底部「✨ AI」直接对识别文字执行动作。
  • 流程图 AI 生成：一句话生成 Mermaid 流程图。
  • 缓存命中：相同输入+动作命中缓存显示「缓存命中 · 未计费」。

隐私与计费

  • AI 开关默认关闭；开启后也只在你主动执行动作时才发送那一条内容。
  • 服务商：内置模型（云端，按量计费）/ Ollama 本地模型（内容不出本机）/ 自定义 API（OpenAI 兼容端点）。
  • 密钥/凭证类内容先拦下来请确认；「用量」区可看今日调用次数与花费（本地模型不计费）；「高级」可调温度、超时、token 预算，回答被截断会明确提示。
  • AI 红线：所有 AI/云端能力受开关门控（前后端双重校验），未启用 = 零可见零请求零费用。

系统同步

在多台设备间保持一致。支持局域网同步与 WebDAV 私有云同步，数据掌握在自己手里。

  • 局域网同步：设置 → 通用 → 局域网同步（LanSyncPanel），同网段设备自动发现、点对点同步。
  • WebDAV 同步：填入你的 WebDAV 地址与账号，自动上传 / 拉取剪贴板库。
  • 冲突处理：同文件冲突时按时间戳合并，关键记录（置顶 / 标签）优先保留。
  • 本地优先：无网络时全部本地工作，恢复连接后自动续传。
🔒
同步加密：开启同步的内容在本机加密后再上传，服务端看不到明文，密钥不离开你的设备。

  • KPI：近 30 天使用 / 复制结果 / 粘贴结果 / 优化信号；推荐偏好（TOP 标记）与 已停用推荐（可恢复）。

  • 发现高频操作：A → B → C 序列自动发现，一键「存成链」变成可复用的动作链。

动作链

把多步粘贴流程串成一个按钮：上一步的输出自动喂给下一步，失败会明确到第几步并保留中间结果。入口：设置 → AI → 自进化 → 存成链，或工具箱「新建流程图」旁的链入口。

能力

  • 编辑器：名称（≤24 字）+ 描述；步骤最多 8 步，每步选一个变换 / AI 动作，可加条件（无条件 / 是 JSON 时 / 含敏感时 / 是代码时），条件不满足自动跳过。
  • 风险提示：每步标注 本地 / 联网；含 AI 步骤时运行前逐条确认「步骤 N 会把内容发送到云端（可能计费），继续？」。
  • 失败处理：失败显示「步骤 N/M 失败：…已保留失败前的中间结果，可复制」；执行类动作（有副作用）不能放进链。
  • 自动执行：设置里可配置「完成后自动执行动作链」（不自动执行 / 选择某条链），粘贴后自动跑。

周报 / 里程碑 / 成就

你的使用数据会沉淀成有趣的回顾（全部仅统计行为，不含内容）。

  • 剪贴板周报（设置 → 通用 → 打开周报）：周概览 5 格（复制 / 已粘贴 / 转化率 / ≈N 分 AI 省时 / N 周连续活跃）+ 内容类型 + 活跃时段 + 常用动作 + 本周挑战；数据不足 50 条会提示「继续用几天，攒到 50 条周报才有意义」；可选 AI 生成周报文字。
  • 里程碑：达到使用节点（如第 1000 条复制）自动弹出回忆卡（图标 + 引语 + 统计），可「查看我的画像」。
  • 成就墙：我的画像内嵌，N / N 已解锁网格，进度条「X 个成就 · 已解锁 Y 个」。
