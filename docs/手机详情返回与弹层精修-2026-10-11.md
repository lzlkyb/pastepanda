## 当前基线与需要精修的机制

- MobileScene 与 mobileSceneMotion：主入口淡入 150ms；任务进退短位移 200ms。支持中断、减少动态效果和后台停止。
- useMobileBack：原生 start/progress/cancel/commit 事件驱动；预览不执行返回业务，确认才遍历历史。已有优先级与迟到返回保护。
- KnowledgeView.module.css 已尝试在预览中展示来源列表/工作区；Reader 与 Article 有独立前景层。当前位移上限 min(96px, width×0.18)。需检查来源层可见性、虚拟列表测量、取消和最终业务返回之间的衔接，不能宣称从未显示来源。
- useSheetDrag：页头/把手拖动；正文独立滚动；位移与速度判断关闭。当前速度使用最后一个 move 的差分；缺少主轴方向锁定，斜滑可能产生不符合意图的位移。该风险先写复现测试，不能仅凭源码称已真机复现。
- mobileSpring：复用项目 k=130、c=16、m=1；精修不引入第二套参数。

## 详情返回

1. Android 系统边缘继续归系统处理，仅桥接原生进度。浏览器稿的 24px 起点和距离阈值只是演示，不能复制为正式 Android 返回监听。
2. 预览时真实来源保持原筛选、滚动和选中项；不请求数据、不保存、不丢弃草稿、不关闭会话。来源层不可交互/不进入可访问性树。
3. 位移与轻微缩放显示当前页面与来源关系；无整页飞走。先验证阅读、文章预览，再覆盖编辑返回与宽屏双栏，禁止上下文不同却预览同一列表。
4. 取消从当前状态回位；原生 commit 才结束任务。视觉收尾不得增加重复 history.back，也不能在等待动画期间吞掉新的有效操作。保存失败要保留编辑页。
5. 列表位置在 DOM/业务层保留；虚拟列表预览不能因 ResizeObserver 重新测量隐藏区域而跳回顶部。若来源尚未准备好，使用可信的来源骨架/身份，不生成假的正文或伪截图。
6. 减少动态效果时去除大位移/缩放，保留明确返回入口。旧 Android/硬件返回走一致业务结果与普通转场。

## 弹层跟手与回弹

1. 竖屏向下、横屏向右；页头和把手是拖动区域，正文不新增全局接管。8px 与主轴/交叉轴 1.25 倍是稿件初值，正式实现优先复用系统/已有触摸阈值并经设备校准。
2. 方向确认前不移动；交叉方向明确时放弃拖动。一次触摸由一个所有者处理，第二指和系统取消不能触发关闭。
3. 松手速度使用短时间窗口采样，防止单帧抖动决定关闭；停留后松手清除陈旧速度，短拖回弹，快速甩动才收起。
4. 遮罩透明度随实际面板位移变化，使用受限线性映射，透明度不使用弹簧。面板回弹沿用项目弹簧。
5. 反向拖回、收起时重开从当前位移接续；完全退出后才释放模态/焦点，不能留下透明拦截。提交中关闭/拖动禁用，危险操作不能通过甩动执行。
6. 横竖屏切换、键盘、后台、系统返回中断落到可信状态；正文、固定动作与回执仍可达。

## 架构与验收

共享层修改集中于 mobileSceneMotion/useMobileBack/useSheetDrag/MobileSheet；来源能力由任务页提供，不克隆整棵 React 树、不迁移业务状态、不按页复制监听。组件超过 300 行先拆分。

先为轴向冲突、停留速度、重复返回、取消恢复与模态释放写改前失败用例，再修改机制并保存红绿输出。复用现有快速点击、旧动画完成、迟到历史事件守卫。

- 自动：斜滑不关、短拖回位、快甩关闭、第二指不接管、cancel 不业务返回、commit 恰好一次、busy 不关闭；隐藏页面无遗留 rAF。
- 布局：320px、390px、568×320 与宽屏双栏；大字号、键盘、减少动效；所有按钮与反馈可达。
- 真机：真实系统边缘、触控采样与帧时间、连续操作、旋转/后台各验证；记录设备/刷新率与慢帧。自动用例或 HTML 预览通过不等于原生手感达标。

官方参考：[Android 预测性返回](https://developer.android.com/design/ui/mobile/guides/patterns/predictive-back)、[Android 底部弹层](https://developer.android.com/develop/ui/compose/components/bottom-sheets)。采用其“预览、确认、取消”和弹层生命周期原则；本稿位移、缩放与阈值是 PastePanda 提案，不声称为官方规定。

## B 确认后的实施

- `useMobileNavigation` 继续管理目的地和历史；新 `useMobilePager` 只管理原生横向滚动与落定。CSS Scroll Snap 驱动视觉，落定后才激活业务页。没有四份页面克隆或手写逐帧分页动画。
- 四个目的地实例保持挂载、独立纵向滚动；非当前页保持 inert/aria-hidden 并暂停 CSS 动画。分页运动期间正文动作暂不可触发；滑动产生的点击被抑制，下一次触摸/鼠标/笔输入与键盘操作仍可达。
- 系统边缘至少保留 24 CSS px；输入、编辑区、slider、显式手势所有者和真实横滚容器不接管分页。局部横滚或取消后的归属保留到下次触摸/明确导航，迟到惯性事件也不能切 Tab。详情、远控、触摸沙盒、弹层和原生返回预览禁用或中断分页；多指、cancel、旋转、失焦和后台回到可信当前页。24px 是项目阈值，不宣称为 Android 官方边缘宽度，仍需真机校准。
- 相邻按钮切页可平滑滚动，跨多页按钮与减少动态效果直接定位；连续点击以最新目标为准。支持 scrollend，旧 WebView 使用有限 160ms 静止检查，无常驻轮询；宽度变化重定位，单纯键盘/通知高度变化不截断手势。
- 详情预览加入轻微缩放与圆角；取消回位的 200ms 内保留来源及 inert，确认返回等待异步 pop 期间保持预览。继续沿用重复提交、迟到 pop、新弹层入栈与旧动画清理保护。
- 修正修改/文章任务的来源：在已有全文上进入修改时，预览露出原全文；阅读返回列表才露出列表。通过 task root 的单一来源标记收口 CSS，避免为所有任务一律显示列表。
- 弹层新增模糊方向等待：8px 以上主/交叉轴任一达到 1.25 倍再归属，未明确方向的斜滑松手不甩动关闭。遮罩按缓存的实际面板范围与位移映射透明度，删除额外透明度 transition，避免跟手滞后；退出仍随面板持续到完整离屏后卸载。
