# 手机端延时与连接详情方案

状态：用户已确认 B，已实施；验证结果见 `docs/手机端-延时与连接详情实施记录-2026-10-02.md`。

设计稿：`design/手机端-延时与连接详情方案-2026-10-02.html`。支持 A/B/C、竖屏/横屏、正常/延时偏高/等待样本/恢复中。全部参数与趋势为静态示例。

## 方案对比

| 方案 | 入口与呈现 | 优点 | 代价 |
| --- | --- | --- | --- |
| A | 更多 → 连接详情，无常驻读数 | 最简洁，完全不占远程画面 | 看延时需要两步，无法及时感知质量变化 |
| B（推荐） | 顶部轻量延时按钮 → 连接详情；更多保留同名入口；横屏保留延时按钮 | 日常只显示一个读数，详情一步可达，与电脑端小读数 + 详情的模式一致 | 手机顶部增加一个小按钮 |
| C | 延时、帧率、编码、码率常驻参数条 → 连接详情 | 适合长时间排查连接问题 | 信息较密，持续占用远程画面 |

## B 的信息层级

1. 常驻：`延时 36 ms`。测量中显示“测量中”；连接恢复期间显示“恢复中”，不拿上次延时假装当前实测。
2. 详情：往返延时 + 实际帧率；近 60 秒趋势；连接方式、分辨率、编码、估计码率、画质设置。
3. 高级参数默认收起：画面延时近似值、采集/编码/传输/解码分段、操作响应近似值、丢包率。数据缺失显示“暂无样本”；不展示虚假的 0 ms / 0% 丢包。
4. 画面与画质：跳转现有画面面板，关闭详情后继续查看视频。降低画质只可能减轻画面负担，不承诺降低心跳往返延时。

延时分档复用 `src/lib/rcSessionStats.ts`：<30 很流畅，<60 流畅，<200 一般，>=200 偏慢。不能把“延时偏慢”当成“连接断开”；帧数下降/画面静止也不能据此判定链路故障。帧率是接收端的观测值，不是画质目标帧率。

## 源码依据与可用数据

已读取 `RcHud.tsx`、`RcQualityChip.tsx`、`RcSessionView.tsx`、`RcMobileSession.tsx`、`SessionToolbar.tsx` 与相关 CSS。预览复用当前会话 CSS、语义色和真实 `MobileSheet`，保持四个主操作与既有弹层动效。

| 信息 | 现有来源 | 手机落地需要 |
| --- | --- | --- |
| 往返延时、连接方式、丢包率、心跳新鲜度 | `rc.status.rtt_ms / path_kind / loss_permille / pong_age_ms` | App 已持有状态；传给手机会话，复用统一判据，不新增心跳或一套轮询 |
| 帧率、分辨率、编码、估计码率 | 已在手机调用的 `useRcFrames` 返回值 | 新详情组件读取，数字统一节流呈现，不逐帧更新整张弹层 |
| 画面延时、分段 | `useRcFrames` 与 `rc.status.clock_skew_ms` | 手机当前未传入时钟校准；先接入并核验，再显示近似值。传输段是计算估计值 |
| 操作响应 | `useRcFrames` 的 `lastInputAt` 选项与返回值 `respMs` | 手机当前未传入输入时间；需在统一发送成功路径接入，先检查全部同类发送点，未接入时显示暂无样本 |
| 自动画质 | 当前请求档位与后端状态 | 手机作为控制端时，不声称知道电脑实际自动档位；按会话方向正确显示 |
| 近 60 秒趋势 | 已有 RTT 数据及桌面趋势模式 | 按会话隔离样本，限时限量，切换/结束清空；页面隐藏暂停呈现，不使用常驻动画循环 |

当前丢包字段的 0 定义为“尚未采样”，不能当成已测得 0%。不增加 IP、带宽测速、安全状态等没有可靠数据源的项目。

## 交互与性能验收点

- 延时按钮点击区域至少 44px 高；主工具不新增第五个常驻按钮；横屏收起工具后仍能查看延时和详情。
- 面板打开暂停远程手势与按键，视频仍继续；进入面板时释放拖拽、组合键等状态，防止输入卡住。
- 关闭、下拉、返回键只收起面板，不结束会话；高级参数滚动与下拉关闭不冲突。
- 弱网提示就地显示，不反复弹 toast；连接恢复后重新使用新样本；数据不滚动跳字，不做脉冲装饰。
- 复用现有弹层运动与减少动态效果设置；玻璃只在既有栏/弹层，不给每个指标添加模糊。
- 正式实施按组件/Hook 拆分，避免向已接近长度上限的 `RcMobileSession.tsx` 堆积逻辑。
- 实施后验证缺失数据、连接异常、会话切换、横屏、弹层输入保护、静止画面不误报，以及数值与电脑端口径一致。

本次预览不访问真实设备、不发送远程输入、不修改画质或系统设置。真实手机观测和性能验收在用户确认实施后进行。
