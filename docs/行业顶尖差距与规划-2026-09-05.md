# PastePanda 行业顶尖差距与规划（2026-09-05）

> 用途：回答「结合软件自身，做到行业顶尖还差什么」——按四根柱逐一对标，给出依赖序主线与拍板清单。
> 性质：**规划文档，不含代码**。所有差距均标注出处；本文不新增任何未经核实的事实。
> 数据来源：《PastePanda-AI架构与路线图》§2/§3、《知识库-总排期》、《个人知识库与笔记-规划》§12、《知识库同步-M6设计稿》§4/§10/§11、`kb-market-fit.md`、项目工作记忆（截图/结构治理条目）。

## 0. 一句话结论

**规划文档覆盖度已经很高，真正缺的不是「新功能规划」，而是三件结构性的东西**：
① 学习体系没有数据（AI 柱全链空转）；② 两处架构代差（截图硬限制 / 知识库块级模型——后者已裁决不追）；
③ 「每日整理工作碎片」这张独一无二的王牌，规划成熟但**零开工**。

补齐路径不是全面对标，而是把
**采集（剪贴板+截图+OCR）→ 沉淀（知识库+每日整理）→ 激活（检索+问答+Agent）**
这条竞品矩阵里不存在的完整链路，做到每一环都好用。

## 1. 「顶尖」的定义与战场选择

| 赛道 | 对标 | 我们的姿态 |
|---|---|---|
| 剪贴板管理 | Ditto / CopyQ / Paste (Mac) | 正面战场，AI 变换与 OCR 是超出对标的能力 |
| 截图标注 | Snipaste / PixPin / CleanShot X | 正面战场，OCR 管线已是差异化 |
| 个人知识库 | Obsidian / Notion | **错位战场**：不做生态/协作/移动端，打「本地优先 + 无服务器同步 + 采集原生」 |
| AI 执行 | NotebookLM / Notion AI / Mem | 错位战场：`ai_enabled` 门控 + 本地推理优先，隐私即卖点 |

**明确不追的（已裁决，防跑偏）**：插件市场（用 MCP 代替）、知识图谱（真实数据否决：1165 张卡片仅 1 个标签）、iOS/移动端（M6 §12）、块级模型、模型写代码执行（红线③）、DeepSeek Harness 打包进 app。

## 2.7 收益分档：用户能不能感觉到（2026-09-05）

> 本节不新增条目，只给 §2.1–§2.5 已有的条目**换一把尺子重量一遍**。
> 起因：上面几张表的「严重度」列混了两种不同的东西——「竞品有而我们没」与
> 「用户缺了会难受」，混在一起就永远排不出序。

### 尺子：收益分三种，不能混谈

1. **用户直接感觉得到**——缺了会难受
2. **防止变坏**——有了没感觉，没有会出事
3. **依赖别的东西先成立**——前提不成立时现在做是空转

### 第一档：用户直接感觉得到，且现在就缺

| # | 用户视角的一句话 | 判断 |
|---|---|---|
| **N1** 笔记插图 | 「**我往笔记里贴不了图。**」编辑器无插图入口、预览不解析相对路径、真库 0 张图 | 🔴 **最实在的一条**。一个剪贴板工具，6.1% 内容是图片，转成笔记后图放不进去——不是缺功能，是**容器漏了** |
| **G2** 图片 OCR 接搜索 | 「**我截的图搜不到。**」图片完全不进 FTS5 | 🔴 与 N1 是一对：图进得去但找不回，等于沉底。**建议与 N1 同批做** |
| **G6b** 长截图截旧内容 | 「**我按了长截图，得到的是错的图。**」 | 🔴 这是**坏了**，不是缺。PixPin 在这块是标杆，直接对位 |
| **N8** 搜索可解释性 | 「搜出来这条，我不知道它为什么排第一。」 | 🟢 **性价比最高**——打分数据全有，只是没透出 |
| **G12** 反链面板 | 「哪些笔记引用了这篇？」AI 侧已能查，界面没做 | 🟡 收益真实但不紧急 |
| **N4** 检索语法 | `tag:` / `folder:`，键盘党的确定性入口 | 🟡 成本低，可随 N8 同批 |

### 第二档：用户零感知，但没有会出事

| # | 为什么还是要做 |
|---|---|
| **G18 ①** MCP 关写开关未实连验证 | 🔴 **见下方单独说明。注意它未被 D-6 覆盖** |
| **G11** M6 同步实连验收 | 同步代码全落地但**两台机器从没真跑过**。同步出错 = 用户笔记丢或被覆盖。这不是功能收益，是**「敢不敢发」的门槛**，应单独提前 |
| **G8** `ScreenshotOverlay.tsx` 4163 行 | 用户完全无感。收益是**未来的开发速度**——「下一个大功能开工前必须治理，否则继续叠会先塌」 |
| **N5** 规模化性能预算 | 现在库小感觉不到。实测均 9043 字/篇，库大了搜索会慢。是「不变卡」的保证 |

#### 🔴 G18 ① 单独说明：D-6 只关掉了一半

`D-6` 拍的是「令牌泄露 + key 轮换」不处理。但 **G18 里还有另一条它没覆盖到**：

> M5 运行时**关写开关拦截从未实连验证**（规划 §12.4）

用户视角：**「我在设置里关掉了 MCP 写权限，但没人验证过它真的生效。」**
它若没生效，外部 AI 工具就能直接改用户的笔记库，而用户以为已经关上了。

这比 D-6 那两条（本机令牌 + 自己的 key）**严重得多**，因为它是**给用户的一个安全承诺**；
而验证成本很低，就是一次冒烟。**不要跟着 D-6 一起关掉。**

### 第三档：依赖别的东西，现在做是空转

| # | 卡在哪 |
|---|---|
| **G9** 向量层 | 收益大——「搜不到词但意思对」的笔记能找出来。但卡三前置：O-4 ✅ / **AM-5 数据 ❌** / 真跑探针 ❌ |
| **G10** AM-5 真标注 | 用户零感知，它是**评测集**。没它，向量层做完**不知道搜索有没有变好**。题目得人出 |
| **G13** AM-3 / AM-9 | 明确卡在 AM-5 之后 |
| **G17** AI 记忆库十项 | 「排好未开工」 |
| **N7** 晨报 | 依赖 B2 #7，而 B2 #7 在等数据——**和 G1 是同一个空数据问题** |
| **G15** 动态编排 | 见 §5 D-3：当前全是纯函数无副作用，收益薄 |

### 第四档：用这把尺子量下来站不住的

🔴 **这五条的共同问题：它们的论证方式是「竞品有 / 结构不完整」，不是「用户缺了会难受」。**

| # | 问题 |
|---|---|
| **G5** Tier3 吸附 | 理由写的是「**Snipaste 招牌体验**」——对标驱动。用户真需要双层轮廓预览 + 键盘遍历吗？无证据 |
| **G6a** 混合 DPI 错位 | 已知硬限制。触发条件是**多显示器 + 混合 DPI**，覆盖多少人不知道 |
| **N2** Obsidian 迁移向导 | 理由是「竞品用户池=获客池」——**这是获客理由，不是现有用户收益**。且无任何真实迁移诉求 |
| **N6** 单篇导出/分享 | 个人工具，分享频率存疑 |
| **G4** 变换系统结构洞 | 用户无感。它的价值是「让学习系统看到这部分能力」——**而学习系统数据是空的（G1）。前提不成立** |

**处置：建议砍掉，待拍板（见 §5 D-9）。** 未拍板前不得当已砍，也不得当正常排期项。

### 由本节得出的排序建议

  那么 G15/G16/G17 这一串重投入的**前提已经变了**
