# 手机知识库：图片补齐与跨端验证

2026-10-08。用户确认 A：缺图时手动补齐单张，旧电脑继续使用完整同步。

## 已实现的契约

- 继续共用全进程 iroh endpoint，新增 `pastepanda-kb-asset/1`；原 `pastepanda-sync/1` 帧和游标不变。
- 同步启停注册/摘除单图 handler；禁止另绑同身份 endpoint。知识库同步关闭、设备暂停、忘记设备均能中断在途补图。
- 手机仅在用户点击缺图操作后请求。阅读、图片加载失败、页面可见等行为不会自动联网补图。
- `mobile_knowledge_asset_fetch` 参数是 `requestId`（每次重试使用新的 UUID）、`peerId`、`noteId`、`src`。
- 返回 `{src, bytes, peer, already_local}`。结果只代表该图片已在手机校验落盘，不能推导笔记或整轮同步完成。
- `mobile_knowledge_asset_cancel` 以 `requestId` 停止本次请求。关闭面板/离开阅读需取消；提前取消保留有界短期记录，防止 invoke 到达顺序竞态。
- 失败以 `{code,message}` 拒绝，包含 `sync_disabled`、`unauthorized`、`paused`、`cancelled`、`busy`、`unsupported`、`offline`、`missing`、`invalid`、`too_large`、`integrity`、`io`。不将对端任意错误文本直接呈现给用户。

## 授权、完整性与资源边界

双方都使用知识库 `devices` 授权和同步开关，而不是远控配对。身份取自已认证连接；请求中的 noteId 必须是当前仍存在的笔记，且正文确实引用该图片。图片仅从应用 images 根目录读取，防止路径穿越和符号链接外逸。

单图最多 10MB，同时最多两次本机请求、两次入站服务。控制帧最多 64KB，正文分块 64KB；30 秒停滞、90 秒总限。两端校验内容 MD5 与图片格式/尺寸，单边不超过 8192 像素、总像素不超过 1600 万；不完整/校验失败的内容不会落为正式图片。落盘使用唯一临时名、fsync 和原子 rename，临时文件失败清理；本机损坏图片可以用校验通过的图片替换。

取消保留已经完成的正文和图片，不删除笔记、不制造墓碑。补图不改笔记时间戳、不推进设备游标、不伪造“电脑已收到”回执。

## 跨平台兼容修复

- Windows、Android/iOS POSIX 绝对路径、标准 file URL 均可转换为便携引用；兼容历史多一个斜杠的 file URL。
- 导入 POSIX 路径生成规范 `file:///data/...`，避免产生 `file:////data/...`。
- 新手机采集的 `pp-asset:<hash>.<ext>` 也参与完整同步的附件导出，不再只扫描 Windows 绝对路径。
- 便携名称统一小写，附件身份包括扩展名，避免 Windows 不区分大小写掩盖 Android 缺图。
- 比较笔记回声时规范化图片引用，避免同一图片的便携引用和本机路径产生无效冲突副本。
- HTTPS、HTTP、协议相对外链、content URI 以及无关路径不便携化，不抓取外部网络图片。

## 已执行的隔离测试

这些测试使用临时落盘 SQLite 库和禁用中继/地址发现的本地 iroh 回环连接；**没有访问、合并用户正式知识库**。

- `sync::attach_tests`：24 项通过，含 Android → 便携 → Windows → 便携 → Android 回环、远程链接守卫、附件字节导出、手机便携正文回声无冲突，以及 images 相对图片引用与代码/普通链接守卫。
- `sync::asset`：6 项通过，含真实两端首次图文同步、删除测试接收端单图后补齐、手机编辑反向同步收敛；单图传输不推进游标。
- 实际传输期间取消接收，连接关闭且无半张图；随后新请求成功。
- 旧端只提供原同步 ALPN 时，实际握手拒绝并返回 `unsupported`；不发送旧端无法解析的新同步帧，不挂起。
- 知识库开关/暂停/未授权、无引用笔记、伪造内容哈希、私有目录符号链接、损坏本机图修复均有守卫。
- 回归：`sync::` 全量 223 项、最终单图协议 6 项、共享 ALPN/路由 2 项、`mobile_knowledge` 全量 32 项均通过。对应日志在 `.cache/knowledge-sync-completion-tests.log`、`.cache/knowledge-asset-final-tests.log`、`.cache/knowledge-shared-route-tests.log`、`.cache/knowledge-all-backend-tests.log`。

## USB 手机双端验收仍需独立记录

本地真实协议测试不能替代 Android 系统、真实 Wi-Fi 和手机存储环境。建议使用明确标记的一篇测试笔记，完成：电脑图片→手机首次同步；手机图片采集→电脑回程；删除或制造测试副本缺图→单张补齐；补图中停止/暂停后恢复；未授权或已撤销设备不能读图；旧电脑不支持时显示更新/完整同步选择。

不得为验收直接清空手机图片目录或改正式全库，也不得仅凭“本机保存成功”宣布“电脑已接收”。实际手机截图与双端结果由总验收记录追加。
