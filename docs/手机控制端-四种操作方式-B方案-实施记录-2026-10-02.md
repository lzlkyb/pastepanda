# 手机控制端四种操作方式 · B 方案实施记录

## 确认范围

用户确认 B 方案及 HTML 设计稿后实施。首次使用继续默认触控板；新增的选择入口沿用原工具栏位置，不改变设备、连接、键盘或文件传输流程。

设计稿：`design/手机控制端-四种操作方式-B方案.html`。

## 操作方式

| 方式 | 输入区域 | 画面手势 |
| --- | --- | --- |
| 触控板（推荐默认） | 电脑画面；保留既有辅助按钮和手势 | 划动移动指针，点按指针处；双指平移滚动电脑，捏合调整本地视野 |
| 直接点击 | 电脑画面；保留鼠标辅助按钮 | 点击目标位置；长按松手右键、移动拖拽；双指与原方式一致 |
| 独立触控板 | 画面下方，横屏时在右侧 | 画面只调整本地视野，点击和长按不操作电脑 |
| 浮动鼠标 | 可拖动控制柄及附近的左键、右键、拖拽按钮；底部保留滚动按钮 | 画面只调整本地视野；控制柄相对移动指针，开启滚动后发送滚轮 |

开启辅助滚动时，操作区划动用于滚动电脑页面。浮动控制柄自身保持在可见区域，其边缘约束不限制电脑指针到达屏幕边缘。调整本地视野不会结束辅助按钮开启的拖拽。

## 偏好与反馈

- 选择后立即关闭面板，通过现有会话反馈层显示结果。
- 本机 WebView 的 `pastepanda-mobile-pointer-mode` 保存操作方式，下次会话恢复；非法值或读取失败恢复触控板。
- 存储失败仍完成当前会话切换，明确提示无法保存偏好。
- 选择面板提供“恢复推荐默认”；触控板和直接点击的辅助显示开关收进辅助选项。
- 模式切换、弹层、断流、失焦、后台、旋转或捕获中断释放输入。浮动柄正常抬指不会释放按钮显式开启的持续拖拽。
- 只看时隐藏输入辅助区和浮动柄，禁用模式与键盘入口。

## 实现边界

- `pointerModes.ts` 是四种方式名称及说明的单一来源。
- `useSessionPointer.ts` 复用内容坐标、输入发送和手势分类，集中处理模式映射与偏好。
- `FloatingMouse.tsx` / `useFloatingMouse.ts` 单独承担控制柄显示与指针捕获；边界纯函数放在 `src/lib/utils.ts`。
- 连续移动继续采用现有输入节流；控制柄位置通过 DOM 更新，不新增动画循环。
- 本次未修改版本号、Rust 输入协议或构建安装包。
