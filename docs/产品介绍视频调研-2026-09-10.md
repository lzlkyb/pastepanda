## 1. 三种主流范式（先选一种，不要混）

| 范式 | 代表 | 开场 | 时长 | 适合 PastePanda 的哪条 |
|---|---|---|---|---|
| **A. 痛点钩子型** | Raycast 功能短片、抖音/B站工具号 | 「你复制过的东西，10 分钟后就没了」 | 30–90s | 官网 hero 短片、B站切片 |
| **B. 产品工艺展示型** | Linear 官网首页、Figma 首页 | 一句产品定位 + 高保真 UI 动效 | 60–120s | **通用底版首选**（官网主片） |
| **C. 观念/品牌片型** | Obsidian「Your thoughts are yours」 | 价值观/隐私主张 | 60–180s | 信任资产、GitHub README 嵌片 |

**判断**：PastePanda 当前阶段更适合 **B 为主、A 的钩子做前 5 秒**。  
理由：已有一条 30s 抽象钩子片；缺的是「官网挂得住、B站能讲完」的中片。

## 2. Linear 官网首页拆解（B 范式模板）

结构可以整段借用：

1. **一句话定位**（不讲功能清单）  
   > “The product development system for teams and agents”
2. **三条支柱**（Purpose-built / Powered by agents / Designed for speed）  
   每条一句话，配一张会动的 UI，不要展开教程。
3. **分功能剧场**（Intake → Plan → AI → Build）  
   每段：小标题 + 2–3 行说明 + 一块「装在卡片里的产品 UI」动效。
4. **社会证明**（客户 logo / 引言）
5. **收尾 CTA**（Download / Get started）

**可迁移到 PastePanda 的骨架**：

```
0–5s   一句话定位：复制即沉淀 —— 剪贴板就是你的知识库入口
5–20s  三支柱：本地存储 · 复制即沉淀 · AI 默认关
20–55s 剧场一：剪贴板历史（搜索/筛选/转笔记）
55–80s 剧场二：知识库（全文检索 / 节级定位 / 带引用问答）
80–95s 剧场三：开发者工具箱快切
95–110s 信任条 + Windows · 开源 · 本地
110–120s CTA：下载入口
```

## 3. 视觉与制作手法（从优秀片里提炼）

### 3.1 画面

| 做法 | 说明 | 为什么 |
|---|---|---|
| **UI 装进卡片/窗口框，不裸全屏** | Linear/Figma 都用带圆角、阴影的「产品卡片」漂在品牌底上 | 比桌面截图更「产品片」，也避开真实桌面杂讯 |
| **高保真 mockup > 现场录屏杂讯** | 可用真截图，但裁干净、去掉任务栏/无关窗口 | 可信 + 干净 |
| **光标/高亮引导注意力** | 悬停放大、描边高亮、箭头 | 观众知道该看哪 |
| **不要 logo 片头** | logo ≤1s 或放在片尾 | 前 3 秒必须是动作/痛点 |
| **镜头运动** | Ken Burns 慢推、视差、卡片浮入 | 静止 >4s 掉完播 |

### 3.2 文案

| 做法 | 说明 |
|---|---|
| 一句定位，不是功能列表 | Linear 从不说「我们有 40 个功能」 |
| 动词优先 | 「右键一步变成笔记」>「支持笔记管理」 |
| 诚实边界 | Obsidian/Raycast 都把「本地、不上传」写在功能页第一段 |
| 硬字幕全程 | >60% 静音观看；技术名词勿用 ASR |

### 3.3 Raycast Clipboard History 页（与 PastePanda 直接对标）

值得抄的表达：

- 首屏就写清：**Copied content never leaves your computer** + 加密本地
- 默认忽略密码管理器内容（对应 PastePanda 的敏感内容防护）
- Pin 常用条目（对应收藏/片段库）
- 热键呼出（对应 `Ctrl+Alt+V`）
- 功能页放 **动图/短视频** 演示，而不是长截图墙

PastePanda 的差异点应在片中明确：

1. 不只是「历史」，是 **转笔记 → 知识库 → 带引用问答** 的完整链路  
2. **Windows 优先**（Raycast 主场是 Mac）  
3. **AI 默认关闭** 是卖点，不是遮掩  
4. **开源 + MCP** 接外部 AI  

### 3.4 声音

- 人声（真人或 TTS 1.1–1.2x）为主，BGM −20dB 以下  
- 工具类不要强节奏卡点  
- 键盘/点击轻音效可点，不要每秒都有

## 4. 产线与工具（HyperFrames 语境）

| 层 | 推荐 | 备注 |
|---|---|---|
| 分镜/板 | 文案时间轴表（本仓库 §5 已有） | 先锁脚本再做画面 |
| 素材 | 真机截图（窗口原尺寸，不最大化） | 敏感信息打码/换演示库 |
| 动效成片 | **HyperFrames**（HTML+GSAP→MP4） | 官方有 `/product-launch-video` 工作流 |
| 备选 | Remotion / AE / 剪映 | HyperFrames 对 agent 更友好 |
| 真录屏升级 | Cap / Screen Studio | 有 30–40s 关键操作录屏后替换静态镜头 |

## 5. 对 PastePanda 通用底版的落地建议

### 5.1 必须遵守

1. 前 5 秒：**一个熟悉动作 + 反差**，不是 logo、不是「大家好」  
2. 中段只讲 **一条完整动作链**：复制 → 历史 → 转笔记 → 检索/问答  
3. 信任条固定三句：**内容在本机 · AI 默认关 · Windows 开源**  
4. 界面镜头：**真截图 + 卡片框 + 遮罩敏感信息**；演示库优先  
5. 全程硬字幕；口播红线见 `docs/短视频推广方案` §8  

### 5.2 不要做的

- 一口气念 8 个功能  
- 用 AI 伪造产品界面  
- 把同步/端到端加密说过头  
- 在片中出现真实客户名、路径、密钥  

### 5.3 与已有 30s 竖屏片的关系

- 30s 抽象片：继续做抖音/小红书钩子  
- 通用底版（本调研 → HyperFrames）：官网 + B站中片  
- 后续用真录屏替换 2–3 个静态镜头，升级成混合版
