## 0. 三个先说清的判断

**① 工具类软件短视频，胜负手在前 3 秒，不在功能数量。**
观众不是来听你介绍产品的，是被"这个动作我天天做"钩住的。所以每条视频的开头必须是**一个观众熟悉的动作**（复制、粘贴、找上次那段报错），而不是 logo 动画、不是"大家好今天给大家介绍一款"。片头 logo 一律 ≤1 秒，或直接不要。

**② 演示界面必须真机录屏，不要用 AI 生成。**
AI 生成的界面会画错按钮、编造不存在的菜单，而本产品的核心卖点恰恰是"真的能跑通"。一条被眼尖观众发现是假的演示视频，杀伤力大于不投。AI 生成在本方案里只用于：2–3 秒片头动画、转场、封面底图、纯概念 B-roll（比如"信息流过剪贴板"的抽象镜头）。

**③ 先拍「已经跑通的」，同步那条先别当主推。**
代码层：iroh 1.1 已落地（`src-tauri/src/sync/transport.rs`，局域网直连 + 跨网打洞 / N0 relay 同一套栈）。
但 `docs/知识库同步-双机实测清单-2026-09-07.md` **至今没有执行结果**，其中三项的失败模式是**静默**的——单机测试结构上碰不到。
→ 同步这条要么先花半天跑完实测再拍，要么在视频里只说局域网场景。别赌。

## 1. 账号定位与人群

**一句话人设**：一个把剪贴板做成知识库的 Windows 工具作者，讲"为什么这么设计"而不只是"有什么功能"。

| 目标人群 | 他们刷到时的心理 | 对应卖点 | 主阵地 |
|---|---|---|---|
| 开发者（主力） | "这段报错我昨天刚解决过，找不到了" | 复制即沉淀、节级定位、MCP 接外部 AI、截图 OCR | B站 / V2EX |
| 效率控 / 双机党 | "家里一台公司一台，笔记搬来搬去" | 剪贴板历史、栈模式、同步 | B站 / 小红书 |
| AI 重度用户 | "AI 每次都失忆，我不想再贴一遍" | MCP 一键接入、带引用问答、AI 默认关闭 | B站 / 抖音 |

**平台优先级**：

| 平台 | 定位 | 说明 |
|---|---|---|
| **B站（主阵地）** | 3–8 分钟中视频 + 1 分钟短切片 | 开发者浓度最高、允许挂下载链接、搜索长尾能吃半年、容错高（技术向观众能接受"这是个个人项目"） |
| **抖音（分发）** | 15–45 秒强钩子切片 | 同一素材重剪，不单独拍摄；泛流量大但转化差，用来破圈 |
| **小红书** | 图文为主，视频做补充 | 已有图文文案包（3 篇），视频版只做"痛点向" |
| 视频号 / 知乎视频 | 暂不投入 | 工具类内容在这两个场域的自然流量不值得单开一条产线 |

## 3. 三条内容路线（选一条作为首月主线）

| | 路线 A · 痛点钩（推荐） | 路线 B · 能力炫技 | 路线 C · 观念输出 |
|---|---|---|---|
| 开场 | "你复制过的东西，10 分钟后就没了" | 一口气演示 8 个功能 | "个人知识库的门槛不在整理，在采集" |

## 4. 黄金结构模板（可直接套）

### 30 秒版（S1 主推）
```
0–3s    钩子    一个观众天天做却没意识的动作 + 一句反差提问
3–8s    痛点    把"没有它时有多麻烦"演出来（别讲，演）
8–22s   演示    一个完整动作链，一镜到底不切
22–27s  证据    一个具体事实（本地存储 / AI 默认关 / 不带广告法极限词）
27–30s  CTA     一句话 + 去哪下
```

### 60–90 秒版（S2）
```
0–3s    钩子    同上
3–10s   痛点    场景化，给一个具体人物时刻（"调试两小时终于解决了"）
10–55s  演示    2–3 个能力，中间用"但是真正关键的是"转场
55–75s  差异    和观众已有的做法对比（云笔记 / 网盘 / 手动）
75–90s  收尾    三条信任支柱挑一条 + CTA
```

### 3–8 分钟版（S3）
```
0–15s   结论前置   "先说结论：xxx"
15–60s  问题背景   为什么这件事难（给真实数据）
60s–5m  实现过程   分 3–4 节，每节一个小标题卡
5m–7m   踩过的坑   至少 2 个，带代码/日志截图
7m–8m   边界       它不适合谁（诚实清单）+ CTA
```

### 🎬 视频 1（S1 主推 · 30 秒）

**标题**：你复制过的东西，10 分钟后就没了
**平台**：B站 / 抖音 / 小红书（三平台同素材，标题各改）
**核心卖点**：复制即沉淀

| 时间 | 画面 | 字幕（大字） | 口播 / 音效 |
|---|---|---|---|
| 0.0–2.5 | 终端里一段红色报错 → 选中复制 → 继续复制下一条、再下一条 | **"昨天解决的那段报错，去哪了？"** | 口播："你明明复制过。"｜打字音 |
| 2.5–5.0 | 回到编辑器按 Ctrl+V，只出来最后复制的那条 | **"Ctrl+V 只记得最后一条"** | 口播："但 Ctrl+V 只记得最后一条。" |
| 5.0–8.0 | 黑场 0.5s → 按 `Ctrl+Alt+V`，PastePanda 从托盘弹出，历史一条条在 | **"其实它全在这儿"** | 上扬音效；口播："其实它全在这儿。" |
| 8.0–14.0 | 鼠标移到那条报错 → 右键 → **转为笔记** → 侧栏知识库里出现，带来源与时间戳 | **"右键，一步，变成笔记"** | 口播："右键，一步，它就不是临时的了。" |
| 14.0–21.0 | 切到知识库搜索框，输入"docker 报错" → 命中 → 打开问答，输入"上次那个 docker 报错怎么解决的" → 流式出答案，尾部带 `[1]` 角标 → 鼠标点角标，跳回原文 | **"下次直接问它"** | 口播："下次不用翻，直接问它。" |
| 21.0–25.5 | 快速三连：设置页本地存储提示 → OCR 本地离线 → AI 开关默认关闭（**关着的那个开关要特写**） | **"内容不出本机｜AI 默认是关的"** | 口播："东西全在你自己电脑上，AI 默认是关的，不开就是零上传。" |
| 25.5–30.0 | logo + 下载入口（GitHub / Gitee 镜像） | **"PastePanda · Windows · 开源免费"** | 口播："Windows，开源，链接在下面。" |

## 6. 制作规范

### 6.1 录屏

| 项 | 设置 |
|---|---|
| 分辨率 / 帧率 | 1920×1080 @ 60fps（竖屏版另录 1080×1920，不要横屏裁竖屏） |
| 系统缩放 | **150%**（100% 下手机上菜单文字看不清） |
| 工具 | **Cap**（开源免费，Studio 模式自带缩放/布局）起步；流程跑顺后换 **CANVID**（$75 终身）或 **Rapidemo**（$79 终身），买的是"点击自动缩放 + 光标平滑"<br>OBS 降为零预算备选：画质最强但**没有自动缩放**，缩放要在剪辑软件里手动打关键帧 |
| 必开 | 按键提示（Keyviz）、鼠标点击高亮、鼠标轨迹平滑 |
| 必关 | 任务栏通知、杀软弹窗、聊天软件、任务栏时钟以外的无关图标 |
| 数据 | **用单独的演示库**（不要拿真库，标题/标签/客户名会被录进去） |
| 主题 | 统一用一套（建议"经典白"录屏对比度最好，或"午夜"最有质感——**定一套不要混**） |

### 6.2 剪辑

- **节奏**：工具类视频每 2–3 秒一个镜头或一次画面变化，静止超过 4 秒必掉完播。
- **字幕**：全程硬字幕，中文，字号占屏宽 8–10%，带描边或底色（保证任何画面上都看得清）。**不要只靠自动识别**，技术名词必错（MCP、iroh、OCR、SQLite、Tauri）。
- **口播**：真人有条件就真人（信任感高一档）；不想出镜就用 TTS，但**语速调快 1.1–1.2 倍**，句子改短——短视频的口播是"说人话"，不是"念稿子"。
- **B-roll**：AI 生成的抽象镜头只用于片头/转场（≤3 秒），**绝不用于演示界面**。
- **音乐**：低音量纯音乐（人声 -20dB 以下），工具类不要强节奏卡点。

### 6.3 封面

三要素：**大字标题（≤12 字）+ 界面局部截图 + 右下角 logo**。
- 标题是提问题或反差句，不是功能名（❌「知识库功能介绍」✅「你复制过的，早该留下了」）
- 三平台封面尺寸各出一张，但**文案保持一致**（方便跨平台认出你）
- 品牌色沿用 `--version-badge-gradient`（#5B6AF0 → #7C5CF0），与安装包、官网一致

### 6.4 三个数据锚点（分镜评审时逐条过）

| 数据 | 含义 |
|---|---|
| **47 秒注意力悬崖** | 核心差异点必须在 47 秒前讲完，别把最狠的一句话留到结尾 |
| **60 秒以内 = 2.5 倍互动** | S1 系列死守 30 秒，S2 不超过 60 秒 |
| **超过 60% 用户静音观看** | 字幕不是可选项；每条视频导出前先静音自查一遍"不看声音能懂吗" |

### 6.5 另做一条「交互式 demo」——它不是视频

落地页上放可点击的 HTML 演示（Arcade / Storylane，有免费档），比静态视频的注册转化高约 **1.7 倍**、demo 预约高 42%。
PastePanda 自带 Web 前端，这条做起来比拍视频还便宜——**建议与视频并行做，不占用视频产能**。

## 7. 标题与标签库

1. 你 XX 过的 XX，XX 后就没了 → 你复制过的东西，10 分钟后就没了
2. 别再 XX 了，试试 XX → 别再手动整理笔记了，试试让剪贴板帮你记
3. XX 年了我才发现 XX → 用了三年剪贴板我才发现，它该是个知识库
4. 让 AI XX，而不是 XX → 让 AI 用上你的笔记，而不是把笔记喂给 AI
5. 一个 XX 工具，解决了 XX → 一个剪贴板工具，解决了"懒得记"这件事
6. XX 不用开会员 → 两台电脑同步知识库，不用开会员
7. 我把 XX 接进了 XX → 我把剪贴板接进了知识库
8. 为什么 XX 都 XX → 为什么你装的笔记软件最后都没打开

## 8. 🔴 口播红线（拍之前过一遍）

### 8.1 事实边界（沿用 `docs/知识库-推广文案.md` §9.2，视频口播更容易说过头）

| 不要说 | 原因 |
|---|---|
| ❌「端到端加密」 | 实际是加密传输 + 指纹核对，别用 E2EE 这个有特定含义的词 |
| ❌「秒级同步」 | 首次同步大量内容可能要几十分钟 |
| ❌「离线 AI」 | 问答走云端 AI；本地离线的只有 **OCR** |
| ❌「自动打标签 = AI」 | 自动标签是纯本地规则 |
| ❌「双向链接图谱」 | 只有反链面板，图谱刻意没做 |
| ❌「支持 Mac / 手机」 | 目前 Windows only |
| ❌「AI 默认开启」 | 默认**关闭**，这是卖点 |
| ❌「30 天自动清理」 | 周期用户可配置 |

### 8.2 视频特有

- **不演示任何真实隐私数据**：演示库先建好，客户名、手机号、密钥、真实项目路径一律换掉。剪贴板工具演示这个，翻车是致命的（你卖的就是隐私）。
- **不用极限词**：最好、最强、第一、唯一、永久免费（《广告法》）。
- **不承诺未实现的能力**：未发版的功能（CHANGELOG `[Unreleased]` 段）不要出现在视频里，发版后再补。
- **版本号与链接**：每条视频简介里的版本号、下载地址要与 `tauri.conf.json` 的 updater endpoints 一致；发新版本后**记得回来改旧视频简介**（或简介里只放主页，不放具体版本号）。

**看什么数据**（按重要性）：
1. **3 秒完播率** —— 钩子的唯一体检指标，<50% 就是开头没钩住，换开头重发
2. **完播率** —— 决定推荐量
3. **评论内容** —— 工具类视频的评论区是需求池（"能不能支持 Mac"就是真实需求）
4. 点赞收藏比 —— 收藏高说明被当工具存起来，是好事，但转化要看简介点击
