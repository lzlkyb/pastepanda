# 手机控制端 R2 实施记录（2026-10-02）

对应已确认设计稿：`design/手机控制端-R2交互设计稿-2026-10-02.html`。

## 已落地

- 默认精确触控板，相对划动移动指针，点按点击指针处；保留直接点击模式。内容归一化坐标复用现有几何函数，首次操作前可以用真实光标遥测定位；本地反馈环与真实电脑光标分层呈现。
- 四个主入口：鼠标模式、键盘、横竖屏、更多。画面、画质、剪贴板与声音保留原能力；返回设备和断开采用既有确认面板。
- 鼠标辅助提供左键、右键、拖拽/释放、滚动。独立触控板按需展开，竖屏在下方，横屏在侧面。
- 横屏收起使用可见“工具”把手，展开后明确提供“收起”；移除自动隐藏计时与隐藏顶缘热区。
- 键盘打开替换工具栏。一行常用快捷键、固定可见收起按钮、可见中文草稿输入与发送。扩展面板保留修饰键、方向、Delete、文字/逐键直传模式；收起再展开保留未发送草稿。
- 模式切换、失焦、旋转、隐藏、权限撤回取消延迟点击/移动，补发已按住的键释放。只看及等待/接收异常禁止远端输入；只看仍可捏合缩放。
- R2 静止点按不再落入 220–550ms 的无反馈窗口；连续小幅滚动累计，连续捏合使用每帧比例，避免重复放大起点比例。缩放后指针靠近边缘自动平移视野，完整画面可见时保持原视野。
- 等待与接收异常用共享帧管线真实状态呈现，并提供取消/返回入口；没有新增不受实际连接状态支持的重新连接承诺。

## 验证

- 手机端测试：14 个文件，75 项通过。新增守卫涵盖权限撤回、延迟点击取消、小幅滚动、相对/直接坐标、拖拽释放、中文整串发送、未发送草稿保留、连续缩放及横屏工具入口。
- `npx tsc --noEmit`、`npm run build:mobile` 通过。
- 对本轮 UI 文件显式运行 `npm run lint:ui -- ...`：0 个必须处理问题。剩余提示包含既有光标几何偏移及阴影颜色，不宣称全库无警告。
- 本地浏览器实际页面检查通过：390px 竖屏、844×390 横屏、320px 窄屏；独立触控板、拖拽状态与释放、中文输入、横屏把手和画质面板可操作，页面异常为 0。截图存放于 `design/mobile-control-r2-2026-10-02/actual-*.png`。
- 测试有既有异步 act 和测试环境 canvas 提示；构建有既有静态/动态 import 分块提示，不影响通过结果。

## 验证边界

本轮浏览器验证使用“设置 → 触摸演示”，没有实际连接电脑。不将本地按压反馈当作远端执行成功。真实手机系统键盘/候选、系统返回和旋转支持、网络延迟及真实远端操作需要真机联调。未构建 exe、未递增版本、未提交或推送。
