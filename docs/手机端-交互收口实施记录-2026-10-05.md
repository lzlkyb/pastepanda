## 二、分页兜底

- `useMobilePager.finish()`：落点偏离吸附点 >1px 且**静止 200ms**（无触点、无滚动事件）→ 吸附最近整页再提交。修复 moving 滞留后点击被永久吞掉的边缘情况；重试间隔 160ms < 阈值 200ms，不打断正常吸附动画。滚动事件同步维护 `lastScrollAt`。

## 三、口径收口与死代码（规则 11 精神：接线与文档必须同口径）

- **点按窗 = 长按窗（550ms）**：`TAP_MAX_MS=220` 的「防误触死窗」在接线上从未生效（`useSessionPointer` 一直传 550），删除该常量与状态机注释里的死窗描述；判定器默认参数改 `LONG_PRESS_MS`，两条守卫用例改为钉住新口径。阈值常量收敛到 `touchConstants` 单处。
- 删除死代码：`HOT_ZONE_PX` / `CAPSULE_FADE_MS` / `CAPSULE_FIRST_SHOW_MS`（横屏热区/自动浮现的残迹，其**替代方案**=首次引导，设计稿见下）、`useSessionPointer.interceptDown` 的拦截分支（按下手感基准保留，改名 `onDown`，不再返回布尔）、`useImmersiveCapsule.keepAlive` 空转函数及其 `onInteract` 接线、SessionToolbar 死 `feedbackSlot`、`data-no-tab-swipe` 无主 CSS 钩子。
- `RcMobileSession.module.css` 重复块合并：`.statusRow`（两处，R2 后无玻璃模糊）、`.screenArea`（两处）；删除无引用的 `.statusDot` / `.statusSub`。

## 七、横屏工具栏首次引导（设计稿确认后同日实施）

设计稿 `design/手机端-横屏工具栏首次引导-设计稿-2026-10-05.html` 经用户确认后落地：

- `useImmersiveCapsule` 改为四相位状态机：`idle → teaching → hint → done`。会话内**首次**进横屏自动展开工具栏并 15s 倒计时（teaching）；到点或用户提前「收起」进 hint（把手一次性脉冲 + 气泡「画面、键盘、画质工具都收在这里」）；用户首次主动打开工具栏 / 点画面（`controlArea` 捕获阶段 pointerdown）/ 切回竖屏 → done，本会话不再打扰。R2「显式收起、把手常驻、不吞顶缘输入」语义不变；StrictMode 双跑由 `everLandscape` ref 挡住。
- 教学倒计时条走 `feedbackSlot`（规则 15 同域），聚合进 `SessionFeedback`（顺带把发送失败横幅也收进来，`RcMobileSession.tsx` 293 行留出红线余量）；气泡挂 rail 外层（toolRail 的 overflow 会裁掉伸出画面的部分），定位沿用 feedbackSlot 横屏的 `76px + inset` 口径。
- 脉冲为 box-shadow 环动画（性能准则 8.1：非常驻——首次交互即停，后台随 Activity 暂停；单元素），`prefers-reduced-motion` 退化为静态高亮；颜色取 `var(--accent)` + `color-mix`，不引入新色值。
- 守卫测试：相位机 4 条（首教到点、主动收起/打开、切竖屏终结且不重教、键盘强制可见不改相位）+ 工具栏引导态 1 条（收起态脉冲+气泡、展开或未引导不出现）。
