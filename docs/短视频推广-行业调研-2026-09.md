# 软件推广视频 · 行业调研（2026-09）

> 调研日期：2026-09-10
> 目的：回答「别人的软件介绍和推广视频是怎么做的、用什么技术做的」，并据此修正 PastePanda 的推广方案。
> 来源：公开行业文章、厂商官网与对比评测（价格各来源不一致，以官网为准）。

---

## 0. 一句话结论

**主流做法不是「录屏」也不是「AI 生成」二选一，而是三层叠加：真机录屏（素材）→ 自动运镜包装（观感）→ 动效+字幕+音乐（节奏）。**

AI 生成视频在软件推广里**不是主力**，只用于片头、转场、概念 B-roll。原因很实在：观众要看的是"这软件到底长什么样、能不能用"，AI 生成的界面是假的，而工业界共识是 **"Real UI, not wireframes"**。

**对我们最刺眼的一条**：我昨天生成的那条 30 秒视频（纯文字卡 + 抽象卡片）属于行业里的**最低配**，是"没有录屏条件下的权宜之计"，不是行业标准做法。要真正起量，必须补真机录屏。

## 1. 三条路线：别人的视频是怎么做出来的

| 路线 | 怎么做 | 谁在用 | 成本 | 适合 |
|---|---|---|---|---|
| **A. 真机录屏 + 自动运镜**（主流） | 录真实操作，工具自动生成点击缩放、光标平滑、运动模糊 | 绝大多数 SaaS 产品演示、Product Hunt 发布视频 | 工具 $0–150 一次 | **PastePanda 应走的路线** |
| **B. 动效包装 / Motion Graphics** | 真 UI 截图或录屏为底，叠 2D/3D 动效、高亮圈、箭头、UI 抽象化重绘 | Figma / Notion / Linear 类发布视频 | 外包 $3k–20k，自己做要 AE | 有预算后做"品牌片" |
| **C. AI 生成** | Sora 2 / Veo 3.1 / Kling 生成概念镜头，HeyGen 做数字人讲解 | 概念片、片头、多语言版本 | 按秒计费，$10–250/月 | 只做补充，不做主演示 |

**额外一条值得单独说的：交互式 Demo（Arcade / Storylane）**
不是视频，是可点击的 HTML 演示。行业数据：比静态视频的注册转化高约 **1.7 倍**，互动视频带来的 demo 预约比线性视频高 **42%**。落地页上可以替代视频——**这条对 PastePanda 成本很低**（我们本来就有 Web 前端），值得单独做。

## 3. 结构套路（行业通用）

### 3.1 国际通行：4-Beat 框架

```
Hook    3–5s   点名痛点，或视觉打破常规
Reveal         露出产品身份与核心机制
Depth          深挖一个能力（只讲一个）
Context + CTA  给证据/社会证明 + 一个明确的下一步动作
```

SaaS 演示视频公认时长 **60–90 秒**；三幕结构：**痛点 15s → 方案演示 60s → CTA 15s**。

### 3.2 国内平台：黄金 3 秒

- **0–3 秒是第一道留存门槛，用户划走只要 0.5 秒**；前 3 秒流失 50% 就会大幅减少推荐。
- 开头 4 种高效模式：**悬念式 / 结论式 / 冲突式 / 利益式**。
- **禁止**：logo 动画开场、慢悠悠全景、"大家好今天介绍一款"。
- 节奏是"快—慢—快"波浪式，不是匀速：开场 5 秒快 → 中段 15–30 秒放慢讲核心 → 结尾 5 秒加快收。
- 每 3–5 秒必须有一次画面变化或信息点。
- **倒叙更有效**：先切结果画面，再回头讲过程。

### 3.3 硬数据

| 指标 | 数值 |
|---|---|
| 60 秒以内视频的单次曝光互动 | **2.5 倍**于长视频 |
| 高管观众的注意力在 **47 秒后下降 60%** | → 核心差异点必须在 47 秒前讲完 |
| **超过 60% 用户静音观看** | → 字幕不是可选项，是必需品（动态字 kinetic typography 最佳） |
| 落地页嵌入视频 | 转化率提升最高 **86%** |
| 82% 的人说看过演示视频后被说服试用/购买软件 | — |
| 交互式 demo vs 静态视频 | 注册 **1.7 倍**；demo 预约 +42% |

### 3.4 常见死法（行业反复点名）

1. **开场放 logo 动画** —— 前 5 秒人就没了。
2. **罗列所有功能** —— 观众什么也记不住。一条视频只讲**一个**工作流。
3. **没有配音/字幕** —— 静音观看者不知道该看哪。
4. **用假数据 / dummy 数据** —— 看起来假，信任下降（**对我们尤其敏感：剪贴板工具录屏必须用脱敏演示库，但数据要"像真的"**）。
5. **桌面脏乱** —— 任务栏图标、通知弹窗、书签栏全都要清掉。
6. **CTA 模糊** —— "了解更多"不转化，要给具体动作。

## 4. 与 PastePanda 的对照：我们差在哪

| 项 | 行业标准 | 我们现在 | 差距 |
|---|---|---|---|
| 画面主体 | **真机录屏 + 动效叠加** | 纯文字卡 + 抽象卡片 | 🔴 主要差距 |
| 自动运镜 | 点击自动缩放 + 光标平滑 | 无（PIL 逐帧，无录屏） | 🔴 |
| 字幕 | 全程硬字幕，动态字 | ✅ 已有（大字、品牌色） | 🟢 已达标 |
| 前 3 秒钩子 | 痛点/反差，禁 logo 开场 | ✅ 钩子是"你复制过的东西" | 🟢 已达标 |
| 时长 | 60 秒内优先 | 30 秒 | 🟢 达标 |
| 静音可看 | 必须 | ✅ 纯字幕，无依赖音频 | 🟢 达标 |
| 音轨 | BGM + 人声 | ❌ 无音轨 | 🟡 待补 |
| 交互式 demo | 落地页转化 +1.7 倍 | ❌ 没有 | 🟡 机会点 |
| CTA | 明确单一动作 | ✅ "Windows 10/11 · 开源免费"偏弱 | 🟡 可改成具体动作 |

**结论：我们的视频在"文案与结构"上已达行业水准，缺的是"真机录屏"这一层。**
这也验证了我昨天的判断——抽象化不是最优解，是**当时没有录屏条件下的正确妥协**（绝不能伪造界面，这条依然成立）。

| 步骤 | 动作 | 花费 |

## 6. 据此要修正的原方案

`docs/短视频推广方案-2026-09-10.md` 的 §6「制作规范」里我写的是 OBS + Keyviz，按这次调研应补充：

- **首选录屏工具改为 Cap（免费起步）→ CANVID / Rapidemo（$75–79 终身）**，OBS 降为"零预算备选"（它没有自动缩放，手动打关键帧很贵）。
- 新增一条：**"交互式 demo" 作为落地页的独立产物**（Arcade / 自建），转化数据比视频好。
- 新增数据锚点：**47 秒注意力悬崖**、**60 秒以内 2.5 倍互动**、**60% 静音观看**——这三条应写进分镜评审清单。
