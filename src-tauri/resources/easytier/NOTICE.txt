Windows recipe disables default features, enables wireguard/smoltcp/socks5/websocket, skips
legacy Windows thunks, and disables pnet_datalink's Windows capture backend.
Windows UDP punch pacing uses a scoped 1ms timer request and a fixed schedule;
its corresponding source is scripts/easytier/windows_punch_pace.rs.
It retains EasyTier's network-interface based address enumeration. Capture
channels return Unsupported; its pnet fallback enumeration returns no rows.
No Npcap/Packet.dll is distributed. Component hashes are in windows-x86_64/build.json.
